# 로그인 · 가입은 목적지 하나를 들고, 이어 온 사주를 내 사주로 저장할 수 있다

> **운영자 결정 2026-09-29**(조율자 세션, 흐름 시안 g 채택) — 흐름의 기조는 d(맛보기 → 잠금 → 로그인 · 가입 → 입력 복원 →
> 진행 보이는 생성), 주소는 지금 그대로, 가입 화면은 지금 모양 그대로. 「이 사주가 내 사주 맞나요?」는 기존 내 사주 카드
> (천간 그림)로 보인다. `next=/me/onboard/self?next=…` 처럼 겹겹인 주소는 이상하다 — `next` 는 최종 목적지 하나만 든다.

## 잰 것 (2026-09-29)

- 로그인으로 보내는 자리 스물일곱(`grep -rn "/auth" app`) 중 돌아갈 곳을 든 것은 셋이었다 — 궁합(`/auth?next=%2Fcompat`) ·
  사주 이어 보기(`/auth?next=%2F%23resume-reading`) · 가입 화면의 같은 갈래. `/me` 아래 열다섯 · `/ops` 넷은 `redirect('/auth')` 였다.
- 가입 관문(`gateFor`)은 `/signup` 으로만 보냈고, 가입을 마치면 사주 이어 보기(`?resume=reading`)가 아닌 사람은 모두 `/me` 로 갔다.
- `/compat` 은 관문 밖이었다 — 가입 전인 사람이 로그인하고 궁합에 돌아오면 고를 사람도 풀이권도 없는 화면에 섰다.
- 사주 이어 보기의 저장은 언제나 「저장한 사람」(`savePersonForReading`)이었다 — 처음 온 사람이 같은 생일을 온보딩에서 한 번 더
  넣었고, 첫 풀이권이 「다른 사람 풀이」에 쓰였다.

## 정한 것

1. **`next` 는 최종 목적지 하나다.** 같은 사이트 경로만 받는다 — 외부 주소 · `//…` · 역슬래시가 든 주소는 `/me` 로 눕힌다.
   `/auth` · `/signup` 을 가리키는 `next` 도 받지 않는다(받으면 그것이 겹친 `next` 다). 규칙은 `src/lib/consent/return-path.ts`
   한 곳이고, 관문 · 문 · 화면이 같은 함수를 부른다. 기본값(`/me`)이면 주소에 싣지 않는다.
2. **서버 화면은 제 주소를 짓지 않는다.** 관문(`proxy.ts`)이 요청마다 지금 주소(경로 + 쿼리)를 머리글 `x-saju-return-path` 로
   덮어써 넘기고, 화면은 `redirectToSignIn()`(`app/auth/sign-in-redirect.ts`) 하나를 부른다. 레이아웃은 쿼리도 동적 조각도
   못 받기 때문이다. 머리글은 누가 지어 보내도 1 의 검사를 다시 지난다.
3. **중간 걸음은 관문이 끼운다.** `gateFor` 가 가입 화면으로 보낼 때 가려던 곳(쿼리 포함)을 `next` 로 싣고, 가입 화면 ·
   `completeSignup` 이 가입을 마친 뒤 그리로 보낸다(액션은 화면이 넘긴 값을 다시 좁힌다). 관문 밖인 사주 이어 보기(`/`)는
   로그인을 마친 자리(`/auth` · 콜백)가 가입 화면을 한 번 거치게 한다(`afterSignIn`). `?resume=reading` 은 걷었다.
4. **궁합(`/compat`)이 관문 안에 든다.** 가입 전인 계정은 가입 화면을 거쳐 `/compat` 으로 돌아오고, 베타가 끝났으면 `/me` 아래와
   같이 `/closed` 로 간다. 계정 · 일정을 못 읽었을 때의 갈래는 `/me` 아래와 같다(ADR 0078).
5. **이어 온 사주를 내 사주로 저장할 수 있다.** 사주 이어 보기에 선 사람이 로그인했고 **내 사주가 없으면**
   「이 사주가 내 사주 맞나요?」를 홈의 내 사주 카드(`SelfCard`, 저장 전이라 고칠 손잡이와 풀이 단추 대신 두 단추)로 묻는다.
   카드의 이름은 적은 이름이 아니라 **닉네임**이다 — 내 사주는 닉네임으로 저장되므로 홈에서 만날 이름을 보인다(읽는 문
   `app/self-person-state.ts`).
   「내 사주로 저장」은 온보딩과 같은 문(`saveSelfPerson` → `create_self_person`)으로 등록하고 `/me/readings/self` 로 간다 —
   풀이는 거기서 사용자가 누른다(ADR 0028). 「다른 사람 사주였어요」는 지금 흐름(저장한 사람)을 연다. 주소는 새로 안 만든다.

## 실패했을 때

- 내 사주가 있는지를 **못 읽으면 묻지 않는다** — 지금 흐름(저장한 사람)이 선다. 이미 내 사주가 있는 사람에게 「내 사주 맞나요?」를
  세우는 것보다 없는 사람에게 한 번 덜 묻는 편이 되돌리기 쉽다(저장한 사람은 목록에서 뺄 수 있다).
- 관문 머리글이 없으면(관문 밖) 돌아올 곳은 `/me` 다 — 전과 같다.
- 접근 판정은 그대로 DB 가 한다. 이 결정은 **길을 가리키는 것**만 바꾼다 — `create_self_person` 이 가입 · 이미 등록했는가를 다시 묻는다.

## 잠그지 않은 것

- 비로그인 맛보기 · 잠긴 목차 · 가입 선물 문구(시안 g 의 다른 조각)는 이 결정이 아니다.
- 현관 「테스트 코드로 시작하기」 · 공유본 「로그인하고 시작하기」는 목적지가 기본값(`/me`)이라 주소가 그대로 `/auth` 다.
