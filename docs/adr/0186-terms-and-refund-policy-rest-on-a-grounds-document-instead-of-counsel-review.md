# 이용약관 · 환불정책은 변호사 검토 대신 법적 근거 문서에 선다 — 판매를 여는 다른 조건은 그대로다

> **운영자 결정 2026-10-16**(대화에서, 조율자가 옮김) — 「이용약관 · 환불정책도 처리방침처럼 변호사 검토 대신 법적 근거 문서로 간다」.
> 처리방침의 선례는 ADR 0180 과 `docs/legal/privacy-grounds.md` 다. 같은 날 사업장 주소는 집으로 정했다(「그냥집으로하지뭐」). 사정은
> `docs/notes/2026-10-16-pg-prep-round.md` 「다음 세션 할 일」 2.

G-25 · G-21 이 들던 「결제 판매를 실제로 여는 일은 변호사 검토가 끝날 때까지 하지 않는다」(운영자 2026-09-24, `docs/legal/README.md`
「무엇이 막히고 무엇이 안 막히나」)와 ADR 0171 머리의 같은 인용을 바꾼다. 그 밖의 판매 조건과 다른 ADR 은 그대로 선다.

## 잰 것 (2026-10-16)

- 이용약관 · 환불정책은 2026-10-12 부터 `/terms` · `/refund` 에 게시돼 있다(ADR 0172). 게시는 2026-10-07 부터 변호사 검토를 기다리지
  않았다(ADR 0148). 변호사 검토 자체도 그날부터 선택이다.
- 그런데도 판매 개시와 가입 폼의 약관 확인 칸은 「검토가 끝날 때까지」에 묶여 있었다 — 보낼 날이 정해지지 않은 검토가 판매의 선행조건으로 남았다.
- 처리방침은 2026-10-15 에 같은 물음을 풀었다 — 변호사 답 대신 줄마다 조문 원문 · 코드 줄을 든 근거 문서로 갔다(ADR 0180).
- 약관 · 환불정책이 인용한 법은 전자상거래법 · 같은 법 시행령 · 약관규제법이다. 2026-10-16 에 국가법령정보센터에서 원문을 다시 읽었다(근거 문서).

## 정한 것

1. **변호사 답은 이용약관 · 환불정책의 시행(시행일 · 가입 폼의 약관 확인 칸)과 판매 개시의 선행조건이 아니다.** 대신
   `docs/legal/terms-grounds.md` 가 약관 · 환불정책의 줄마다 조문 원문 · 링크 · 확인 날짜 · 코드 `파일:줄` 을 든다. 변호사에게 묻는 것은
   선택 검토로 남는다(`docs/legal/counsel-request.md`).
2. **근거 문서는 요건을 사실대로 적고 「적법」이라 단정하지 않는다.** 머리말은 「법률 자문 아님 · 변호사 검토 전」이다. 조사 범위는
   약관 · 환불정책이 이미 인용한 조문까지다 — 새 물음을 더하지 않는다. 약관 · 환불정책 문장을 바꾸는 PR 은 그 줄의 근거도 같은 PR 에서 고친다.
3. **판매를 여는 다른 조건은 그대로다** — 결제 직후 계약내용 이메일 교부(전자상거래법 제13조②, G-21), 사업자 값과 통신판매업
   신고번호(`BUSINESS_*`, ADR 0172), PG 계약과 운영 키(G-21), 운영자의 문구 승인과 시행일. 남은 걸음은 G-21 · G-25 가 든다.
4. **이 결정이 바꾸지 않는 것** — 본인확인(G-20)의 CI 물음(요청서 B-1 · B-2)과 결혼중개업법 물음(G-25 ⑪)의 자리는 그대로다.
5. **사업장 주소는 운영자의 집이다.** 상세 주소는 저장소에 적지 않는다(ADR 0172 「정한 것」 2) — 근거 문서가 표시 의무의 조문과 함께 든다.

## 고르지 않은 것

- **변호사 답을 기다린다** — 검토가 선택이 된 뒤에도 판매만 그 답에 묶여, 보낼 날이 없는 검토가 판매를 막았다.
- **근거 없이 연다** — ADR 0180 과 같은 까닭으로 줄마다 근거를 남긴다. 나중에 검토를 받을 때도 그 문서가 묻는 자리를 보인다.

## 결과

- `docs/legal/README.md` · `docs/legal/counsel-request.md` · G-21 · G-25 의 「검토가 판매의 조건」 문장이 이 결정에 맞춰 바뀐다.
- ADR 0171 은 머리의 인용만 일부 대체되고 결정(심사 계정만 결제창)은 그대로 선다.
- 요청서의 약관 · 환불 물음(A-1 · A-2 · 「G-25 ⑥ · ⑦」 · B-7 · B-8)은 선택 검토의 물음으로 남는다 — 답이 판매를 막지 않는다.
