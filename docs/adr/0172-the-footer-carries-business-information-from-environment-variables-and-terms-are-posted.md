# 바닥글은 사업자 정보를 환경변수에서 받아 모든 화면에 싣고, 이용약관 · 환불정책이 공개 주소에 선다

> **운영자 결정 2026-10-12**(조율자 세션, 이슈 #666). 「바닥글에 사업자 정보 자리를 만들고 값은 나중에(환경변수) 넣는다. 집 주소를
> 게시할지 비상주 사무실로 옮길지는 값을 넣기 전에 운영자가 정한다.」 같은 날 칸을 늘렸다 — 전자우편주소 · 호스팅서비스 제공자 ·
> 공정거래위원회 사업자정보 공개 페이지 링크. 이 결정이 대체하는 것 — **ADR 0151 전부**(「정한 것」 2 의 「집 주소는 저장소에 적지
> 않는다」는 아래 2 로 이어 간다). 이용약관 · 환불정책의 게시는 운영자 결정 2026-10-07(`docs/legal/README.md`) 그대로다.

## 까닭

PG(포트원 필수 구축요건, <https://help.portone.io/content/requirements>)와 전자상거래법 제10조가 사업자 정보와 이용약관을
**결제 페이지까지 상시** 표시하라고 한다. 운영자가 든 조문(제10조① · 시행령 제11조의4 · 시행규칙 제7조 — 초기 화면의 표시 항목과
사업자정보 공개 페이지 링크, 제7조②)은 **law.go.kr 에서 확인 전**이다. 출처: <https://www.law.go.kr/LSW/ftcInfoP.do?ftcSeq=753> ·
<https://thecheck.co.kr/?p=6064>. 전화는 휴대폰 번호를 받지 않는 PG 가 있어 070 을 들일 예정이다([G-21 기록](../product/gaps/records/g-21.md) ⑤).

## 정한 것

1. **바닥글은 운영 화면(`/ops/**`) 밖의 모든 화면에 선다.** 앱 밖(`/` · 로그인 · 가입 · 공유 · 안내)은 지금 판에 사업자 정보 묶음을
   더한다. 앱 안(`/me/**` · `/compat`)은 이름 · 소개 · 안내 링크를 빼고 **약관 링크 셋(이용약관 · 환불정책 · 처리방침)과 사업자 정보만**
   든다(`app/site-footer.tsx`, 링크는 `app/site-links.ts` 의 `POLICY_LINKS`). 폰의 인연 덱(`data-deck-fit`)과 대화방
   (`data-chat-room`)은 문서를 화면 한 장에 묶으므로 그동안 바닥글을 걷는다(`app/globals.css`) — 같은 탭의 다른 화면과 넓은 폭에서는
   선다.
2. **값은 저장소에 적지 않는다 — 환경변수 아홉이다.** 저장소가 공개이고 사업장 주소가 아직 운영자의 집이다. 이름으로 읽는 자리는
   `app/business-info.ts` 하나이고, 비밀이 아닌 설정이라 `scripts/secret-env.mjs` 의 `CONFIG_ENV` 에 선다. `NEXT_PUBLIC_` 이 아니라
   서버에서만 읽고, 뿌리 레이아웃이 바닥글(클라이언트)에 값을 넘긴다. 미리 그리는 화면은 빌드 때의 값을 든다 — 값을 바꾸면 다시
   배포한다.

   | 환경변수 | 칸 |
   | --- | --- |
   | `BUSINESS_TRADE_NAME` | 상호 |
   | `BUSINESS_REPRESENTATIVE` | 대표자 |
   | `BUSINESS_REGISTRATION_NUMBER` | 사업자등록번호(`123-45-67890` 꼴) |
   | `BUSINESS_ADDRESS` | 사업장 주소 |
   | `BUSINESS_PHONE` | 전화 |
   | `BUSINESS_EMAIL` | 이메일 |
   | `BUSINESS_MAIL_ORDER_NUMBER` | 통신판매업 신고번호 |
   | `BUSINESS_HOSTING_PROVIDER` | 호스팅서비스 제공자 |
   | `BUSINESS_DISCLOSURE_URL` | 공정위 사업자정보 공개 페이지 주소(https) — 사업자등록번호 곁의 링크 |

3. **값이 빈 칸은 그리지 않는다.** 비었거나, 자리표시(「홍길동」 · 「000-00-00000」 · 「［기입］」)이거나, 꼴이 틀린 번호 · 이메일 ·
   주소(https 아님)는 빈 값으로 본다(`src/lib/brand/business.ts` 의 `businessInfoFrom`, 시험 `business.test.ts`). 하나도 없으면 묶음째
   안 선다 — 값을 넣기 전의 바닥글은 지금과 같다(앱 안은 약관 링크 셋만).
4. **이용약관은 `/terms`, 환불정책은 `/refund` 다**(처리방침 `/privacy` 를 본떴다). 로그인 없이 열린다 — `proxy.ts` 의 matcher 밖이다.
   글자는 `src/lib/brand/terms.ts` · `refund.ts` 가 들고, 원본은 `docs/legal/terms-draft.md` · `refund-policy.md` 다 — 초안을 고치면
   코드도 고친다. 옮길 때 초안의 꺾쇠 표지(`［표준 제N조］` · `［변호사 검토 필요: …］`)는 싣지 않았다.
5. **본문의 사업자 빈칸은 같은 환경변수에서 채우고, 비면 화면에 빈칸 표지를 내지 않는다.** 상호가 없으면 「회사」로만 부르고, 약관
   제3조와 환불정책 「판매자 정보」는 값이 있는 줄만 든다. 「［고객 문의 이메일 — 기입］로」는 이메일이 있으면 「이메일(주소)로」, 전화만
   있으면 「제3조의 연락처로」 · 「아래 판매자 정보의 연락처로」, 둘 다 없으면 「이메일로」가 된다. 계약 뒤에만 채울 수 있는 빈칸(본인확인기관 ·
   PG · 연동 대행사 이름 — 약관 제8조⑤ · 제12조③)과 정하지 않은 재가입 제한 기간(제8조④)은 그 항이나 그 말을 뺐다. 시행일은 코드의
   상수(`TERMS_EFFECTIVE_DATE` · `REFUND_EFFECTIVE_DATE`)이고 지금은 비어 줄째 안 선다.
6. **게시는 판매 개시가 아니다.** 판매 스위치 · 가입 동의 흐름 · 처리방침 v8 은 그대로다(G-20 · G-21 · G-25).

## 바꾸지 않은 것

- 처리방침(`/privacy`, `notice-v6`)의 글자.
- 결제 · 상품 화면 — 그 화면은 이 경로에 링크만 건다(이슈 #667).

## 남은 것

- **약관 제30조②(분쟁 조정기관)는 싣지 않았다** — 운영자가 선택지(가 · 나 · 다)를 고르기 전이다(`docs/legal/README.md` 물음 5). 지금
  글은 「선택지 다」와 같아 보이지만 고른 것이 아니다.
- 약관 제3조의 호스트서버 소재지 · 개인정보 보호책임자 줄은 환경변수가 없어 싣지 않았다.
- 값을 넣기 전에 운영자가 사업장 주소(집 · 비상주 사무실)를 정한다. 값은 Vercel Production 에 넣고 다시 배포한다.
- 화면 문구(칸 이름 · 페이지 제목 · 링크 글자)는 시안이다 — 운영자가 확정하면 문구 대장 `docs/product/copy-ledger/public.md` 에 절을
  더한다.

## 치르는 값

- 앱 안의 모든 화면 끝에 줄이 하나 는다. 폰의 덱 · 대화방은 바닥글을 걷어 그 화면에서는 약관 링크가 바로 안 보인다 — 같은 탭의 다른
  화면에서 닿는다.
- 약관 글이 코드와 초안 두 곳에 산다. 갈리면 초안이 원본이다.
