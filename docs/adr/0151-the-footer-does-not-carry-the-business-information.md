# 바닥글은 사업자 정보를 싣지 않는다

> **운영자 결정 2026-10-08**(대화에서) — 첫 화면 바닥글의 상호 · 주소 · 통신판매업 신고번호를 빼라. 사업장 주소가 운영자의 집
> 주소이고, 법인이 아니다. 이 결정이 대체하는 것 — ADR 0149 의 운영자 결정 3 과 「정한 것」 6.

## 정한 것

1. **앱 밖 화면의 바닥글은 서비스 이름 · 한 줄 소개 · 「비공개 베타」 · 안내 링크까지다.** 사업자 정보 줄(`dl`)을 걷고 값을 들던
   `src/lib/brand/business.ts` 와 그 시험을 지웠다 — 그리는 자리가 없는 값은 상수로 두지 않는다.
2. **집 주소는 저장소에 적지 않는다.** 저장소가 공개라 ADR 0149 · 문구 대장에 적힌 상세 주소를 「인천광역시 부평구」까지로 줄였다.
   지난 커밋의 글자는 git 기록에 남는다 — 기록을 다시 쓰는 것은 force push 라 하지 않는다(ADR 0150).

## 다시 열 때

결제(G-21)를 켜기 전에 다시 본다. 전자상거래법 제10조의 표시는 개인사업자 통신판매업자에게도 걸리고 PG 심사도 사업자 정보를
본다 — 그때 사업장 주소를 집이 아닌 곳(비상주 사무실 등)으로 옮길지, 어느 화면에 무엇을 실을지를 운영자가 정한다.
