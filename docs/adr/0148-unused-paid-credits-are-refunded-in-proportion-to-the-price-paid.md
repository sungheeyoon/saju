# 안 쓴 유료 풀이권은 언제든 산 값의 비율대로 공제 없이 돌려준다

> **운영자 결정 2026-10-07**(대화에서, 조사 노트 `docs/notes/2026-10-07-reading-credit-refund-research.md` 를 보고) — 유료 풀이권은
> 자동 만료가 없다 · 7일 안이든 뒤든 요청하면 안 쓴 유료분을 전액 환불한다 · 환불액은 실제 결제액 × 안 쓴 유료 회차 ÷ 산 유료
> 회차다(쓴 회차를 1회 정가로 다시 셈하지 않고 수수료를 떼지 않는다) · 정상 제공한 풀이는 사전 고지와 무료 체험을 갖춘 경우
> 단순 변심 환불에서 뺀다 · 생성 실패와 계약과 다른 제공은 복구 또는 환불한다 · 무료 풀이권은 현금으로 돌려주지 않는다 ·
> 서비스를 끝내면 최소 30일 전에 알리고 안 쓴 유료분을 수수료 없이 정산한다. 그리고 **이용약관 · 환불정책의 게시는 변호사 검토를
> 기다리지 않는다**(PG 심사가 살아 있는 이용약관 · 환불정책 주소를 요구한다).

ADR 0100 이 「청약철회 · 환불은 G-21 · G-25 가 든다」로, ADR 0106 이 「환불 금액은 사람이 정해 넣는다(산식 없음, G-25 ⑥)」로 남긴
자리를 채운다. 장부(ADR 0106)의 표 · 문 · 쓴 순서(무료 → 예외 → 산 때가 이른 묶음)는 그대로다 — 이 결정은 그 장부가 내는 값으로
**얼마를 돌려주는가**만 정한다.

## 정한 것

| 물음 | 답 |
| --- | --- |
| 유료 풀이권의 기한 | **자동 만료 없음**(ADR 0100 그대로). 과기정통부 표준약관 제13조의 유상 포인트 5년보다 이용자에게 유리하다 |
| 산 날부터 7일 안 | 요청하면 안 쓴 유료 회차를 공제 없이 돌려준다 — 전자상거래법 제17조의 청약철회 |
| 7일이 지난 뒤 | **같은 금액**을 돌려준다 — 법정 최소가 아니라 약관으로 더 주는 운영 정책이다 |
| 환불액 | 주문마다 `실제 결제액 × 돌려줄 안 쓴 유료 회차 ÷ 그 주문의 산 유료 회차`. 쓴 회차를 1회권 정가로 다시 셈해 묶음 할인을 회수하지 않고, 수수료 · 위약금을 떼지 않는다 |
| 원 단위 | 같은 묶음을 여러 번 나눠 돌려주면 누적으로 셈한다 — `결제액 × 지금까지 걷은 회차 합 ÷ 산 회차`(원 미만 버림)에서 이미 돌려준 금액을 뺀다. 묶음을 다 돌려주면 합이 결제액과 같고, 넘지 않는다 |
| 정상 제공한 풀이 | 결제 전 고지와 무료 풀이권 1개의 체험을 갖춘 경우 단순 변심으로는 돌려주지 않는다 |
| 생성 실패 · 계약과 다른 제공 | 다시 제공하거나 돌려준다. 실패한 시도는 애초에 풀이권을 안 쓴다(ADR 0021). 인연 요청의 수락만으로 생성이 실패한 회차를 쓴 것으로 보지 않는다 |
| 예약 중인 회차 | 예약이 풀린 뒤(요청을 거두면 곧바로) 돌려줄 대상이다 — 예약은 환불을 영영 막는 사유가 아니다 |
| 무료 · 예외 풀이권 | 현금으로 돌려주지 않는다(ADR 0100 그대로) |
| 탈퇴 | 남은 유료분은 탈퇴 전에도, **탈퇴 뒤에도 결제 기록이 남아 있는 동안**(마지막 결제 · 환불일부터 5년, ADR 0106 결정 10) 요청하면 같은 셈으로 돌려준다 — 탈퇴로 소멸하지 않는다 |
| 이용 정지 · 해지 | 남은 유료분은 같은 셈으로 돌려받을 수 있다 |
| 서비스 종료 | 최소 30일 전에 공지하고 개별로 알리며 판매를 멈춘다. 안 쓴 유료분은 같은 셈으로 수수료 없이 정산한다. 공지 기간이 지났다고 청구권이 없어지지 않는다. 30일은 고른 운영 정책이지 확인된 법정 기한이 아니다 |

예: 59,000원 20회권에서 유료 3회를 썼으면 남은 17회는 50,150원이다. 7일 안이든 뒤든 같다.

## 까닭

- **조사(2026-10-07 노트)** — 앞서 제안됐던 「7일 뒤 10% 공제」의 근거로 든 콘텐츠이용자 보호지침 제25조는 스트리밍형 계속 계약의
  해지 규정이라 풀이권에 그대로 옮기기 어렵다. 「쓴 회차를 1회권 가격으로 공제」(옛 선택지 가)는 20회권을 절반 넘게 쓰면 환불이 거의
  0 이 되어 약관규제법 제9조의 원상회복 쪽에서 가장 약했다. 남은 비율 그대로(옛 선택지 다)가 셈도 쉽고 다툼도 적다.
- **분류의 불확실성을 정책으로 줄인다** — 풀이권이 가분적 디지털콘텐츠인지 · 상품권 · 포인트인지에 대한 확정 해석은 찾지 못했다.
  안 쓴 유료분을 언제든 공제 없이 돌려주면 어느 분류에서도 이용자에게 불리하지 않다.
- **기한을 두지 않는다** — 사주 · 궁합을 얼마나 자주 볼지 가정해 20회권에 소진 기한을 걸 근거가 없다(ADR 0100).

## 대가

- 남은 유료분의 의무가 기한 없이 남는다. 산 수 · 쓴 수 · 환불 이력을 권리가 남아 있는 동안 읽을 수 있어야 한다 — 계정이 있는 동안은
  장부가, 탈퇴 뒤에는 `retention.reading_payment` 가 든다(5년). 그 뒤의 청구는 확인할 기록이 없다.
- 공제 없는 환불이라 반복 구매 · 취소의 결제 수수료와 응대 비용을 회사가 진다. 미사용분에 대응하는 돈을 다 쓰면 종료 정산이 어렵다.
- **법률 판단의 확정이 아니다.** 변호사 검토는 하고 싶을 때 나중에 한다 — 결혼중개업법 물음(G-25 ⑪)만은 공개 출시 전에 변호사에게
  남길 수 있다(운영자, 아직 정하지 않았다). 실제 판매를 여는 조건(판매 스위치, G-21)은 이 결정이 바꾸지 않는다 — **약관을 게시하는 것은
  판매를 여는 것이 아니다.**

## 바뀌지 않는 것 · 남은 것

- 환불은 여전히 사람이 PG 콘솔에서 먼저 하고 `refund_reading_order` 로 적는다(`docs/ops/runbook/credits.md` 「산 풀이권」). 이 산식은
  사람이 넣는 금액의 기준이다 — 환불 셈 화면 · 자동 환불은 판매를 여는 PR 의 몫이다(G-21).
- 약관 문장은 `docs/legal/terms-draft.md` 제12조 · 제15조 ~ 제17조의2 · 제23조, 이용자에게 보이는 짧은 글은 `docs/legal/refund-policy.md` 다.
