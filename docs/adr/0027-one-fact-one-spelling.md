# 한 사실에는 한 표기 — 그리고 그 표기를 어디에 적을지도 규칙이다

ADR 0026 이 **무엇을 부르는 이름**을 정했다. 이 문서는 **어떻게 적는가**를 정한다.
낱말이 한 벌이어도 표기가 셋이면 사용자는 그것이 같은 것인지 확인하는 데 눈을 쓴다.

## 시각을 모른다는 한 가지 사실을 세 이름으로 불렀다

넣을 때는 「시간 모름」 라디오를 고르고, 내 사주에서는 「시각 모름」으로 읽고, 결과 표에서는
「시각 미상」을 봤다. 한 사람이 한 번의 흐름에서 셋을 다 만난다.

**「출생 시각 모름」**(`HOUR_UNKNOWN_LABEL`)으로 모은다.

- 「시간」이 아니라 **「시각」** — 시간은 길이(두 시간)로도 읽힌다.
- 「미상」이 아니라 **「모름」** — 미상은 행정 문서의 말이다.

값은 그대로 `'unknown'` 이다. 바꾼 것은 화면에 적는 글자뿐이라 이미 나눠 준 링크도 저장된
판본도 움직이지 않는다.

**표가 좁으면 줄바꿈하지, 낱말을 바꾸지 않는다.** 네 칸짜리 기둥 표에서 「출생 시각 모름」은
두 줄로 앉는다. 거기서만 「시각 모름」으로 줄이면 그것이 세 표기가 생긴 경로다.

### 라디오 두 칸을 대칭으로 맞췄다

「시간 입력」 / 「출생 시각 모름」으로 두면 한쪽만 무엇의 시각인지 말한다. 화면에서는
`legend` 가 그 자리를 덮지만 **낭독기는 고른 칸 하나만 읽어 주는 때가 있어**, 그때
「입력」이 무엇의 입력인지 모른다. 둘 다 「출생 시각 …」으로 적는다.

이 이름이 길어지면서 시험 하나가 걸렸다 — `getByLabel('출생 시')` 가 시(hour) 입력 칸과
「출생 시각 모름」 라디오를 **함께** 잡았다. 부분일치 선택자는 화면 낱말이 길어지는 날
조용히 둘을 잡으므로, 이 폼에서는 `exact: true` 로 못박는다.

## 「출생 정보」 — 붙였다 띄었다 하고 있었다

띄운 곳 7, 붙인 곳 14. `revise.tsx` 와 `people/page.tsx` 는 **같은 파일 안에서 둘 다**
썼다. 띄어 적는 쪽으로 52자리를 한 번에 옮겼다. 판단할 것이 없는 자리다.

## 진행 중은 「~ 중…」 하나다

스물넷 중 넷이 다른 말투였다 — 「적는 중이에요…」·「보내는 중이에요…」·「풀이를 쓰고
있어요…」·「구글로 이동합니다…」.

**짧은 상태 라벨에 말투를 싣기 시작하면 화면마다 온도가 달라진다.** 버튼 한 칸에서
공손함을 표현할 필요가 없고, 그 자리에서 사용자가 알고 싶은 것은 무엇이 도는 중인가다.

## 버튼에 해라체를 쓰지 않는다

「뺀다」가 화면에서 유일한 해라체였다. 옆의 확인 버튼들은 「삭제를 요청합니다」·
「차단합니다」·「신고합니다」다.

**「제외합니다」가 아니라 「뺍니다」로 갔다.** 바로 왼쪽 문장이 「○ 님을 목록에서
뺍니다」이고 여는 버튼이 「목록에서 빼기」다 — 여기서 「제외」로 바꾸면 한 동작을 부르는
낱말이 셋(빼기·뺍니다·제외합니다)이 된다. 고치려던 것은 **말투**이지 낱말이 아니었다.

## 마침표는 자리가 정한다

| 자리 | 마침표 |
| --- | --- |
| 제목 · 라벨 · 딱지 · 버튼 | 없음 |
| 짧은 상태 표시 | 없음 |
| 설명문 · 안내문 · 경고문 | 있음 |
| 여러 문장 | 문장마다 |

바꾼 것은 넷이다 — 「복사했습니다」·「저장했습니다」(상태 표시)와 「중지된 계정입니다」·
「삭제를 요청한 계정입니다」(제목). 나머지 거절·안내 문장은 이미 규칙대로 서 있었다.

표는 CONTEXT.md 의 「화면 문구 규칙」에 있다. 이 문서는 **왜 그렇게 정했는지**를 들고,
그쪽은 **다음 문구를 적을 때 보는 자리**다.

## 마지막에 훑는다

내린 낱말은 다시 올라온다. 그래서 끝에 한 번 훑었고, `match-v0` 하나가 **각주에 남아
있었다** — 카드 딱지에서는 뺐는데 그 아래 한 줄에 그대로 있었다.

용어집이 이미 그것을 금지하고 있었다(「기존 실험 지표」 항목: *내부 버전은 사용자에게
보이지 않는다*). 각주가 답하는 물음은 「이 숫자가 무엇인가」이고 판본 이름 없이 말할 수
있다 — 「서로 견주어 보라고 만든 실험값입니다」.

**훑는 일을 시험이 대신하게 했다.** `matching.test.ts` 가 지표에서 사용자에게 나가는
문자열을 모아 `match-v0` 을 거절하고, `consent.test.ts` 는 동의 쪽 상수 전부를 훑는다.

## 남은 것

- **해요체가 사주풀이 카드 안에만 있다** — 「아직 받아 둔 풀이가 없어요」·「이 풀이는
  어떠셨어요?」. 이번에 고친 것은 진행 라벨뿐이고 이 카드의 말투는 일부러 두었다. 사람이
  쓴 글을 받는 자리라 부드러운 것이 맞을 수 있다. 다만 그 카드 안에 「예상하지 못한 오류로
  풀이를 만들지 못했습니다」가 함께 서 있어, **한 카드에 두 말투**인 상태는 그대로다.
- 조후·종격·통근·신강신약의 긴 각주는 신살과 같은 모양이다(ADR 0026). 아직 안 접었다.
- `notice-v2` 의 시행일 `2026-09-02` 는 `588ede3` 의 커밋·배포 날짜에서 잡았다.
  실제 시행일이 다르면 `NOTICE_EDITION.effectiveFrom` 한 줄이다.
