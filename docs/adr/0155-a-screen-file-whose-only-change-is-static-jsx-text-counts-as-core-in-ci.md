# 정적인 JSX 문구만 바뀐 화면 파일은 CI 에서 `core` 로 센다

> **제안**(2026-10-08) — 운영자가 측정 표를 보고 정한다. 운영자가 정한 제한(`className` · 문자열 속성은 대상이 아님, 시험 소스에 든
> 문구는 원래 규칙, 페이지의 추가 · 삭제 · 이동은 원래 규칙)을 그대로 지켰다.

ADR 0119(관문 · 화면의 입구 · 인증은 베타에서도 머지 전에 잰다)에 예외를 더한다. 규칙의 원본은 `scripts/ci-plan.mjs` 머리의
「정적인 JSX 문구만 바뀐 화면 파일은 `core` 로 센다」다.

## 정한 것

- **운영 베타의 PR 에서 `app/**` 의 `.tsx`(입구 `page` · `layout` 포함)가 정적인 JSX 문구만 바뀌었으면 그 파일은 `core` 다.** 그 주소의
  e2e 차선을 켜지 않고, `layout` 이어도 공용 위험이 아니다. 판정은 ADR 0153 의 파서를 다시 쓴다. `JsxText` 와 JSX 자식 자리의
  `{'…'}` 문자열을 가린 구문 나무가 base 와 같아야 한다. 실행식 · props · 이벤트 · 조건부 렌더링 · import · export · 태그는 그대로여야 한다.
- **원래 규칙 그대로 가는 것.** 속성 값이 바뀐 파일은 원래 규칙이다. `className` 이 그렇고(`hidden` · `pointer-events-none` · 반응형
  표시 · 레이어가 동작을 막는다), 문자열 속성(`aria-label` · `placeholder` · `title` · `alt`)도 처음에는 그렇다. 시험이 그 글을 볼 수
  있을 때도 원래 규칙이다. 바뀐 옛 · 새 글이 시험 소스(`e2e/**` · 흐름 검사와 도우미 · 그 둘이 import 하는 공용 상수)의 문자열에
  부분으로 들 때, 시험의 문자열이나 정규식이 옛 · 새 글 중 한쪽에만 맞을 때, 글자가 둘보다 적을 때가 그렇다. 인증 · Next 공용
  경계 · 메타데이터 파일도 원래 규칙이다. 옛 소스를 못 읽을 때(페이지의 추가 · 삭제 · 이동), 파싱이 실패할 때, 뜻이 있는 주석이
  바뀔 때, 공개 출시 단계일 때도 그렇다.
- **보조 근거의 방향.** 운영자의 제한은 「옛 문구가 시험 소스에 있는가」다. 거기에 반대 방향을 더했다. `getByText('로그인')` 처럼
  부분으로 찾는 시험은 그 짧은 글이 옛 글과 새 글 중 한쪽에만 들면 고르는 요소가 달라지기 때문이다. 양쪽에 다 들면 고르는 것이
  그대로라 세지 않는다. 처음 짠 「시험 문자열이 글 안에 들기만 해도」는 `사주` · `궁합` 같은 낱말에 걸려 거의 모든 문장이 원래 규칙이 됐다.

## 잰 값(2026-10-08)

최근 60일(2026-09-05 ~ 10-08) 머지된 PR 423 개 가운데 `app/**/*.tsx` 를 바꾼 158 개를 다시 돌렸다. 각 머지 커밋의 나무에서 옛 규칙과
새 규칙을 돌렸고, 단계는 운영 베타로 두었다.

- **계획이 달라진 PR 은 0 개다.** 문구만 바뀐 화면 파일을 품은 PR 은 모두 구조가 바뀐 화면 파일이나 공용 위험을 함께 들었다.
- 반사실로 쟀다. 그 문구 파일 하나만 든 PR 이었다면 차선을 건너뛸 파일은 7 개였다(#56 의 1 개, #338 의 6 개). 그 PR 들의 실행과 머지
  직후 main 실행(끊겼으면 그다음 끝난 main 실행)에서 **그 차선은 한 번도 붉지 않았다.**
- 화면 파일 변경 944 건의 내역은 이렇다. 추가 · 삭제 109 건, 구조가 다름 779 건, 문구만 바뀌었는데 시험이 그 글을 봄 47 건, 문구만 바뀌고
  시험이 안 봄 9 건(지금의 시험 소스로 셌다).

## 치르는 값

- 시험 소스를 PR 마다 한 번 읽는다(문자열 약 3,100 · 글자 있는 정규식 약 270). 문구만 바뀐 화면 파일이 있을 때만 읽는다.
- 남는 구멍이 있다. 시험 문자열이 문구 둘에 걸치는 경우(`{name}님, …`), 그리고 화면 밖 상수로 짜 맞춘 글을 찾는 시험은 부분 문자열로
  안 잡힐 수 있다. 그 붉음은 머지 뒤 main 의 전체가 잡는다.
