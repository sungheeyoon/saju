# 화면은 던진 액션 부름을 받아 실패 줄로 세우고, 화면 안의 못 읽은 칸은 붉은 줄 하나로 선다

> **운영자 지시 2026-10-11** — 「UI/UX 기본이 안 돼 있다」며 감사를 시켰고, 감사가 찾은 가장 큰 공통 결함이 이것이었다. 문구는 같은 날 밤
> 조율자를 거쳐 받은 원칙(「짧게 — 실패 줄은 『저장하지 못했어요』 + 『다시 시도』 수준, 한 줄 넘는 안내문은 만들지 않는다」)을 따랐다.

## 잰 것 (2026-10-11)

- 클라이언트 파일(`'use client'`)이 `'use server'` 파일에서 들여와 부르는 자리 쉰 가운데 부름이 던지는 것을 받는 자리는 열다섯이었다
  (`try` · `.catch` · 부르는 고리가 받음 — 덱 · 풀이 판 · 로그인 전 문단 · 푸시 · 사진 올리기 · 공유).
  액션은 값으로 답하지만(ADR 0078) 부름 자체가 던지는 길이 남는다 — 망 끊김 · 배포 직후 화면이 든 액션 id 를 서버가 모름 · 액션 안의
  받지 않은 예외. 받지 않은 예외는 전환(`startTransition`)을 타고 오류 경계(`app/error.tsx`, 하나뿐)로 올라가, 머리글 아래가
  「화면을 불러오지 못했어요」로 바뀌고 쓰던 입력이 사라진다(`node_modules/next/dist/docs/01-app/01-getting-started/10-error-handling.md`).
- 설문의 임시 저장은 `void saveServiceSurvey(…).then(…)` 이라 부름이 던지면 「임시 저장하는 중…」에 멈췄다.
- 화면 안에서 한 칸을 못 읽은 자리(홈의 내 사주 · 소식 · 받은 요청 · 인연 기록 둘)는 회색 글씨에 `role` 이 없고 다시 읽을 단추가 없었다.
  `role="alert"` 는 마흔아홉 자리에 꾸밈이 열여덟 가지였다.
- 뼈대(`loading.tsx`) 없는 동적 화면(`/me/people/[personId]`, ADR 0116 이 일부러 안 둔 자리)으로 가는 링크는 누른 뒤 서버가 다 그릴 때까지
  반응이 없었다. `useLinkStatus` 를 쓰는 곳은 0 이었다.

## 정한 것

1. **클라이언트의 액션 부름은 `actionAnswer(부름)` 을 지난다**(`app/ui/action-answer.ts`). 던지면 `{ ok: false, message }` 로 접고 문장은
   하나다 — 「처리하지 못했어요. 다시 시도해 주세요.」 실패 모양이 다른 액션(`kind: 'failed'`)은 부르는 쪽이 모양을 지어 넘긴다. Next 의 이동
   (`redirect()` 가 부름에서 던지는 표지)은 받지 않고 다시 던진다(`unstable_rethrow`) — 가입 · 운영 2단계 인증이 그 길로 옮긴다. 받은 원문은
   사용자에게 내지 않는다. 이미 제 문장으로 받는 자리(`try` · `.catch`, 예: 덱의 지나치기)는 그대로 둔다.
2. **잠금** — `app/action-calls.boundary.test.ts` 가 `'use client'` 파일이 `'use server'` 파일에서 들여온 이름을 부르는 자리를 다 훑어, 감쌌거나
   같은 함수의 `try … catch` 안이거나 `.catch(…)` 가 붙었는지 본다. 이번에 스물일곱을 감쌌고, 남은 여섯(다른 작업이 맡은 파일 — 채팅 보내기 · 발견 참여 · 프로필 둘 · 사진 옮기기 · 지우기)은
   목록으로 들고 줄어들기만 한다(G-95).
3. **화면 안 실패 줄은 `FailureLine` 하나다**(`app/ui/failure-line.tsx`) — 붉은 글씨(`FAILURE_TEXT`) · `role="alert"` · 읽기 실패의 자리에는
   「다시 시도하기」(`router.refresh()` — 쓰던 입력과 스크롤을 두고 그 화면을 서버에서 다시 받는다). 누름이 실패한 줄에는 단추를 안 단다 —
   다시 누를 단추가 그 폼에 있다.
4. **뼈대 없는 화면으로 가는 링크는 누른 것을 보인다**(`app/ui/link-pending.tsx`, Next `useLinkStatus`). 늘 그려 두고 투명도만 바꿔 자리가
   안 밀리고, 빠른 이동에서 깜박이지 않게 조금 늦게 선다. 단추면 도는 고리, 카드 전체가 링크면 카드 테.

## 하지 않은 것

- `role="alert"` 마흔아홉 자리를 한 번에 `FailureLine` 으로 갈지 않았다 — 이번에 고친 자리만 썼다(G-95).
- 세션이 끝나 문이 이름 없이 막은 문장(`app/db-error.ts` 의 「다시 로그인한 뒤 시도해 주세요」)에 로그인으로 가는 길을 달지 않았다(G-95).
- 오류 경계를 화면마다 더 두지 않았다 — 부름을 받으면 경계까지 갈 일이 없다.
