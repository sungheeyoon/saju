# 앱을 안 보는 사람에게 새 메시지를 웹 푸시로 알린다 — 본문 없이, 켠 기기에만

> **운영자 결정 2026-10-08**(대화에서) — 「앱을 보고 있지 않은 사용자에게 새 메시지를 알려주는 경로를 하나 완성한다. 제공자는
> 최신 공식 문서·비용·모바일 지원·설정 난도를 조사해 선정하라. 잠금 화면 등에 메시지 본문이나 민감정보를 기본 노출하지 마라.」
> 제공자 선정은 조율자에게 맡겼다(「알아서 선정」). G-26 의 첫 줄(「새 메시지 통보부터」)을 닫는다.

## 정한 것

- **제공자는 표준 웹 푸시(Web Push · VAPID)다.** 가입 · 계약 · 건당 요금이 없고, 브라우저 회사의 푸시 서비스(FCM · Mozilla ·
  Apple)가 나른다. 안드로이드 Chrome · 데스크톱 Chrome/Edge/Firefox/Safari 는 그대로, iOS/iPadOS 는 16.4 이상에서 **홈 화면에
  추가한 앱**으로 열었을 때만 된다. 서버는 `web-push`(npm)로 암호화해 보낸다. 견준 것과 근거 · 비용은 PR 본문(조사)이 든다.
- **켜는 것은 사람이다.** 설정의 「새 메시지 알림」 한 줄에서 누름(사용자 제스처)으로 브라우저 권한을 묻고, 받으면 이 기기의 구독을
  서버에 남긴다. 끄면 이 기기의 구독을 지우고 브라우저 구독도 푼다. 권한을 거부한 브라우저에는 「브라우저 설정에서 허용해야 한다」는
  한 줄만 선다. **기본은 꺼짐**이다. 구독은 기기마다 하나이고 계정에 매인다.
- **로그아웃 · 계정 전환** — 로그아웃은 이 기기의 구독을 서버에서 먼저 지운다. 다른 계정이 같은 브라우저에서 켜면 그 endpoint 는 새
  계정으로 옮긴다(endpoint 는 유일하다). 그래서 한 기기가 앞 사람의 메시지 통보를 받지 않는다.
- **무엇을 보이나** — 제목은 서비스명, 본문은 「새 메시지가 왔어요」 한 줄(문구는 승인 대기). **닉네임 · 본문 · 사진을 싣지 않는다**
  — 페이로드에도 없다(푸시 서비스도 못 본다). 실은 것은 이동할 주소(`/me/chat/<matchId>`)와 묶음 표(`tag`)뿐이다.
- **누르면 그 방으로** — 서비스 워커가 열린 창이 있으면 그 창을 앞으로 가져와 그 주소로 옮기고, 없으면 새 창을 연다. 로그인이
  풀렸으면 로그인 뒤 그 방으로 돌아온다(지금의 `next` 흐름).
- **언제 보내나 — 중복 막기**
  - 메시지가 저장되면 DB 가 받는 사람의 켜진 구독마다 배달 줄(`push_delivery`)을 **방 하나에 대기 줄 하나**로 남긴다
    (같은 방의 다음 메시지는 대기 줄을 새로 만들지 않는다). 받는 사람이 그 메시지까지 이미 읽었으면 보내지 않는다.
  - 같은 방은 보낸 뒤 **60초** 안에 다시 보내지 않는다(그 사이 메시지는 다음 배달로 묶인다). 브라우저 쪽에서도 `tag` 가 방이라
    알림이 쌓이지 않고 바뀐다. 푸시 서비스에는 `Topic`(방)으로 아직 안 간 것을 바꾼다.
  - 앱이 그 방을 보이는 채로 열고 있으면 서비스 워커가 알림을 세우지 않는다(브라우저가 허락하는 곳에서).
- **어떻게 나르나 — 보내기와 다시 보내기**
  - 배달 줄이 생기면 DB 가 `pg_net` 으로 앱의 배달 문(`POST /api/push/dispatch`, 비밀 머리글)을 깨운다 — 커밋 뒤에 나간다.
  - 배달 문은 기한이 된 대기 줄을 잠그고(`for update skip locked`) 보낸다. 성공 → `sent_at`. `404`/`410` → 그 구독을 끈다.
    `429`/`5xx`/연결 실패 → `attempts` 를 올리고 뒤물림(1분 · 5분 · 30분)으로 다시 기한을 세운다. 다섯 번 실패하면 접는다.
  - **다시 보내기**는 `pg_cron` 이 1분마다 배달 문을 한 번 깨운다(Vercel Hobby 의 크론은 하루 한 번이라 DB 가 깨운다 —
    `supabase_wakes_the_recovery_not_vercel` 과 같은 길).
  - VAPID 열쇠 · 배달 비밀이 없으면 배달 문은 「설정 안 됨」을 남기고 줄을 그대로 둔다 — 잃지 않는다(어댑터).
- **보존** — 배달 줄은 보낸 · 접은 뒤 7일에 걷는다. 구독은 끄거나 · 로그아웃하거나 · 404/410 이거나 · 탈퇴 처분 때 지운다.

## 하지 않는 것

- 이메일 · 카카오 알림톡 · 앱 스토어 앱(G-26 의 나머지 줄로 남긴다).
- 요청 · 소식의 외부 통보 — 이번은 새 메시지 하나다.
- 잠금 화면 미리보기를 켜는 설정 — 필요하면 별도 결정이다.

## 치르는 값

- iOS 는 홈 화면에 추가해야 받는다 — 그 안내 문구가 화면에 든다(승인 대기).
- 새로 받는 개인정보가 하나 는다 — 기기의 푸시 endpoint 와 열쇠. 처리방침(`/privacy`)에 한 줄이 들어가야 운영에 켤 수 있다
  (문구 · 고지 판 승인 대기, 간극 대장).
- 운영에 켜려면 사람이 VAPID 열쇠 · 배달 비밀을 Vercel 과 Supabase(Vault)에 넣어야 한다 — PR 본문의 설정 목록.
