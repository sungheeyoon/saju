# 화면은 부드러움 한 벌을 입고, 메뉴는 홈 · 매칭 · 풀이 · 채팅 넷이며, 서비스 이름은 「점점」이다

> 후속 결정(일부): ADR 0126 — 메뉴(2)는 탭 넷 홈 · 궁합 · 인연 · 채팅이 됐다
> 후속 결정(일부): ADR 0149 — 운영자 결정 4 와 「정한 것」 6 의 이름은 「만날지도」(MannalMap)가 됐고(상수 한 곳은 그대로), 로고는 「궤도 지도」로 다시 그렸다

2026-09-24 에 운영자가 로그인한 홈을 다시 짜는 라운드를 열었다. 실제 화면을 건드리지 않는 비교 자리(`/me/home-preview`)에
시안을 세 차례 세웠다 — 1차는 기존 부품의 재배치 아홉, 2차는 디자이너 역할을 하나씩 맡은 아홉, 3 · 4차는 고른 두 스타일의 매칭 ·
풀이 · 채팅과 그 둘을 섞은 것. 운영자가 **라이프스타일 — 부드러움**을 채택하고 **관계 지도 — 나를 중심으로**의 지도를 그 안에
들였다. 이 ADR 은 그 결정과 실제 화면으로 옮긴 모양을 적는다. 비교 자리는 옮긴 뒤 지웠다.

## 운영자 결정 (2026-09-24)

1. 채택: **부드러움**(크림 종이 바탕 · 오행 파스텔 면 · 다섯 상징 · 먹색 주 단추 · 고운돋움 제목). 모든 화면을 이 느낌으로 옮기고
   기능도 실제로 돈다.
2. 관계 지도를 부드러움으로 다시 그려 **홈**(최근 풀이 인용 자리)과 **매칭**(「내 궤도로 다가오는 인연」)에 넣는다.
3. 메뉴는 **홈 · 매칭 · 풀이 · 채팅**. 테스트 때 세운 「서비스 설문」 같은 탭은 메뉴에서 빠져도 된다. 앱 경로 변경은 허용.
4. 서비스 이름은 **「점점」** — 점으로 만든 관계 지도와 맞고 점술의 「점」을 은근히 품는다. 로고를 이름 옆에 둔다.

## 정한 것

**1. 주소는 `/me` 그대로, 이름만 「홈」이다.** 경로 변경은 허용됐지만 관문(`proxy.ts` · `src/lib/consent/gate.ts`)과 경고 안내
(`app/me/layout.tsx`, ADR 0108)와 로그인 복귀 경로와 홈이 여는 참여 문(`DiscoveryDoor`, ADR 0070)이 전부 `/me` 를 기준으로 선다.
`/home` 으로 옮기면 그 넷을 한꺼번에 다시 세워야 하고 사용자가 얻는 것은 주소창의 글자뿐이다.

**2. 메뉴(PRD §7.4.1).** 탭 넷 + 머리글의 풀이권 · 종(소식) · 톱니(프로필 · 계정 관리 · 서비스 설문 · 로그아웃). 옛 「사주·궁합」 ·
「사람」은 홈 안의 길이 됐다. 「소식」을 탭으로 둔 2026-09-23 의 판단(답해야 할 일이 사는 화면)은 뒤집혔다 — 종의 수와 홈의 안 읽은
소식 띠가 그 일을 든다. 관문이 되돌리는 자리(`/signup` · `/closed`)에서는 탭 · 종 · 풀이권을 안 세운다(누르면 되돌아오는 죽은 길이다).

**3. 디자인 체계는 토큰 한 벌이다.** 기존 토큰 이름(`--accent` 등)은 그대로 두고 값을 부드러움으로 옮겼다 — `--accent` 는 먹색이라
`bg-accent` 단추가 곧 주 단추다. 오행 다섯은 진한 글자색 · 파스텔 면 · 중간색의 세 짝과 다크 짝을 가진다. 옮기며 대비를 고쳤다 —
보조 글자 4.0:1 → 5.0:1 이상, 다크의 오행 글자 3:1대 → 8.5:1 이상. 부품은 `app/ui/`(단추 세 단 · 아이콘 · 오행 상징 · 로고 ·
판과 글자 크기)에 있고, 화면은 새 색(hex)을 지어내지 않는다. 모르는 기운의 색은 `unknown` 이다 — `none` 이면 Tailwind 의
`fill-none` · `border-none` 이 그 색이 된다.

**4. 관계 지도는 판정이 아니라 기록이다.** 홈: 가운데 나, 안쪽 궤도에 풀이나 궁합을 본 사람, 바깥에 저장만 한 사람. 선은 이미 본
궁합에만 긋고 점수를 붙인다. 매칭: 안쪽에 내 오행 다섯(여덟 글자의 20% 미만은 빈 원 — 후보를 고르는 문턱과 같다), 바깥에 오늘의
후보, 지금 후보가 채워 주는 자리에 선. 둘 다 없는 관계를 긋지 않고 좋고 나쁨을 말하지 않는다. 지도의 링크는 JavaScript 없이도
돈다.

**5. 모르는 값은 지어내지 않는다.** 채팅 방 문은 상대의 오행을 주지 않아 상대 말풍선은 중립 색이다. 풀이 목록의 인연 궁합 상대 쪽
표지도 회색이다. 문에 칸을 더하는 일은 간극 대장 G-59 로 남겼다.

**6. 이름은 상수 한 곳이다**(`src/lib/brand`). 화면 제목은 이름만 적고 뿌리 레이아웃의 틀이 「— 점점」을 붙인다. 기능 이름으로서의
「만세력」은 그대로다. 약관 · 처리방침 본문과 경고 이메일의 이름은 G-58 에 남는다.

## 바뀐 것 (PRD)

§3.0 홈 · 화면 표 · §4.2 풀이(책장 · 에세이) · §4.7 설문(톱니) · §6.1.1 매칭(상세 창 없음 · 두 열 · 지나친 인연은 두 번째 보기) ·
§7.1 채팅(두 칸 · 「⋯」에서 신고 · 차단 · 중립 색) · §7.4.1 메뉴.

## 치르는 값

- 폰에서 홈의 관계 지도가 한 화면쯤 차고, 지도와 타일이 같은 사람을 두 번 보인다.
- 매칭의 상세 창을 걷었다 — 모든 것이 카드 위에 서서 카드가 길다.
- 신고가 「⋯」 → 고르기 → 사유로 한 번 늘었다(메시지마다의 작은 「신고」 글자는 44px 를 못 채웠다).

## 추기 — 옮기며 잃은 것을 되찾았다 (2026-09-24 밤)

운영자가 옮긴 화면을 보고 「시안 때보다 쇠퇴했다」고 짚었다. 지운 비교 자리를 git 에서 되살려 원본과 나란히 놓고 넷을 고쳤다.

- **홈 관계 지도** — 궤도에 깐 색 띠 · 가운데 번지는 색 · 사람 원의 상징 딱지 · 휜 두 줄 선이 원본의 명료함을 가렸다. 판 · 궤도 · 선을
  중립 색으로 되돌리고 오행 파스텔은 사람 원에만 둔다. 내 사주 카드는 닉네임 · 한 줄 평 → 출생 정보 → 여덟 글자 → 단추 차례.
- **매칭** — 사진 비율(폰 6:5 · 넓은 화면 4:5)과 점수의 자리(사진 위 이름 → 큰 수 · 판정)를 원본대로, 카드 아래 글은 줄였다. 지도는
  **거리 = 관계, 각도 = 채우는 오행, 색 = 채워지는 자리에만**으로 다시 세웠다.
- **풀이** — 넓은 화면은 왼쪽 책장 · 오른쪽 글의 두 칸(레이아웃이 목록을 든다). 주소는 글마다 그대로다.
- **채팅** — 「5. 모르는 값은 지어내지 않는다」를 지키면서 두 일간 색을 되찾았다. 함께 보는 궁합이 이미 서로에게 연 동의 시점 사본
  (`my_match_scope`)에 두 사람의 여덟 글자가 있다 — 그 두 일간만 브라우저로 보낸다. 결과가 닫힌 방은 중립 색이다. G-59 는 풀이 책장만 남는다.
- **풀이 책장** — 채팅과 같은 길로 닫았다(G-59, `20261022090000`). 목록 문(`my_readings`)이 줄마다 표지의 두 일간을 준다 —
  내가 주인인 글은 그 사람의 지금 명식, 인연 궁합은 같은 동의 시점 사본의 두 일간(앞이 나)이다. 책장은 명식을 다시 읽지 않고,
  인연 궁합의 상대 쪽 반도 색을 입는다.

## 추기 — 본문 웹 글꼴(Pretendard)을 뺐다 (2026-09-30)

운영자 결정(2026-09-30): 「그 글꼴을 어디에 쓰는데 싣는 거야, 싣지 마 그냥」. 2026-08-26(`7577082`)부터 본문 · 단추 · 보조가
입던 Pretendard 가변 글꼴(`pretendard` 의존성, `app/globals.css` 의 동적 조각 `@import`)을 걷었다. 본문은 **기기의 시스템 서체**다 —
`--font-system` 한 벌(`-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", system-ui,
sans-serif`)을 `--font-sans` · `--font-rounded` 의 대체 · `body` · `.glyph` 가 함께 읽는다. Pretendard 전용 글자 모양(`ss05` · `ss06`)도
뺐다. **제목의 고운돋움(`next/font`)은 그대로다.**

- **전송량** — 로컬 dev 로 잰 첫 방문의 Pretendard 조각: 첫 화면(`/`) 8개 207,724B, 만세력(`/saju`) 6개 156,732B → 0.
- **폰 한 화면**(390×664, 로컬 macOS · 애플 산돌고딕) — 나 탭 저장한 사람 제목 아랫선 564.8 → 563.8px(끝 584), 인연 탭 카드 띠
  없음 267 · 띠 있음 201px(같음), 궁합 탭 고르는 칸 89 · 한 줄 1247px(같음). 여백은 고치지 않았다. CI 리눅스(대체 서체)는 이 PR 의
  `full-ci` 차선이 같은 시험으로 잰다.
- CSP 의 `font-src 'self' data:` 는 그대로다 — 고운돋움을 `next/font` 가 같은 곳에서 준다.
- 공유 그림 굽는 도구(`scripts/brand-share-images.mjs`)의 한 줄 소개도 Noto Sans KR 600 으로 옮겼다. 이미 구운 v3 그림은 그대로다.

## 추기 — 승인한 모양을 부품으로 옮겼다 (2026-10-08)

#543(궁합 고르는 판, 운영자 승인)이 판 · 고르는 칸 · 요약 한 줄을 화면에 글자로 다시 적었다. 모양은 그대로 두고 부품을 더했다 —
`CARD_FRAME`(카드의 테만, 속을 띠로 나누는 판) · `ROW_LINE`(카드 사이의 선 한 줄) · `SEGMENTS` · `SEGMENT` · `SEGMENT_ON`
(입력 방법을 고르는 칸 — 화면을 바꾸는 알약 탭과 갈라 모서리가 조금 각지고, 고른 칸은 덧붙이지 않는 한 벌). 판 제목은 이름 단
(`TYPE_NAME`)으로 둥근 서체가 돌아왔다. 같은 판 맨 아래 붙어 테가 두 줄로 겹치던 같은 사람 확인 · 실패 알림은 사이 선택 띠 안으로 옮겼다.

## 추기 — 화면의 기둥 폭 (2026-10-09)

`.app-shell` 안에서 본문을 가운데로 묶는 폭은 `app/ui/surfaces.ts` 의 `COLUMN_*` 가 든다 — 폼 한 장은 `COLUMN_FORM`, 저장한 사람
목록 · 상세는 `COLUMN_PEOPLE`. 다른 화면의 폭을 합치는 일은 G-83 에 남는다.
