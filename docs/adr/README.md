# 현재 결정 색인

영역마다 **지금 유효한 ADR 의 번호와 제목**만 든다. 결정의 내용은 옮겨 적지 않는다 — 번호를 따라 그 문서를 읽는다.
한 ADR 이 두 영역에 걸치면 두 곳에 선다.

- **통째로 대체된 ADR 은 여기 없다.** 그 머리에 `> 후속 결정: ADR NNNN — …` 줄이 있고, 그 줄이 가리키는 ADR 을 읽는다.
- **일부만 대체된 ADR 은 여기 선다.** 그 머리의 `> 후속 결정(일부): ADR NNNN — …` 줄이 어느 대목이 어디로 갔는지 말한다 — 읽기 전에 머리부터 본다.
- 새 ADR 은 여기에 줄을 더하고, 대체하는 ADR 의 머리에 후속 결정 줄을 단다(`docs/agents/domain.md` 「Writing an ADR」).
  색인이 가리키는 번호가 있는지, 통째로 대체된 ADR 이 서지 않는지, 나머지가 빠짐없이 서는지는 `scripts/code-rules.test.ts` 가 잰다.

## 첫 화면 · 로그인 전 결과

- ADR 0163 — 품질 검사에 걸린 풀이도 내보내고, 걸린 검사를 시도마다 적는다 — 막는 것은 셋뿐이다

- ADR 0153 — 바뀐 줄이 전부 주석인 코드 파일은 CI 에서 정책으로 센다
- ADR 0154 — 정책 파일만 바꾼 main 푸시는 `policy` 차선만 돈다
- ADR 0159 — 문구만 바뀐 파일은 core 에 옛 글자를 찾는 시험의 차선만 더하고, 문구 · 문서뿐인 묶음은 main 의 전체 CI 를 기다리지 않고 배포한다

## 디자인 체계 · 화면 문구

- ADR 0026 — 사용자에게 보여줄 이름을 먼저 정하고, 내부어는 화면 밖에 둔다
- ADR 0027 — 한 사실에는 한 표기 — 그리고 그 표기를 어디에 적을지도 규칙이다
- ADR 0109 — 화면은 부드러움 한 벌을 입고, 메뉴는 홈 · 매칭 · 풀이 · 채팅 넷이며, 서비스 이름은 「점점」이다
- ADR 0135 — 화면 말투는 해요체가 기본이다
- ADR 0149 — 서비스 이름은 「만날지도」(MannalMap)이고, 앱 밖 화면의 바닥글이 사업자 정보를 든다
- ADR 0160 — 저장은 주 단추 한 벌이고, 못 누르는 주 단추는 가라앉으며, 되돌릴 수 있는 켜고 끄기는 같은 무게다
- ADR 0161 — 가운데 기둥은 46rem 하나이고, 첫 제목 위 여백은 넓은 화면에서 48px 이다
- ADR 0164 — 화면은 던진 액션 부름을 받아 실패 줄로 세우고, 화면 안의 못 읽은 칸은 붉은 줄 하나로 선다

## 코드 · 시험 · 문서 · 위임 규칙

- ADR 0047 — 엔진은 모델에게 말을 걸지 않는다
- ADR 0076 — 무르게 하는 일은 바뀐 것의 이름을 고른다
- ADR 0078 — 읽는 문은 실패를 말하고, 모양은 생성 타입이 주장한다
- ADR 0164 — 화면은 던진 액션 부름을 받아 실패 줄로 세우고, 화면 안의 못 읽은 칸은 붉은 줄 하나로 선다
- ADR 0079 — 부재 단언은 반증할 수 있어야 한다
- ADR 0080 — `await` 에 붙은 판단은 시험이 못 부른다
- ADR 0081 — 누른 것은 끝난 것이 아니다
- ADR 0084 — 모양도 단언한다 — 행동만 재던 자리에
- ADR 0085 — 층은 문서가 아니라 시험과 린트가 지킨다
- ADR 0086 — 코드 규칙은 잰 값에서 나오고 린트와 시험이 든다
- ADR 0087 — 시험 지도는 무엇을 돌리는지와 vitest 가 어디서 끝나는지를 말한다
- ADR 0088 — 용어집은 주제로 묶이고 제 코드 이름을 든다
- ADR 0089 — PRD 는 지금 모양만 들고, 틈은 대장 한 장이 든다
- ADR 0090 — 위임 규약은 저장소의 문서 한 장과 도구 설정이 함께 들고, 세션 메모는 저장소로 옮겨졌다
- ADR 0093 — 등급 3 의 잠금은 공식 운영에 들어간 뒤에 켠다
- ADR 0140 — 일은 역할 문서 한 장에서 시작하고, 그 문서의 넷째 칸을 고치며 끝난다
- ADR 0145 — 역할 문서는 원본으로 가는 길잡이(Router)다 — 규칙을 줄여 다시 말하지 않는다
- ADR 0146 — 라운드 끝의 돌아보기는 `/retro` 가 한다 — 저장소만의 절차를 따로 두지 않는다
- ADR 0147 — 읽기량의 천장은 여유를 둔 눈금이고, 손대기 전에는 그 역할의 일 대부분이 쓰는 것만 읽는다
- ADR 0162 — 역할은 공통 규칙과 그 일의 파일을 읽고, 읽기량은 보수적 예상치로 센다 — 화면 문서는 무리마다 한 파일이다
- ADR 0150 — 사람과 말하는 세션은 일이 하나면 역할을 바꿔 직접 하고, force push 는 어느 가지에도 하지 않는다
- ADR 0151 — 바닥글은 사업자 정보를 싣지 않는다
- ADR 0152 — 운영 주소는 한 줄에만 살고, 공개 저장소는 사람을 가리키는 값을 들지 않으며, 지시받은 일은 PR 까지 묻지 않고 간다
