# 사주의 생년월일은 신원 정보가 아니다

이 제품에서는 생년월일이 곧 나이이고, 매칭·채팅에는 연령 하드 제외가 필요하다. 그러나
`Person.birthDate` 를 그 근거로 쓸 수 없다 — 사용자가 언제든 고칠 수 있고(ADR 0004),
애초에 **남의 사주를 등록하는 것이 정상 사용**이라 어느 Person 이 누구인지 시스템이
알지 못한다.

```
Person.birthDate       사주 계산용. 사용자 입력이고 revision 이 쌓인다
UserAgeVerification    매칭 참여 자격용. 별개의 값이고 별개의 절차로 얻는다
```

카카오의 연령대·생일은 별도 동의가 필요하고 성년 확인으로는 부족하므로, 공개 출시
전에 본인확인 방식을 따로 정한다. 둘이 충돌하면(본인확인 값과 입력한 생년월일이 다르면)
공개 매칭 참여를 중단하고 재확인을 요구한다.

출생**시각**은 외부에서 확인할 방법이 없다. 사용자 입력으로 두되 변경 이력과 요청
무효화 규칙으로 관리한다(ADR 0004).

## MVP

본인확인이 없는 동안에는 **연령 필터를 없애는 대신 공개 매칭을 열지 않는다.** 확인된
성인 테스터를 초대하는 제한된 테스트만 한다. 필터를 끄고 문을 여는 것과, 문을 안 열고
필터를 미루는 것은 다르다.
