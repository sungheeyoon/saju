# 운영 화면도 앱에 서고, 같은 두 번째 요소 · 같은 DB 의 문을 지나며, PortOne 확인이 드는 준비 취소만 앱에 없다

> **결정 대기** — 운영자 지시(2026-10-30 「모든 페이지 남김없이 구현」)로 지었고, 권한 표면이라 머지 전에 운영자가 표로 답한다
> (`docs/agents/delegation/decisions.md` 「누가 무엇을 볼 수 있는가」 · 「실패했을 때 열리는가 닫히는가」).

앱 첫 라운드 인계(`docs/notes/2026-10-30-expo-app-round.md`)는 `/ops/*` 를 옮기지 않는다고 적었다. 2차 묶음의 지시가 그것을 뒤집었다.
ADR 0209 · 0103 · 0105 · 0191 의 막음은 그대로이고, 이 결정은 그 막음을 앱 세션에서 어떻게 지나는가만 정한다.

## 잰 것 (2026-10-30)

- 운영 화면의 판정과 쓰기는 전부 DB 함수이고 `authenticated` 에 열려 있다. 서버에서만 되는 것은 준비 취소의 PortOne 조회 하나다
  (`app/ops/orders/portone-cancellations.ts` — 서버 열쇠).
- `/ops/mfa` 의 등록 · 확인은 Supabase Auth 의 요소 API 라 앱 세션으로 그대로 불린다.

## 정한 것

- **앱의 머리는 웹과 같은 차례다**(`mobile/src/ops/denial.ts`). 세션이 없으면 입력 화면으로, aal2 면 문을 부르고, aal1 이고 확인을 마친 TOTP 가
  있으면 `/ops/mfa` 로, 없거나 요소를 못 읽으면 운영자가 아닌 사람과 같은 「없는 화면」과 거절 한 줄이다. 문이 `42501` 이면 역시 없는 화면이다.
- **앱의 판정은 표시일 뿐이다.** 막는 것은 `is_operator()` 와 그 aal2 판정(마이그레이션 `20270102090000`)이다. 앱이 aal2 를 먼저 보는 까닭은
  자료가 나오고 접속기록에 「읽음」이 서기 전에 멈추려는 것이다. 그 마이그레이션이 오르기 전에는 앱의 이 막음이 유일한 aal2 막음이다 — 웹과
  같은 창이고, 이 창에서 세션 토큰을 직접 쓰는 길은 웹에서도 앱에서도 열려 있다(ADR 0209 「차례」).
- **실패는 닫힌다.** 세션 · 수준 · 요소를 못 읽거나 머리가 던지면 없는 화면이고, 운영자의 문 실패는 실패 줄이다. 어느 쪽도 자료를 세우지 않는다.
- **진입 길을 만들지 않는다.** 메뉴 · 홈에 줄이 없고 `mannalmap://ops/today` 같은 주소로만 간다. 운영자에게만 길을 보이려면 「나는 운영자인가」를
  여는 문이 필요하고, 그것은 ADR 0061 이 안 열기로 한 문이다. 운영 머리는 문이 답한 뒤에만 선다.
- **준비 취소는 앱에 없다.** `operator_release_reading_refund` 를 앱에서 부르면 PortOne 확인을 건너뛰어, 돈은 나갔는데 회차가 돌아올 수 있다(ADR 0184).
  단추도 문 부름도 없고 웹에서 한다. 새 `app/api/**` 문은 이 결정에서 만들지 않는다.
- **판정과 라벨은 함께 쓴다.** 순수한 것을 `app/ops/` 에서 `src/lib/ops/` 로 옮겼다. 웹의 글자와 동작은 그대로다.

## 안 고른 것

- **앱에서 운영 화면을 빼고 웹을 연다** — 2차 지시(「모든 페이지 남김없이」)와 어긋난다.
- **`app/api/**` 문으로 준비 취소를 앱에 연다** — 운영자가 콘솔을 함께 보는 동작이라 폰에서의 급함이 작고, 환불 쓰기 문이 하나 는다.
- **숨은 진입 동작(로고 길게 누르기 등)** — 숨긴 길은 막음이 아니고, 찾은 사람에게 「여기 뭔가 있다」를 알린다.

## 값

- 운영 쓰기가 폰에서도 된다 — 이용 정지 · 무상 지급 · 환불 준비 · 확정의 손이 하나 는다. 막음은 같고 확인창도 같다.
- 앱에서 코드를 확인하면 Auth 가 그 사람의 다른 세션을 끊는다(ADR 0209) — 웹의 운영 세션도 끊긴다.
- 앱의 막음이 웹과 어긋나지 않는지는 `scripts/mobile-ops-copy.test.ts` 가 글자로만 잰다 — 앱 코드를 돌리는 시험이 아니다.
