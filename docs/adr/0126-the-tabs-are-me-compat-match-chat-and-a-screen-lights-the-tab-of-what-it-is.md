# 탭은 나 · 궁합 · 인연 · 채팅이고, 화면은 어디서 열렸나가 아니라 무엇인가로 탭을 켠다

> **운영자 결정 2026-09-29** — 흐름 시안 여럿 중 **g** 를 골랐다(조율자 세션). 「화면 · 탭은 e(나 · 궁합 · 인연 · 채팅), 흐름의
> 기조는 d」, 「주소는 지금 그대로 둔다 — 탭 이름과 어느 화면에서 어느 탭이 켜지나만 바꾼다」, 탭 소속은 **나** = `/me` ·
> `/me/people/*` · `/me/readings/*`, **궁합** = `/compat` · `/me/compat`, **인연** = `/me/matching` · `/me/match/*`, **채팅** =
> `/me/chat`. 종(`/me/requests`)은 그대로. 이 ADR 은 ADR 0109 의 「2. 메뉴」를 잇는다 — 그 밖의 0109(부드러움 · 이름 「점점」 ·
> 관계 지도)는 그대로다.

## 잰 것 (2026-09-29, `app/site-header.tsx`)

- 탭은 홈(`/me`) · 매칭(`/me/matching`) · 풀이(`/me/readings`) · 채팅(`/me/chat`)이었다(ADR 0109).
- 홈은 `/me` · `/me/people/*` · `/compat` · `/me/compat` · 로그인 뒤의 `/` 에서 켜졌다. 풀이는 `/me/readings/*` 와 **인연 궁합
  `/me/match/*`** 에서 켜졌다 — 인연 궁합은 매칭이 아니라 풀이였다. 내 사주풀이(`/me/readings/self`)도 풀이였다.
- 그래서 한 궁합이 **어느 입구로 들어왔나에 따라** 다른 곳처럼 보일 틈은 없었지만, 궁합을 고르는 자리(`/compat`)와 그 결과가
  「홈」의 불 아래 있었고, 동의로 열린 궁합은 그것을 만든 매칭과 떨어져 「풀이」에 있었다.
- 나 탭 홈(`/me`)에서 책장(`/me/readings`) 자체로 가는 링크는 **없었다** — 내 사주 카드는 `/me/readings/self`, 사람 타일은
  `/me/readings/<id>` 로 곧장 간다. 넓은 화면은 글을 열면 책장이 옆에 서지만 폰은 책장 목록에 닿는 길이 탭뿐이었다.

## 정한 것

1. **탭 넷: 나(`/me`) · 궁합(`/compat`) · 인연(`/me/matching`) · 채팅(`/me/chat`).** 궁합 탭의 첫 화면은 두 사람을 고르는 지금의
   `/compat` 그대로다. 아이콘은 `app/ui/icons.tsx` 의 기존 넷 — `home` · `heart` · `people` · `chat`(새 그림 없음).
2. **화면은 무엇인가로 탭을 켠다.** 한 사람의 것(`/me/people/*`, 책장 · 내 사주풀이 · 다른 사람 사주풀이 `/me/readings/*`,
   로그인 뒤의 `/`)은 나, 두 사람을 고른 궁합(`/compat` · `/me/compat`)은 궁합, 동의로 열린 궁합(`/me/match/*`)은 인연이다.
   책장에서 궁합을 열면 불이 나에서 궁합으로 옮는다 — 글이 무엇인지와 탭이 같은 말을 한다. 한 화면에서 켜지는 탭은 넷 중
   하나뿐이다(`app/site-header.test.ts`).
3. **「풀이」 탭은 없다. 책장은 주소 그대로 나 탭 안의 길이다.** 나 탭 홈의 링크 묶음(이름을 「더 해 보기」에서 **바로가기**로
   바꿨다)에 **만든 풀이 다시 보기** 하나를 더했다(기존 부품). 책장 화면의 제목 「만든 풀이」는 그대로다. ADR 0033 의 「만든 글이 모이는 자리」는 그대로 선다 — 탭이 아닐 뿐이다.
4. **주소 · 관문 · 로그인 복귀는 그대로다.** `/compat` 은 이미 proxy 의 matcher 안이라 탭이 되어도 관문이 달라지지 않는다.

## 치르는 값

- 책장에 닿는 걸음이 폰에서 하나 늘었다(탭 → 홈 바로가기의 「만든 풀이 다시 보기」).
- `/compat` 에는 탭 뼈대(`loading.tsx`, ADR 0116)가 없다 — 다른 셋과 달리 누른 뒤 서버 응답까지 지금 화면에 머문다. 필요하면 따로 단다.
  → 닫힘(2026-09-29): 달았다(ADR 0129).
- 탭 이름이 바뀌며 화면 글자 넷이 옛 탭 이름(「매칭에서」 · 「홈에서」)을 말하게 됐다 — 같은 PR 에서 고쳤다. 문구는 운영자가
  확정했다(2026-09-29): 「오늘의 인연 만나기」 · 「내 사주를 불러오지 못했어요. 나 탭에 내 사주 카드가 보이는지 확인하고 다시 시도해
  주세요.」 · 「내 사주와 저장한 사람의 풀이는 나 탭에서, 두 사람의 궁합은 궁합 탭에서 시작할 수 있습니다.」 · 「바로가기」 · 「만든 풀이 다시 보기」.

## 2026-09-29 e+ — 목록은 나를 안 켠다

책장 목록 `/me/readings` 는 「풀이 보관함」이 되어 **어느 탭도 안 켠다**(ADR 0133). 그 안에서 연 한 사람 풀이는 나
그대로다. 홈 바로가기의 글자도 「풀이 보관함」이다.
