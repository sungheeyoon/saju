# 위임 규약은 저장소의 문서 한 장과 도구 설정이 함께 들고, 세션 메모는 저장소로 옮겨졌다

## 무엇이 흩어져 있었나

2026-09-22 진단이 「에이전트에게 맡기고 신임할 수 있는 상태」로 가는 정비를 일곱으로 세웠고
여섯이 끝났다(ADR 0085~0089 — 층 잠금 · 코드 규칙 · 시험 지도 · 용어집 재편 · PRD 와 간극 대장).
남은 일곱째가 **위임 규약**이었다. 그날 잰 값은 이렇다.

- 맡길 이슈의 모양이 없었다. `ready-for-agent` 딱지는 있는데(`docs/agents/triage-labels.md`)
  무엇이 채워져야 붙는지는 없었고, 이슈 틀도 PR 틀도 없었다. 구조 후보 라운드에서는 이슈의
  문장이 **연속 다섯 건** 반쯤 틀렸다(#88) — 그 문장을 그대로 믿고 고치면 엉뚱한 것을 지운다.
- 「끝났다」의 뜻이 사람 머릿속에 있었다. PR 마흔이 전부 squash 로 들었고 서른셋이 ADR 을
  같이 썼지만, 무엇을 돌렸고 무엇을 안 돌렸는지는 PR 마다 모양이 달랐다.
- 권한을 가르는 것이 없었다. `.claude/` 가 없고 설정은 사용자 전역의 「묻지 않는 모드」뿐이었다.
  main 머지가 곧 프로덕션 배포이고 `db push` 가 운영 DB 를 바꾸는데, 그것을 밟기 전에 묻는다는
  규칙은 세션 메모에만 있었다 — 2026-09-20 에 `--auto` 가 즉시 머지로 떨어져 검사 전 배포가 한 번
  났다.
- **세션 메모 63벌, 약 500KB 가 저장소 밖에 있었다.** 엔진의 계산 판단, DB·인증 층의 교훈, RPC
  노출 경계, 검증 규율, 프롬프트 지도, 로컬 환경의 함정, 사용자가 준 지시(존댓말 · 한글 문구는
  표로 · 되돌리기를 선택지로 올리지 않는다). 다른 에이전트도 다른 세션도 못 봤고, 그중 일곱
  벌이 이미 없는 경로를 들고 있었다(`app/query.ts` · `app/me/layout.tsx` ·
  `src/lib/saju/evidence/prompt.ts` · `src/lib/matching/elementAxes.ts` …).
- 배포·마이그레이션 규약(앱 배포 ≠ DB 마이그레이션 · `db push` 를 따로 · 넓히고 나중에 좁힌다)도
  메모에만 있었다 — 간극 대장의 G-41.

## 정한 것

**`docs/agents/delegation.md` 한 장.** 다섯 절이다.

1. **맡길 이슈** — `ready-for-agent` 가 붙으려면 채워야 할 칸 일곱(무엇이 참이 되는가 · 어디를
   건드리나 · 무엇을 돌리나 · 끝났다고 말할 조건 · 권한 등급 · 결정이 필요한 자리 · 읽을 문서).
   틀은 `.github/ISSUE_TEMPLATE/ready-for-agent.md`.
2. **권한 등급** — 되돌릴 수 있는가로 다섯 등급(읽는다 · 로컬에서 고친다 · 되돌릴 수 있게 밖으로
   낸다 · 사람이 답한 뒤에 · 안 한다). 등급 3 과 4 의 명령은 `.claude/settings.json` 의 `ask`·`deny`
   와 **같은 표**다.
3. **끝났다는 것** — PR 이 드는 칸 여섯(무엇이 참이 되는가 · 잰 값 · 돌린 것 · 잠금이면 일부러
   어긴 것 · 문서 · 사람이 할 걸음). 틀은 `.github/pull_request_template.md`. 안 한 것은 안 했다고
   적는다(ADR 0079).
4. **일하는 법** — 세션 메모의 피드백을 재는 법 · 사용자와 · 저장소와 셋으로 옮겼다. 규칙이
   아니라 한 번씩 틀리고 나서 적은 것이다.
5. **로컬 환경의 함정** — 증상 → 원인 → 하는 일 표 열둘. runbook 과 test-map 에 없는 것만.

**배포·마이그레이션 규약은 runbook 에.** `docs/ops/runbook.md` 「배포」 절 머리에 「앱 배포 ≠ DB
마이그레이션」 · 「마이그레이션이 먼저, 앱이 나중」 · 「넓히고 나서 재고 좁힌다」 · 「올린 뒤 무엇을
보나」 넷을 뒀다. 접속값 절에는 `[SENSITIVE]` 자리표시자와 `db query --linked` 를 더했다. G-41 을
닫는다.

**세션 메모는 저장소로 옮겼다.** 63벌을 셋으로 갈랐다.

- **규약·절차·결정이 된 것** — 이 문서 · runbook · 이미 있는 ADR 이 든다. 옮기지 않았다(같은 것을
  두 자리에 적으면 하나가 낡는다). 어디로 갔는지는 `docs/notes/README.md` 의 표가 든다.
- **판단 기록 열셋** — `docs/notes/` 에 그날의 사정째로. 머리말이 「세션 기록이다 · 요구사항이
  아니다 · 코드와 어긋나면 코드가 맞다 · 지금은 어디를 보라 · 낡은 경로」를 든다. 공개 저장소라
  상대방의 이름과 계정 조각은 지우고 옮겼다.
- **낡아서 버린 것** — 끝난 티켓 목록, 옛 PRD 의 단계 번호로 진행을 재던 것, 지운 가지의 안내.

**대장의 줄 셋을 움직였다.** G-40 · G-41 은 닫혀 changelog 로 갔고, G-02(`ensure_rls`)는 메모에만
있던 사용자 결정(2026-09-22, **운영에서 걷는다** — 저장소로 들이면 로컬·CI 에서도 트리거가 먼저
고쳐 새 RLS 잠금이 영영 초록이 된다)을 옮겨 적어 `결정 대기` 에서 `정했다` 가 됐다.

**시험이 든다** — `scripts/code-rules.test.ts`.

- 권한 표의 `Bash(…)` 규칙과 `.claude/settings.json` 의 `ask`·`deny` 가 **정확히 같은 집합**이다
  (등급 3 ↔ `ask`, 등급 4 ↔ `deny`).
- 이슈 틀과 PR 틀의 `##` 칸이 전부 위임 규약 문서에 있고, 이슈 틀의 딱지는 triage 표에 있는
  이름이다.
- `docs/notes/README.md` 의 차례가 그 폴더의 파일 전부를 든다.
- 위임 규약 문서의 뿌리 경로가 실재한다(ADR 0087 의 입구 문서 시험이 `docs/agents/*.md` 를 다
  읽으므로 저절로).

## 잠그지 않은 것

- **`deny` 가 실제로 막는지 밟아 보지 않았다.** 다른 세션을 띄워 force push 를 시켜 보는 일이라
  이 작업의 사정권 밖이었다. 그래서 문서는 표를 「도구가 지키는 담」이 아니라 **에이전트가 읽는
  규약**이라 부른다. 규칙 문법은 명령 앞부분만 보므로 `cd x && supabase db push` 는 지나간다 —
  적어 두었다.
- **노트의 경로는 재지 않는다.** 기록이라 낡는 것이 맞다. 머리말의 「낡은 경로」는 옮기던 날
  기계적으로 찾은 것(백틱 안의 뿌리 경로가 실재하는가)이고, 이름만 적힌 식별자(`revisionsFor`
  같은 것)는 안 봤다.
- **PR 틀을 채웠는가는 아무도 안 잰다.** 틀은 칸을 세울 뿐이다.
- **메모리 쪽.** 옮긴 뒤 에이전트의 메모리 파일은 저장소를 가리키는 한 줄로 줄였다. 다음 세션이
  같은 것을 다시 메모리에 적으면 두 벌이 된다 — 문서 끝의 「새 기억은 저장소에 적는다」가 그
  규칙이고, 재는 것은 없다.

## 앞선 결정과의 관계

- **ADR 0082** — `--auto` 머지가 gate 를 기다리게 된 것이 등급 2 의 근거다.
- **ADR 0085 · 0086 · 0087** — 같은 결. 문서가 다른 파일을 가리키면 시험이 그 가리킴을 든다.
  「막는다」는 일부러 어겨 증명한다는 규율을 DoD 의 칸으로 올렸다.
- **ADR 0079** — 「안 돌린 것을 통과로 적지 않는다」가 PR 틀의 첫 규칙이다.
- **ADR 0084 · 0089** — `ensure_rls` 의 결정이 G-02 에 옮겨 적혔다. 대장의 줄을 움직이는 첫 사례다.
- **ADR 0042 · 0071** — 「순서가 곧 안전이다」(가입 훅)와 「넓히기 → 좁히기」(A 단계)가 runbook 의
  배포 규약 넷으로 일반화됐다.
