# 매칭은 자리 대신 사람을 복원한다

2026-09-18. 기존 오늘의 인연을 매칭 탭으로 확장한다. PRD §6.1.

## 화면과 참여

사진 중심 카드에 기존 예측 궁합 점수·보완 이유·소개를 표시한다. 홈의 중복 후보 목록은
매칭 진입으로 대체하고, 홈에서 열리던 자동 참여·요약 갱신은 유지한다(ADR 0037의 진입
시점 계약). 모바일 하단은 내 사주·사주·궁합·매칭·풀이·소식의 다섯 칸이며 저장한 사람은
전체 메뉴에 남는다. `/me/matching/preview`의 AI 예시와 실제 후보는 같은 UI를 사용한다.

## 지나침과 영구 숨김

`discovery_passed`와 `discovery_hidden`은 별개다. 과거 영구 숨김 자료를 일괄 변환하지 않는다.
배포된 `20260923090000`의 정책을 유지한다: 최근 20명은 계속 보관하며, 그 밖으로 밀린
사람은 마지막 넘김부터 24시간이 지나야 추천 제외가 풀린다. 스냅샷의 24시간과 기준 시점이
다르다. 이 변경은 모든 기록을 하루 뒤 없애는 정책으로 바꾸지 않는다.

표시와 제외의 최근 20명은 동일한 `(passed_at DESC, passed_user_id DESC)` 순서를 사용한다.
그 20명 중 현재 공개 자격을 잃은 사람은 표시하지 않는다. 21번째를 대신 채우면 목록 안인데
추천에서는 제외되지 않는 사람이 생기므로 조회에서 뒤 사람을 끌어올리지 않는다.

## 현재 자격과 사진

`discovery_pair_eligible`이 활성·참여·현재 명식 판본·상호 성별 조건·차단·영구 숨김·진행 중인
요청을 검사한다. 일반 추천은 여기에 지나침 제외를 더한다. 보관함과 복원은 지나침만
예외로 두고 같은 자격을 검사한다. 사진 권한도 현재 공개 가능한 보관 대상에만 추가한다.
내부 함수는 인증 사용자에게 직접 실행 권한을 주지 않는다.

## 복원은 한 번의 변경이다

`restore_passed_connection`은 자기 보관 기록과 현재 자격을 검사하고, 최신 스냅샷 맨 앞에
현재 요약의 카드를 넣고, 요청에 필요한 노출 근거를 기록하고, 보관을 해제한다. 이 모든
변경과 공개 카드·보관 목록 반환은 한 트랜잭션이다. 따라서 화면에만 나타났다가 새로고침하면
사라지거나, 사진은 보이는데 요청에 필요한 근거가 없는 복원을 만들지 않는다.

같은 스냅샷의 다른 카드 순서는 유지한다. 사용자가 직접 복원하면 자동 추천 10명 외에
추가 카드가 생길 수 있다. 복원은 새 후보 추첨이나 새 궁합 요청이 아니다.

클라이언트 덱은 남은 카드와 되돌릴 사람의 이력을 ID로 가진다. 이동 타이머는 시작한
사람만 제거한다. 복원 성공 시 예약된 이동을 취소하고 선택한 카드를 맨 앞에 넣으며,
실패 시 이력과 보관함을 유지한다. 보관함 버튼과 실행 취소는 같은 복원 함수를 사용한다.

## 검증

- DB: 20명 경계·동률·24시간·공개 조건·사진 권한·복원 거절 시 보존·복원 후 궁합 요청.
- 덱: 연속 복원·현재 덱 밖 복원·20명 제한·이동 중 다른 사람 복원.
- 브라우저: 새로고침 후 복원·연속 되돌리기·이동 중 취소·실패 후 재시도·실제 사진.

이미 배포된 마이그레이션은 수정하지 않고 `20260923100000`에 보완했다.
