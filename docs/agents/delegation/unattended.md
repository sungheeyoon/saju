# 위임 규약 — 무인 라운드

색인은 `docs/agents/delegation.md` 다.

## 무인 라운드 — 운영자가 자는 동안 (2026-09-28)

운영자는 밤에 「역할별로 감사하고, 틀린 것은 고치고, 커밋 · 푸시하면서 계속 이어가라」고 맡긴다. 그 말이 무엇까지
허용하는지 정해 둔 곳이 없어 세션마다 달랐다 — 2026-09-28 밤 조율자는 「동의 없이 진행」을 받고도 머지를 안 했고,
반대로 보고서는 main 에 직접 밀어 main 을 붉혔다(`docs/notes/2026-09-28-overnight-audit.md`). **무인 라운드는 권한 등급을
넓히지 않는다** — `docs/agents/delegation/permissions.md` 「권한 등급」 표가 허용하는 것 가운데, 운영자가 시작할 때 준 범위 안에서만 움직인다.

**권한 봉투는 시작할 때 한 번 적는다.** 조율자는 라운드를 열며 그날 세션 기록(`docs/notes/`)의 첫 줄에 무엇을 맡았는지
적는다. 운영자가 「알아서 계속」이라고만 했으면 아래가 기본값이다.

| 항목 | 기본값 |
| --- | --- |
| 코드 · 문서 수정, 작업 가지 커밋 · 푸시, PR 생성 · 갱신 | 허용 |
| gate 통과 뒤 `--auto` 머지 — 결정이 아닌 PR | 허용 |
| main 직접 푸시 | 금지 — 보호 규칙이 막는다(ADR 0121) |
| `docs/agents/delegation/decisions.md` 「결정 점검표」에 걸리는 PR — 새 문구 · 정책 · 접근 · 실패 때 여닫음 · 보존 · 비용 · 화면 흐름 · 메뉴 구조 | PR 까지 만들고 머지하지 않는다. 아침 보고의 「결정 대기」로 |
| 운영 `db push` | 운영 베타에서는 묻지 않고 밟고 **본 값을 적는다** — `migration list` 의 remote 칸과 PostgREST 캐시(`docs/agents/delegation/permissions.md` 「권한 등급」 표, ADR 0093). 마이그레이션이 든 PR 은 push 와 확인이 끝난 뒤에 `--auto` 다 |
| 실호출 | 에이전트는 안 한다 — 운영자가 직접 돌린다(운영자 답 2026-09). 에이전트는 명령과 확인할 값을 PR 에 적어 건넨다 |
| 운영 배포 | 「배포」 답을 받은 뒤다(`docs/agents/delegation/coordinator.md` 「머지는 배포가 아니다」) |
| main 이 붉어짐 | 새 작업을 멈추고 먼저 복구한다(`docs/agents/delegation/working.md` 「시작하기 전에 — 붉은 main 이 먼저」) |

**자동으로 고쳐도 되는 경계.**

- 기존 규칙 · 디자인 체계(ADR 0109, `app/ui/`) · 접근성 규칙 · 이미 승인된 문구나 디자인을 **어긴 것을 되돌리는** 수정 —
  고치고 검증해서 `--auto`.
- 뜻을 바꾸지 않는 화면 다듬기(여백 · 정렬 · 반응형 · 포커스 · 오류 상태) — e2e 와 **전후 스크린샷**을 근거로 `--auto` 해도
  된다. 아침 보고에 PR 번호를 싣고 전후 스크린샷은 그 PR 본문에서 보게 한다(`docs/agents/delegation/done.md` 「끝났다는 것」 「전후 그림」) — 운영자가
  곧바로 되돌릴 수 있게.
- 새 사용자 문구 · 화면 흐름 · 메뉴 구조 · 결정 점검표의 항목 — 수정안과 PR 은 만들되 결정 대기.

**묶음(파동)으로 들인다.** 발견한 PR 전부가 아니라 **지금 머지할 묶음**을 정해 순서를 고정하고,
`npm run merge:sim -- <PR 번호들>`(머지할 순서대로 적는다 — 열린 PR 을 스스로 모으지 않는다)로 최신 main 위에 함께 합쳐 본다(나란히 선 PR 이 서로의 새 파일을 모르는 붉음을 먼저 잡는다 —
밤샘 감사 「배운 것」). 그다음 하나씩 최신 main 위에서 gate → `--auto`. 묶음이 다 들면 main 의 CI 를 보고 다음 묶음으로 간다.

**흐름 한 장.** 역할별 읽기 감사 → 수정 에이전트가 코드에서 다시 확인 → 결정 / 결함으로 가름(결정 점검표) → 가지 커밋 ·
푸시 · PR → 위험한 변경은 이 대화를 모르는 검토 에이전트가 대조(`docs/agents/delegation/coordinator.md` 「위험에 따라 두 번째 검토」) → 묶음 모의 합치기 →
하나씩 gate · `--auto` → main 확인 → 다음 묶음.

**아침 보고의 칸.** 머지된 것(PR 번호) · 결정 대기(PR 번호와 물을 표) · 직접 확인한 근거(`파일:줄` · 실행 결과, 위
「확인한 흔적」) · 돌린 시험과 결과 · main 상태(CI · HEAD) · 화면이 바뀐 것의 전후 스크린샷(그 PR 본문의 첨부를 가리킨다) · 안 한 것과 그 까닭.
아침 보고는 대화로 끝난다. 세션 기록(`docs/notes/`)은 이 칸을 옮겨 적지 않는다 — 머지 목록 · 배포 SHA · smoke 값은 PR · 배포
기록 · 간극 대장이 원본이고, 노트는 다른 문서에 없는 것만 적어 PR 로 넣는다(`docs/agents/delegation/notes.md` 「세션 기록」, ADR 0121).
