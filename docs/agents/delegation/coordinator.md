# 위임 규약 — 조율자 세션

색인은 `docs/agents/delegation.md` 다.

## 조율자 세션 — 사람 하나 · 백그라운드 에이전트 여럿 (2026-09-23~24 에 잼)

사람과 말하는 세션(조율자)은 **직접 고치지 않고 맡긴다.** 일은 `Agent` 도구로 `isolation: "worktree"` ·
`run_in_background: true` 에이전트에 하나씩 준다.

**대화가 저장소 일로 넘어가면 먼저 그 일의 역할 문서를 읽는다(ADR 0150).** 일이 하나면 그 역할로 바꿔 워크트리에서
직접 한다. 서로 기대지 않는 일이 여럿이거나 따로 검토가 드는 일이면 위대로 맡긴다
(까닭: `docs/notes/2026-10-07-chat-drift-retro.md`). Claude Code 에서는 훅이 한 줄로 일러 준다(`docs/agents/delegation/permissions.md` 「훅 — 메인 체크아웃에서 일러 준다」).

- **운영자가 고치라고 한 일은 커밋 · PR · `--auto` 까지 묻지 않는다(ADR 0152)** — 묻는 것은 결정 점검표의 새 줄과 배포뿐이다.
- **사람에게 묻는 곳은 조율자 하나다.** 에이전트에게는 「묻지 말고 끝까지 진행 · 결정이 아닌 PR 은 gate 뒤 `--auto`
  머지까지 · `docs/agents/delegation/decisions.md` 「결정 점검표」에 걸리는 PR 은 만들기만 하고 머지하지 않고 보고에」를 준다. 사람 판단이 드는 것(정책 · 문구 · 비용 · 되돌릴 수 없는 설정)은 에이전트가 **멈추지 않고 보고에 모으고**,
  조율자가 모아서 `AskUserQuestion` 한 번(질문 넷까지)으로 묻는다. 사람만 할 수 있는 것(계정 · AWS · 사업자
  정보 · 변호사)은 빈칸 · `[변호사 검토 필요]` 로 두고 나머지를 끝낸다. 결정 점검표에 걸린 PR 은 조율자가 머지 전에
  운영자에게 표로 묻는다.
- **브리프는 차가운 시작이다** — 에이전트는 이 대화를 모른다. 칸: **역할**(`docs/start.md` 「역할 고르기」 — 읽을 것 · 하지 않을 것 ·
  끝날 때 고칠 것은 역할 문서가 든다) · 이번 일에만 더 읽을 것(파일 경로) · 정해진 것(사람 결정을
  그대로) · 할 일 · **건드리지 않을 자리(지금 나란히 도는 세션과 그 파일)** · 워크트리(`stack:slot`) · 돌릴 시험 ·
  내보내기(PR → 필요하면 `db push` 와 remote 값 → 최신 main 위로 `--auto` 머지) · 보고 형식. 나란히 도는 세션이
  없다고 적었다가 나중에 하나 더 띄우면 앞 세션에 `SendMessage` 로 알린다.
  화면 문구: 대장 경로(`docs/product/copy-ledger.md`)와 규칙(`docs/agents/code-rules/screen-copy.md` 「화면 문구」)을 가리킨다 —
  시안 문구를 확정이라 쓰지 않는다.
- **브리프는 규칙을 옮겨 적지 않는다(2026-09-28).** 권한 · 마이그레이션 순서(`db push` → 확인 → 머지, `docs/agents/delegation/permissions.md` 「예외 —
  마이그레이션이 든 PR」) · 멈출 자리는 **이 규약의 문장을 그대로 붙이거나 절 이름으로 가리킨다** — 기억으로 다시 쓰지
  않는다 — 기억으로 다시 쓴 브리프가 규칙을 뒤집은 적이 있다(`docs/notes/2026-09-28-overnight-audit.md`). 브리프 틀 문서는 따로 두지 않는다(진실이 두 벌이 된다) — 역할 문서가
  그 자리를 대신하고, 역할 문서도 규칙을 옮겨 적지 않고 절을 가리킨다(ADR 0140).
- **무엇이 무엇을 답하나 — 사실과 의도(2026-09-28).** 「지금 어떻게 동작하나」는 **코드와 실행 결과**가 답한다.
  「어떻게 동작해야 하나」는 **PRD · ADR · 운영자 결정**이 답한다. 둘이 어긋나면 코드를 곧 정답으로 삼지 않고, 먼저
  **버그**(코드를 고친다) · **문서 노후화**(문서를 코드에 맞춘다) · **결정 미반영**(운영자 결정이 문서 · 코드에 아직 안
  들었다) 중 무엇인지 가른다 — 가르는 일 자체가 `docs/agents/delegation/decisions.md` 「결정 점검표」에 걸리면 결정이다. `docs/start.md` 「원본 — 무엇이 무엇을 답하나」의
  「어긋나면」 칸에서 「PRD 가 맞다」는 요구사항의 원본을, 「시험 · 린트가 맞다」는 층 · 코드 규칙의 원본을 말한다 —
  둘 다 의도의 근거가 어디인지를 정한 문장이지, 지금 동작을 문서에서 읽으라는 뜻이 아니다.
- **확인한 흔적을 붙여 전한다(2026-09-28).** 운영자 판단을 부르는 주장, 현재 상태의 단정, 권한 · 보안 · 비용 · 사용자
  약속에 관한 주장은 **이 세션에서 직접 확인한 `파일:줄` 또는 실행 결과**를 붙인다. 저장소 밖의 사실 — 법 · 가격 · 남의
  업체 조건(PG · 정부 절차 · 요금) — 은 **출처 링크**를 붙이고, 없으면 「확인 전」이라고 말한다. 세션 메모 · 감사 보고 · 이전 세션의
  기억은 **확인 전의 가설**이다 — 세션 메모가 결정의 「대가」를 「운영자 판단 남음」으로 옮겼고 조율자가 원본을 안 보고
  운영자에게 다시 물었다. 화면 문구를 제안할 때는 먼저 지금 코드의 글자(grep) · 서비스명 상수(`src/lib/brand`) · 앱의
  주된 말투 · 코드가 보장 못 하는 약속이 없는지를 본다 — 문구 대장에 옛 서비스명 · 틀린 현재 문구 · 오류 경계가 보장
  못 하는 문장(「저장된 값은 그대로 있습니다」)이 들어간 것은 코드가 아니라 옛 대장과 감사 보고를 보고 썼기 때문이다.
- **위험에 따라 두 번째 검토를 붙인다(2026-09-28).** 운영 정책 · DB · 보안 · 사용자 약속이 걸린 보고 · 브리프 · 문구는
  보내기 전에 **이 대화를 모르는 검토 에이전트**가 코드와 대조한다. 모든 보고에 의무로 두지 않는다 — 걸린 것에만.
- **전체 감사는 사건에 붙여 연다.** 정기로 돌리지 않고 **출시 전 · 기능을 크게 걷은 뒤 · 병렬 PR 라운드 뒤**에 연다.
  틀은 밤샘 감사의 역할 여덟(코드 규칙 · 아키텍트 · 시험 · 보안 · DB · 프런트 · 문서 · SRE, 읽기만 · 「메모 말고 코드」로
  브리프, `docs/notes/2026-09-28-overnight-audit.md` 「팀」)이다.
- **남은 일을 말하기 전에 간극 대장의 `보류` 줄을 본다.** 운영자가 미룬 것(`docs/product/gaps.md` 의 `보류`)은 그 줄의
  조건이 올 때까지 다시 권하거나 묻지 않는다.
- **조율자의 문서 · 세션 기록도 PR 로 넣는다** — main 에는 관리자까지 PR 로만 든다(`docs/agents/delegation/permissions.md` 「main 은 PR 로만」, ADR 0121).
  노트를 올리기 전에 `npx vitest run scripts/code-rules.test.ts` 를 돈다 — 없는 ADR 번호와 차례에 빠진 노트로 조율자의
  직접 커밋이 main 을 붉혔다(#297). 라운드 노트에 무엇을 적고 무엇은 번호로만 가리키나는 `docs/agents/delegation/notes.md` 「세션 기록」이 든다.
- **에이전트의 PR 에 커밋을 더하면 PR 의 가지로 민다** — 워크트리의 로컬 가지(`worktree-agent-…`)와 다를 수 있다:
  `git push origin HEAD:$(gh pr view <N> --json headRefName -q .headRefName)`. `git push origin HEAD` 는 원격에 새 가지를 세웠다(2026-10-07).
- **병렬 라운드의 머지 직전에 `npm run merge:sim -- <머지할 순서의 PR 번호…>` 를 한 번 돈다** — PR 마다 초록이어도 한
  PR 의 새 잠금이 다른 PR 의 새 파일을 몰라 합치면 붉었다(2026-09-28). 글자 충돌 · 단위 · 잠금 · 린트 · 타입만 보고, 스택
  검사는 각 PR 의 CI 가 잰다.
- **PR 본문 등 임시 파일은 워크트리 안에 쓴다** — 스크래치 폴더를 두 에이전트가 같이 써서 서로 덮었다(#209).
  에이전트는 `.md` 보고 파일을 못 쓸 수 있다(하네스가 막는다) — 보고는 메시지로 받고 조율자가 저장한다.
- **병렬로 둘 것과 차례로 둘 것** 은 `docs/agents/delegation/parallel.md` 의 표를 따른다. 실제로 부딪힌 것: ADR 번호(머지 직전 main 의 빈 번호),
  pgTAP 파일 번호, 마이그레이션 타임스탬프(머지 직전 main 의 마지막 뒤), gaps 의 같은 줄(제 조각만 다시 얹기).
- **보고를 그대로 옮기지 않는다.** 에이전트 · 외부 리뷰의 주장은 조율자가 코드에서 확인한 뒤 사람에게 전하고,
  동의 · 이견을 한 줄로 말한다. 사람이 붙여 넣은 외부 리뷰도 같다.
- **머지는 배포가 아니다**(ADR 0110). Git 배포가 꺼져 있어 PR 도 머지도 Vercel 자리를 안 쓴다. 에이전트는 Ready 를
  기다리지 않는다. 라운드가 끝나면 조율자가 `docs/ops/runbook/deploy.md` 「묶음 배포」로 최신 main 을 한 번 올리고, main HEAD = Production 과
  smoke 를 확인해 적는다 — 그 한 번은 등급 3 이라 사람이 답한 뒤다.
- 워크트리마다 운영 CLI 첫 호출에 키체인 창이 뜬다 — `docs/agents/delegation/local-env.md` 「로컬 환경의 함정」.
- **나란히 도는 세션의 일을 먼저 본다(2026-09-25).** 맡기기 전에 `git worktree list` 의 각 워크트리가 무엇을 고치는지 보고,
  같은 일을 두 번 맡기지 않는다. 사람의 화면 세션 보고를 머지할 때 **e2e 가 빠졌으면 머지 전에 돌린다** — 걷은 화면
  조각을 찾던 e2e 넷이 main 을 붉혔다(#220, `docs/notes/2026-09-25-coordinator-round.md`).
- **끝난 워크트리를 걷는다.** 머지된 에이전트의 워크트리가 남아 스택 자리를 쥐면 새 에이전트의 `stack:slot --auto` 가
  「빈 자리 없음」으로 거절한다(2026-09-24, 워크트리 16개가 자리 1~9 를 쥠). 새 라운드를 띄우기 전에 가지가 머지된 워크트리를
  `git worktree remove` 로 걷는다(사람에게 한 번 확인).
