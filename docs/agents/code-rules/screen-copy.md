# 코드 규칙 — 화면 문구

색인은 `CODING_STANDARDS.md` 다.

## 화면 문구

규칙은 여기 없다 — **`docs/context/copy.md` 「화면 문구 규칙」**(해요체가 기본 · 되돌리기 어려운 결과의 고지는 합니다체를 쓸 수 있다 · 결과가 드러나는
동작명 버튼 · 「~ 중…」 · 문장일 때의 마침표 · 한 사실 한 표기 · 한 화면 한 이름 · 늘 참인 문장은 안 세운다)과
**`docs/product/prd/screens.md` §3.2**(상품 이름 넷, 버튼은 동사로 갈린다)가 답이고, ADR 0025 · 0026 · 0027 · 0135 가 그 근거다.

에이전트에게는 규칙이 하나 더 있다. **한글 문구를 지어내지 않는다**(ADR 0196 — 운영자 결정 2026-10-22). 문법이 맞아도 제품이 쓰는 말이
아닌 문장이 연달아 퇴짜를 맞았다. 대장에 없는 문구는 **같은 자리에 실제 한국 서비스(네이버 · 카카오 · 토스 등)가 쓰는 표현을 찾아
출처(링크 · 확인 날짜)와 함께 맞춰 넣고**, 운영자 답을 기다리지 않고 PR · 머지까지 간다 — 운영자는 나중에 확인한다(사후 확인).

- 그 PR 이 무리 파일에 「확인 전」 절(`## <무리>-NN 확인 전 — …`)을 더한다 — 줄마다 자리 · 이전 · 넣은 글자 · 출처(링크 · 확인 날짜).
  실사례를 못 찾았으면 출처 칸에 「실사례 없음」과 가장 가까운 사례를 적는다
- 머지되면 운영자 확인 모음 #770 에 줄로 더한다(PR · 절 · 자리) — 새 확인 이슈를 열지 않는다. 운영자가 확인하면 절 제목을 「확정 문구」로,
  고쳐 주면 그 글자로 바꾸고(옛 글자를 찾는 시험도) 「확정 문구」로 둔다
- 사용자가 문안을 불러 주면 줄바꿈까지 그대로 쓴다 — 확인도 끝난 것이다
- **문구가 결정 점검표의 다른 줄**(권한 · 보존 · 삭제 · 비용 · 요금 · 환불, 사용자에게 새로 하는 약속)에도 걸리면 그 줄 때문에 결정이다 —
  이 규칙과 무관하게 머지 전에 묻는다(`docs/agents/delegation/decisions.md` 「결정 점검표」)

문구만 바뀐 라운드는 시험을 안 돌린다. **예외 하나** — `/ops/**` 에서 운영자에게만 보이는 설명 · 제목 · 빈 상태 문구는 실사례를 찾지
않고 쓰고 PR 에 모아 보고한다. 개인정보의 이용 · 보관, 운영자의 권한, 제재 결과, 사용자에게 전달되는 문구는 여기 안 든다(ADR 0103).

**UI 변경 요청이 오면 문구는 먼저 대장에서 찾는다** — 머리 `docs/product/copy-ledger.md`(규칙 · 여러 화면에 걸친 줄)와 그 무리 색인이
가리키는 고칠 화면의 무리 파일(`docs/product/copy-ledger/`, ADR 0162). 있으면(「확인 전」 절도) 그 문구를 쓴다. 없으면
위대로 실사례를 찾아 넣는다. 시안 · 외부 리뷰 · 에이전트의 문구는 출처가 없으면 넣지 않는다. 문구가 말하는 상태 전이(누르면 무엇이 되나 · 실패 갈래 · 처음/다시)는 코드에서 확인한다.
**글자를 바꾸면 옛 글자를 찾는 시험도 그 PR 이 고친다** — `e2e/` · `scripts/check-*.mjs` 에서
옛 글자를 이름 그대로(`name: '…', exact: true`)도 찾는다(2026-10-10, 하나를 놓쳐 PR 이 붉었다). 2026-09-29 — 브리프가 「시안에 있던 문구는 확정」이라 적어 시안의 자리표시
문구(평서체 · 옛 이름)가 제품에 들어갔고, 「답하면 궁합이 열린다」(거절도 답이다 — 궁합은 수락해야 열린다)가
제안됐다. 대장이 저장소 밖에 있어 아무도 안 읽었다.

문구는 그 화면(`.tsx`)에 산다. 여러 화면이 같은 사실을 적으면 상수 하나(`HOUR_UNKNOWN_LABEL`)로
든다 — 화면마다 다시 적지 않는다. 화면만 쓰는 상수는 `src/lib/<영역>/copy.ts`(ADR 0159) — 글자 · 글자만 든 표만 서고 e2e ·
흐름 검사는 그 이름을 읽는다 — 시험이 글자로 찾으면 그 문구는 「문구만」이 아니다(덧 G-90).
`copy.ts` 의 상수는 JSX 자식(`{NAME}`)과 글자 속성의 값으로만 쓴다 — 프롭 · 배열 · 함수 인자로 넘기는 문구는 `copy.ts` 밖의 상수에 둔다
(`scripts/ci-plan.mjs` 의 `copyConstantMisuses` 가 잰다).
