# 코드 규칙 — 주석과 ADR 참조

색인은 `docs/agents/code-rules.md` 다.

## 주석과 ADR 참조

- **주석은 한국어 산문**이다. 식별자 · 인용 · 명령줄만 영어다(주석 18,415 줄 중 14,049 줄에
  한글이 있고, 나머지는 인용과 명령이다).
- **주석은 지금의 것만 적는다(2026-10-05)** — 지금 참인 불변식, 이름과 타입으로 안 보이는 실패 방식, 이 모양을
  고른 기술적 대가. 「무엇을 한다」는 이름이 말한다. **옛 구현 · 버린 안 · 운영자 결정의 날짜와 경위는 주석에 두지
  않는다** — 결정은 ADR, 날짜별 변경은 `docs/product/prd-changelog.md`, 사정은 노트(`docs/notes/`)가 든다. 결정 근거가
  필요하면 **지금 유효한 ADR 하나**를 가리킨다. 기존 주석은 **그 파일을 고칠 때 손댄 자리 둘레만** 걷는다 — 주석만
  걷는 전역 정리 PR 은 열지 않는다.
- **결정은 `ADR NNNN` 으로 가리킨다.** 네 자리, 띄어쓰기 하나(`ADR 0078`), 여럿은 `·` 로
  (`ADR 0072·0078`). 붙여 쓰거나 하이픈으로 잇거나 자릿수를 줄이지 않는다 — 시험이 그 표기를 센다.
  806 건이 264 파일에 있고 전부 실제 파일을 가리킨다 — 시험이 이것을 든다. 이슈는 `#67` 이다.
- **TODO · FIXME 를 남기지 않는다**(0건). 미결은 간극 대장(`docs/product/gaps.md`)의
  `G-nn` 줄이나 이슈다(`docs/agents/delegation/decisions.md` 「결정 점검표」 아래). 코드 안의 TODO 는 아무도 안 세는 목록이다.
- 시험 이름은 **참인 문장**이다 — `it('src/lib 은 app 과 관문을 모른다')`. 무엇을 잰다가 아니라
  무엇이 참이다.
