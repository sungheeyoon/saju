## 배운 것 · 헤맨 것

- **조율자가 CI 계획을 로그로 보지 않고 설명했다** — 「`copy.ts` 밖 상수 때문에 e2e 를 다 돌았다」는 추측이었다. `plan` 의
  `reason` 은 차선을 켠 파일 둘(`app/me/(home)/page.tsx` · `app/me/matching/history/page.tsx`)만 들었다. 판정을 말하기 전에
  `plan` 로그의 `reason` 을 본다
- **PR 제목 type 에 `copy` 는 없다** — `ui(copy):` 로 단다. 제목을 고친 뒤 `gh run rerun` 은 옛 제목(이벤트 페이로드)으로
  다시 돈다 — 닫았다 다시 열어 새 이벤트를 만든다
- **문구를 바꿀 때 옛 글자를 찾는 시험은 PR 이 고친다** — 빈 보관함 타일 이름을 찾던 e2e 하나를 놓쳐 PR 에서 붉었다. 바꾼
  글자를 `e2e/` · `scripts/check-*.mjs` 에서 이름 그대로도 찾는다(`name: '…', exact: true`)
- **44px 칩을 빈틈없이 붙이면 과녁 시험이 43px 로 잰다** — 중심에서 반 픽셀씩 걸어 이웃에 닿을 때까지 재기 때문이다(#582)
- **ui 역할의 필수 읽기량이 천장에 붙었다** — ui 는 몇 바이트 남았다. `screens.md` 「3. 화면」 한 줄 · ADR 0109 추기가 넘겨
  에이전트들이 문서 칸을 다 채우지 못했다(#578 · #579 · #580). 조율자의 후속 줄도 `gaps.md` 에 못 들어 이슈(#583)로 갔다 — 천장을 올리거나 필수 읽기를 줄이는 것은 운영자 결정이다. 역할 문서가 이 천장을 말하지 않는다
- **전후 그림을 GitHub 첨부로 올릴 길이 CLI 에 없다** — 에이전트마다 커밋한 대표 몇 장 + 비공개 아티팩트로 갈랐다
- **스크래치패드는 이 세션의 에이전트가 같이 쓴다** — `dev.log` · `shots/` 가 서로 덮였다. 에이전트 브리프에 고유 폴더를 준다
- **`scripts/ui-seed.mjs`** 는 `UIWALK` 코드 줄이 옛 마감일로 남아 있으면 검사 제약에 걸린다(`on conflict` 가 `valid_until` 을 안
  고친다). 에이전트 워크트리에서 `worktreeStack()` 이 main 스택을 돌려줘 main 의 로컬 DB 에 시드했다
- **배치 PR 다섯이 changelog 끝줄 · 문구 대장 절 번호로 번갈아 충돌했다** — 절 번호는 조율자가 처음에 나눠 준다(25 ~ 28)
