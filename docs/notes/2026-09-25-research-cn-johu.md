## 0. 두 축 — 공신력과 보급도

공신력(조정자가 준 등급, 그대로 쓴다):

- **S** 고전 원문 · 이름난 대가의 책 · 주석

- **B** 실무자 블로그 · 포럼(풀이 사례 있음), 앱 · 사이트의 자기 방법 글

보급도는 앱 · 소프트웨어에만 따로 적는다 — 공신력에 섞지 않는다. 숫자가 없으면 「모름」이다.

### 2.4 「透干 + 通根」은 조후의 쓸 수 있음의 조건인가

| 쪽 | 출처와 말 |
| --- | --- |
| 뿌리가 있어야 쓴다 | 算準網 2783 B — 조후가 맞으려면 「有调候用神且健旺有根气」, 사례 癸未 丁巳 丙午 癸巳 「虚透无根，反被旺火熬干……此时不能用水调候」. HeiGe B — 「调候用神也要落到地支有根：仅天干虚露、地支无根，调候力薄」(`references/03_tiaohou_qiongtong.md:40`), 「表中用神在原局透出且有力 → 富贵之兆」(`:38`). 算準網 2803 B — 일반론 「天干透者地支藏，此是根基最妙方」. 조사 C 의 任鐵樵 S 「寒雖甚，要暖有氣」 |
| 천간에 드러나지 않아도 쓴다 | 朱祖夏 A — 시지 **午**(지지)를 조후 겸 생신 용신으로 쓴다(사례 `zzx-sinhae-sinchuk`, 처방은 지장간에만 있다) |
| 원국에 없어도 조후가 첫 필요다 | 謝咏 B — 辛酉 辛丑 壬辰 癸卯 는 불이 없는데 「迫切的需要太阳之光」(사례 `xy-sinyu-sinchuk`). 張永紅 B — 「故喜行暖地」, 운으로 채운다 |
| 뿌리 있게 드러났는데 물린다 | 朱祖夏 A — 丙午 己亥 庚寅 丙戌 은 丙이 뿌리를 두었는데 「以扶抑和通关取用都要取己土印星为用神，不可取火调候」, 「若以调候取用，反会火上浇油」(사례 `zzx-byeongo-gihae`). tianzhi-core A — 「病」과 같은 처방 오행을 뺀다. HeiGe B — 「调候字已在局中得力 → 调候已解」 |
| 뿌리와 무관하다 | 張永紅 B — 「调候用神还有一特性，就是不怕刑冲及合化变质……调候是一种季节，一种时间，是无形的」 |

판정:

- **「쓸 수 있으려면 뿌리가 있어야 한다」는 받친다** — S1(任鐵樵, 조사 C) · B3. 거스르는 A 는 없다. 다만 朱祖夏(A)는 천간이 아닌
  지지 午를 쓰므로 **「透干」까지 요구하는 말은 현대 A 층에서 깨진다.** 받치는 것은 「통근(원국 안의 힘)」이지 「투간」이 아니다.
- **「조후를 부르려면 드러나 뿌리를 둬야 한다(필요조건)」는 서지 않는다** — 謝咏 · 張永紅(B)은 원국에 없는 불을 가장 먼저 필요하다고 한다.
  둘은 「쓸 수 있음」과 「필요함」을 다른 말로 쓴다.
- **「드러나 뿌리 둠 → 물리지 않는다」는 깨졌다** — 조사 C 표본의 물림 0/6 이 1/8 이 됐다. 깨뜨린 까닭은 「이미 넘친다」다.
  HeiGe 의 「已在局中得力 → 调候已解」와 tianzhi-core 의 「病과 같은 처방은 뺀다」가 같은 쪽이다 — **뿌리 있는 처방은 급함을 줄이는
  신호로도 읽힌다.** 조사 C 는 이 사실을 「쓸 수 있음」의 신호로 읽었는데, 현대 자료는 같은 사실을 「이미 풀렸다」로도 읽는다.
- (a) 뿌리 필요(쓸 수 있음) **S1 · B3** / 투간 불필요 **A1** / 부재해도 필요 **B2** / 넘치면 물림 **A2 · B1** / 무관 **B1**.
- (b) S/A 무게로: 「통근이 쓸 수 있음의 조건」은 선다(S1, 반대 A 없음). 「투간」은 안 선다(A1 반대). 「뿌리 있는 처방이면 조후를 물리지
  않는다」는 **S/A 안에서 뒤집힌다**(A2 가 넘치면 물린다고 한다).

## 3. 사례 — 열둘 더해 56 건

## 4. 엔진에 주는 뜻 — 문턱을 짓지 않는다

1. **조사 C 의 후보 1(처방이 드러나 뿌리를 둠)은 「쓸 수 있음」으로만 남긴다.** 「투간」은 A 층(朱祖夏)이 거스르고, 「물림이 없다」는 A 층
   (朱祖夏 · tianzhi-core)과 HeiGe 가 거스른다 — 뿌리 있는 처방은 「이미 풀렸다」로도 읽힌다. 한 사실을 두 방향으로 읽는 계통이 있다.

3. **서열(조후 ≥ 억부)은 정하지 않는다.** 현대 A 층은 억부 먼저, S(梁湘潤)와 B/C 다수는 조후 먼저다. 소프트웨어 둘도 반대로 골랐다.
