## 운영자 결정 (2026-10-11 낮)

- **다 쓴 풀이의 목차는 걷는다 — 「예전 것이 낫다」**(#637). 보관함 「이름으로 찾기」는 남았다.
- **사진 문구는 「올리다」가 아니라 「저장」**(대장 46). 한국 서비스의 실제 문구는 공개 자료에서 못 찾았다 — 같은 화면의 「사진은 바로 저장돼요」와 맞추고, 시스템 낱말 대신 결과 낱말을 쓴다는 까닭으로 붙여 온 표를 그대로 택했다.
- **사진은 선택이다 — 가입 폼 · 권유 화면 · 알림 없이, 사진이 없을 때만 「사진 추가」가 보인다**(대장 47, PRD account §5.1). 붙여 온 다른 의견과 조율자 의견이 같았다.
- 얼굴 위치 · 음력 문구 · 읽기량 정리를 나란히(#639 ~ #642).

## 판단과 그 까닭

- **얼굴 위치는 원본을 자르지 않고 보일 자리(가로 · 세로 %)만 둔다**(ADR 0170) — 틀 비율이 화면마다 달라 한 번 자른 바이트로는 다 맞출 수 없다. 확대는 같은 까닭으로 뺐다.
- **읽기량은 천장을 올리지 않고 ui 의 고정 읽기를 줄였다**(ADR 0169) — 대장 무리 파일이 「먼저 읽기」라 절마다 자랐다. ADR 0162 를 일부 되돌린 일이라 운영자 확인을 남겼다(G-101).
- 그림을 아티팩트로 보이다 조율자가 결함 하나를 찾았다(사진 메뉴의 「삭제」가 하단 독에 가림 → #636, ADR 0168).

## 헤맨 것 · 배운 것

- **나란히 선 PR 하나가 들 때마다 남은 PR 이 충돌했고, 충돌한 PR 은 CI 가 안 돈다.** 밤의 #627 과 같은 꼴이 #633 · #634 · #635 에서 되풀이됐다 — 규약에 적었다(`docs/agents/delegation/coordinator.md` 「「CI 기다림」 보고를 믿지 말고 PR 을 본다」).
- 문구 대장의 전역 절 번호가 네 번 부딪혔다 → ADR 0169 가 무리 파일 접두 번호로 바꿨다.
- PR 제목만 고치면 검사가 다시 안 돈다(#633, 빈 커밋으로 풀었다). `update-branch` 뒤 `--auto` 가 풀렸다(#635).
- 에이전트 공통으로 헤맨 것 — 포트 3100 을 다른 세션의 서버가 쥐고 있어 전후 그림이 남의 서버로 찍혔다(`UI_PORT` 를 바꿔 다시) · 워크트리 격리가 git 이 든 복합 명령을 막는다 · 오래된 워크트리가 로컬 DB 자리를 쥐고 있다. 다음 `/retro` 거리다.
- 외부 리뷰 문장도 가설이었다 — 「설정 실패가 말없이 빠진다」는 짚은 자리가 틀렸고 진짜 자리는 다른 줄이었다(#633), 「채팅에 궁합 길이 없다」는 넓은 화면엔 있었다.
