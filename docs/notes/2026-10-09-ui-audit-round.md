> **세션 기록이다.** 요구사항도 규칙도 아니다 — 코드와 어긋나면 코드가 맞다. 머지 목록은 PR(#545~#558), 남은 일은
> `docs/product/gaps.md`, 결정은 ADR 0157 이 원본이다.

## 권한 봉투

운영자가 대화에서 한 번에 넘겼다: 「다 바꾸고 보고 · UI 는 CI 전부를 로컬에서 돌리지 않는다 · 조율자로서 병렬로」, 이어
「중간마다 묻지 말고 — #550·#557 머지, #554 DB 적용·확인 후 머지·배포, #555 DB 적용·확인 후 머지. 배포도 승인한다」(2026-10-09).
문구 넷(#547 · #548 · #550 · #554/#555)은 표로 한 번 물어 시안 그대로 승인받았다.

## 판단과 까닭

- **화면 갤러리부터 지었다.** 운영자가 「모든 화면 · 팝업을 한곳에」를 먼저 청했고, 그 그림을 두 검토 에이전트가 반씩 훑어 결함 서른여 개를
  냈다. 바깥 리뷰 둘(붙여 넣은 것)은 조율자가 코드에서 다시 재어 동의 · 이견을 한 줄씩 붙여 전했다 — 「최근 본 글」은 서버 열람 기록 없이
  `localStorage` 로 충분하다는 이견이 #551 의 모양이 됐다.
- **충돌 영역으로 일곱을 갈랐다** — 풀이 판 · 보관함 · 생성 흐름(DB) · 사람/설정/프로필 · 뼈대/껍데기 · 인연/채팅 · 궁합/로그인. 마이그레이션
  사슬은 생성 흐름 하나만 쥐었다. **문구는 레이아웃과 다른 PR** 로 내게 해 레이아웃이 결정을 기다리지 않고 들어갔다.
- **결정 PR(#554 · #555)은 머지 전 두 번째 검토** — 13 의 거르개가 인연 궁합 연 쪽 회귀를 놓친다는 것을 잡았다.

## 배운 것

- **`prd-changelog` 는 union 이 로컬 병합에서만 걸린다** — 일곱 PR 이 끝에 덧붙여 차례로 `DIRTY` 가 됐다. 머지마다 가지에 main 을 합쳐 미는
  고리를 돌렸다. 문구 대장은 union 이 아니라 「검토 대기」 앞의 같은 자리에 넷이 「15」 절을 넣었다 — main 쪽 다음 번호로 미는 풀이를 썼다.
- **합치면 읽기량이 천장을 넘는다** — PR 마다 초록이어도 PRD 화면 파일이 함께 자라 feature 가 95,000 을 넘었다(`npm run merge:sim` 이 잡음).
  둘은 문장을 줄여 맞췄고, #554 는 천장을 한 눈금 올렸다(ADR 0157 「읽기량 천장」).
- **진행을 적는 문은 작업이 제출된 뒤에만 적는다** — `note_reading_progress` 는 `frozen` 작업에 `false` 를 돌려준다. 조율자의 브라우저 검사가
  이것을 몰라 「갱신이 안 된다」로 붉었고, 원인은 앱이 아니라 검사였다(`prepare_reading_job` → `adopt_reading_job` 를 먼저).
- **누르는 자리 검사(`e2e/target.ts`)는 반 픽셀에 걸린다** — 칩을 묶음으로 감싸 위치가 반 픽셀 옮겨지자 44px 칩이 43.5 로 쟀고, 1px 넘친
  라디오가 접힌 윗줄 · 아랫줄을 덮었다. 줄 사이 `gap-y-1` 로 풀었다(#549).

## 헤맨 것

- 역할 문서(`docs/roles/ui.md`)가 「gate 뒤 `--auto`」의 gate · 워크트리 `node_modules` 를 가리키지 않아 에이전트 다섯이 따로 찾아갔다.
- 승인된 화면 모양(예: 「저장한 사람 / 직접 입력」 순서, #543)을 결정으로 볼지 가르는 기준이 ui 역할에 없다.
- 재정의한 SQL 함수를 직전 정의와 견주는 법이 reviewer 역할에 없다(검토 에이전트는 awk 로 두 본문을 떼어 diff 했다).
- 로딩 뼈대(`loading.tsx`)는 화면 찍기 도구가 못 찍는다 — 그날은 커밋하지 않는 미리보기 페이지로 찍었다(#558 노트).
