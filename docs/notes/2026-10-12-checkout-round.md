## 권한 봉투 (운영자, 2026-10-12)

대화는 통신판매업 · 에스크로 · PG 심사 조사로 시작해 「진행해」로 저장소 일이 됐다. `db push` 둘(`20261207090000` · `20261208090000`) ·
머지 · 묶음 배포 하나(`08a067d`)는 운영자가 그때마다 답한 뒤다. 운영자가 다른 곳에서 붙여 넣은 검토 넷(문구 · 법령 대조)은
조율자가 약관 초안 · 코드와 대조한 뒤 동의 · 이견을 붙여 전했다.

## 판단과 그 까닭

- **사업자 값은 자리만 서고 값은 환경변수(ADR 0172)** — 집 주소가 공개 저장소에 들어가지 않게(ADR 0151 의 사정). 주소를 집으로 둘지 비상주 사무실로 둘지는 값을 넣기 전에 운영자가 정한다.
- **판매는 닫은 채 심사 계정만 결제창(ADR 0171)** — 변호사 검토 전에는 판매를 열지 않는다는 G-21 을 지키면서 카드사 심사가 요구하는 「결제창이 실제로 뜬다」를 만족시켰다.
- **유효기간 유료 5년 · 무료 1년(ADR 0173)** — 운영자 「다른 서비스 따라」. 카카오페이지 · 디지털콘텐츠 표준약관 제13조 · 점신 제14조⑤를 근거로 적고,
  점신의 「탈퇴하면 소멸 · 환불 불가」는 2026-04 공정위 오픈마켓 약관 시정(탈퇴 시 유상 캐시 소멸)과 부딪혀 따르지 않았다. 무료 1년은 시행일 이후 몫부터(소급하지 않는다).
- **결제 화면은 리디 꼴(ADR 0175)** — 동의 체크 → 결제 단추 → 작은 글씨 유의사항. 리디의 「7일 이내 · 일부 쓰면 취소 불가」는 우리 약관 제15조② · 제16조①보다
  불리하게 읽혀 카카오뮤직 의결(기만적 철회 방해)과 같은 꼴이라 가져오지 않았다.
- **머리글 풀이권은 운영자가 직접 올린 B안이 기준** — 펼침 메뉴(`credits-menu.tsx`)를 되돌리지 않고 설정 메뉴와 같은 폭 · 위치 · 글자 체계로만 다듬었다(「승인된 운영 코드가 기준」).

## 헤맨 것 · 배운 것

- **문구를 근거 없이 지었다가 여러 번 되돌렸다** — 「기한 없이 써요」 · 「언제든 돌려드려요」 · 「구매 전 확인사항」 카드. 앱 안 결제 화면은 웹 검색으로 원문이 안 나온다 —
  운영자가 리디 충전 화면 문구를 붙여 넣은 뒤에야 섰다. 실사례가 필요하면 처음부터 캡처를 부탁하는 편이 빠르다.
- **조율자가 머지 알림을 놓쳐 배포가 한동안 안 섰다** — `--auto` 머지는 알림을 따로 주지 않는다. 자동 머지를 건 뒤에는 `gh pr view` 를 도는 백그라운드 감시를 걸었다.
- **나란히 선 두 PR(#668 · #669)이 같은 ADR 번호 0171 을 잡았다** — 뒤 PR 을 0172 로 옮기고, 번호 이음 시험 때문에 머지 차례를 #668 → #669 로 고정했다. 병렬 PR 의 ADR 번호는 브리프에서 미리 나눠 준다.
- **읽기량 천장을 17바이트 넘었다(#673)** — 깎지 않고 결제 화면 문구 절을 「설정」 무리에서 새 무리 파일 `docs/product/copy-ledger/credits.md` 로 옮겼다(G-107 아래 허용된 길).
- **이 WSL 에는 Docker 가 없다** — 마이그레이션 · pgTAP 의 첫 실행이 CI 였고(#668 은 `74_authenticated_doors` 목록 누락으로 한 번 붉었다), 로그인 화면 그림은 임시로 로그인 없이 여는 패치로 찍고 되돌렸다.
  `local-env.md` 「워크트리에서 전후 그림 찍기」에 이 길이 없어 에이전트마다 다시 짰다. 그 그림에는 Next 개발 표시 「4 Issues」(로컬 DB 없는 요청 실패 넷)가 남았다 — 찍을 때 가린다.
- **조율자가 그림을 대충 봐서 운영자가 정렬을 잡았다** — 알약 안 아이콘과 숫자의 세로 중심이 1.37px 어긋났다. 이후 확대(4배) 그림과 브라우저에서 잰 값으로 보였다.
- **운영자의 처음 뜻을 브리프에 잘못 옮겼다** — 「폰에서는 이모지랑 숫자만」을 알약 + 숫자로 옮겼고, 실제 뜻은 설정처럼 작은 아이콘 하나와 그것을 누르면 펼치는 메뉴였다. 결국 운영자가 B안을 직접 만들어 올렸다.
- `<button>` 을 `<details><summary>` 로 바꾸면 `getByRole('button')` e2e 가 깨진다(`authed (live)`) — 설정 메뉴처럼 `getByLabel` 로 찾는다.
- 런북 「묶음 배포」 5 는 「그 일의 이슈」에 적으라는데 이슈 없는 묶음이었다 — #208 꼴로 운영 배포 확인 이슈(#677)를 새로 열었다.
- **정리** — 머지된 에이전트 워크트리 · 운영자의 시안 워크트리(`~/saju-wt/`) · 지난 세션의 워크트리 셋(#663 · #664 · #665 머지 · 잠근 프로세스 없음 확인)과 그 가지를 걷었다. 로컬 · 원격 모두 `main` 하나다.
