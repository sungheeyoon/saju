## 판단과 그 까닭

- **읽기 상한은 고치지 않고 걷었다(ADR 0177)** — 천장은 예상치 + 5,000 의 눈금이라 근거가 없었고, 깎기 · 쪼개기 · 제품 ADR 을 따로
  세우는 유인이 됐다(G-107). 막는 것은 역할 문서 한 화면과 가리킨 자리가 있는지뿐이고, 읽기량은 보고 표다. 그 뒤 PR 넷이 예상치
  95,000 을 넘었지만 붉지 않았다.
- **풀이권 단위는 「개」를 하루 만에 「장」으로 다시 바꿨다** — 처음엔 대장 안에서 갈린 「번 · 개」를 확정된 쪽(「개」)으로 맞췄다(#685).
  운영자가 붙인 검토가 「~권은 장」을 짚었고, 네이버 시리즈 · 카카오페이지의 「이용권 N장」을 확인한 뒤 화면 · 결제 · PG 주문명 · 약관 ·
  DB 문장까지 「장」(수량) · 「회」(풀이 횟수) · 「편」(풀이 한 건)으로 나눴다(#687 · #692 · #693). 명칭에 맞는 단위를 처음부터 실사례로
  찾았으면 한 번에 끝났다.
- **약관 표기 정정은 고지 없이(ADR 0176 추기)** — 시행일 상수가 비어 있고 동의한 사람이 없어 개정이 아니라 오기 정정으로 봤다.
  시행일이 서면 그때부터 제4조 절차다.
- **CI 의 「주소 없음 → 전부」는 import 를 거꾸로 따라 좁혔다(ADR 0178)** — 113 → 91. 남은 42 는 layout · 서버 액션 · route · 관문이
  부르는 파일이라 일부러 전부다(ADR 0119).
- **지도 둘(`relation-map` · `orbit-map`)은 합치지 않았다** — 공통은 이미 `app/ui/orbit.tsx` 에 있고, 남은 자리 펴기 · 곡선 차이를
  합치면 사람 자리가 움직인다. 로고 글자(1.3rem)도 토큰 밖 허용 목록에 두었다.

## 헤맨 것 · 배운 것

- **조율자의 추천 하나가 틀렸다** — 「타입만 들이는 import 는 서버에 닿지 않는다」를 점검 보고대로 승인 받아 맡겼는데, 주입받은
  `SupabaseClient` 로 실제 DB 를 부르는 파일 19개가 e2e 0개로 떨어졌다. 검증 문턱을 바꾸는 PR(#682)에 독립 reviewer 를 붙여서
  머지 전에 잡혔다 — 문턱을 낮추는 변경은 반례를 찾는 검토를 따로 둔다.
- **나란히 선 PR 이 같은 ADR 번호를 잡았다(0176 둘)** — 지난 라운드의 교훈(번호를 브리프에서 미리 나눠 준다)을 첫 배치에서 안 지켰다.
  둘째 배치부터 0177 · 0178 을 미리 줬다.
- **쪼개기와 이상값 PR 이 엇갈려 main 이 붉었다(#702)** — #695 가 `panel.tsx` 의 큰 따옴표를 `reading-result.tsx` 로 옮긴 사이 #697 의
  허용 목록이 옛 파일을 적었다. 파일을 옮기는 PR 과 경로를 글자로 드는 시험을 더하는 PR 을 나란히 돌리면 생긴다 — 옮기는 쪽이 머지 직전
  `grep` 으로 옛 경로를 한 번 더 본다. #700 과 #703 이 같은 한 줄을 고쳐 둘 다 들어갔다.
- **에이전트가 옛 규칙으로 판단했다** — #680(천장 걷음)이 들어간 뒤에도 늦게 시작한 브랜치의 에이전트 둘이 천장에 걸린다며 줄을 빼거나
  옮겼다. 규칙을 바꾼 PR 이 들어가면 돌고 있는 에이전트에게 알린다.
- **에이전트의 보고를 그대로 믿지 않는다** — 「원격 가지가 남았다」는 보고가 두 번 있었지만 `deleteBranchOnMerge` 는 켜져 있었고 가지는
  없었다. `git fetch --prune` 로 보고 정리했다.
- **Docker 가 뜬 뒤에야 로그인 화면 전후를 찍었다** — 그 전에는 CSS 바이트 비교 · 크로뮴 계산값 비교로 대신했다(방법은
  `docs/agents/test-map/what-to-run.md` 화면 줄). 로컬 데이터는 한 번 만들고 코드만 바꿔 찍어야 바이트 비교가 된다 — `ui-states.mjs` 의
  `build()` 는 부를 때마다 별명에 시각을 붙인다.
- **워크트리 명령 격리** — heredoc · 변수 · 파이프 · `&&` 로 이은 `git` · `gh` 가 거절돼 에이전트마다 우회를 다시 찾았다.
  `local-env.md` 에 우회 셋을 적었다(#694). heredoc 안의 `${}` 도 걸린다.
- **정리** — 이 라운드의 워크트리 스물 남짓과 그 가지, 스크래치패드의 캡처 184장과 전후 그림 아티팩트(운영자가 지움)를 걷었다.
  로컬 · 원격 모두 `main` 하나다.
