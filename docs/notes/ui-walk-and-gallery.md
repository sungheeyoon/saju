## 도구 (`scripts/`, PR #51 에 커밋됨)

- `ui-dev.mjs` — 개발 서버를 **로컬 스택에 붙여** 3100 에 띄운다(`UI_PORT` 로 옮김)
- `ui-seed.mjs` — 계정·풀이·매칭을 세우는 손잡이. 접속값은 `supabase status` 에서만 받는다
- `ui-states.mjs` — `raw`(가입 전)·`new`(온보딩)·`full`(다 갖춤)·`pair`(수락된 궁합)
- `ui-walk.mjs <상태>` — 로그인된 크롬 창을 띄운다 / `ui-shots.mjs <폴더>` — 전부 찍는다.
  목록의 한 줄에 **`act`** 를 달면 「누른 뒤에만 서는 화면」도 찍는다(풀이 설문이 그것이다)
- 갤러리 HTML 을 엮는 스크립트는 **스크래치패드에만** 있다 — 다음 세션에서 다시 지어야
  한다. **처음부터 짓지 말고 발행된 것을 읽어 그림만 갈아 끼운다**(`Artifact` `read` →
  절마다 `<img src=data:...>` **앞의 두 장만** 치환 → 발행). 뒤에 오는 「이전 판」 그림과
  손으로 쓴 글이 그대로 이어진다. 읽어 온 파일에는 발행 때 붙는 `<!doctype>…<body>`
  껍데기가 있으니 **벗기고** 올린다

## 사람 서버를 죽이지 않고 둘째 서버를 띄우는 법

3100 에 사람이 쓰는 dev 서버가 있으면 같은 디렉터리에서 둘째 **`next dev`** 는 못 뜬다.
**`next start` 는 뜬다** — 산출물 자리를 옮기면 된다. 그 장치가 이미 있다:
`startCheckServer()`(`scripts/next-server.mjs`, `NEXT_DIST_DIR=.next-check`). 곁가지
작업본을 만들 것 없이 이것을 쓴다.

옛 방법(`git worktree` + `cp -Rc node_modules`)도 되지만 더는 안 쓴다 — 지을 것이 두 벌
이고 치울 것도 두 벌이다.

## 2026-09-08 에 는 것 — 훑기가 스스로 만들던 거짓말

**씨앗이 찍는 날짜가 화면의 약속이 된다.** 훑기가 `2026-12-31` 을 넣고 있어서
`/privacy` 와 `/signup` 이 프로덕션(종료 2026-10-31 · 파기 2026-11-30)과 다른 날을
찍었다. 훑는 사람은 문구를 보는 대신 씨앗을 읽게 된다.

**끝난 뒤를 찍을 때는 날짜가 아니라 시계를 옮긴다.** `/closed` 는 종료일이 지나야
서므로 일정 줄을 옛 날짜로 갈아 끼워 왔는데, 그러면 그 화면만 약속하지 않은 날을
든다. 지금은 `scripts/fake-clock.mjs` 로 그 서버의 시계만 민다:

- `next dev` 는 한 폴더에 하나만 뜬다 → 검사가 쓰는 자리(`.next-check` + `next start`)를
  그대로 쓴다. `startCheckServer({ whileRunning })` 이 **띄울 때만** 환경을 얹는다.
- **클래스 상속만으로는 모자라다.** `proxy.ts` 는 샌드박스 안에서 도는데 건너가는 것이
  직접 가진 속성뿐이라 물려받은 `Date.parse` 가 사라져 500 이 난다 — 정적 멤버를 손으로
  옮겨 심는다.

**날짜를 적는 자리는 하나다.** 시계를 미는 쪽이 `current_beta_schedule` 을 묻는다 —
상수를 다시 읽으면 정의가 둘이 되고, 그 둘은 갈린다(한 번 갈렸다). 훑기 안에 남은
날짜는 빈 로컬 DB 를 여는 `BETA_ENDS_ON` 하나뿐이다.

**훑기가 제 상한에 갇힌다.** 하루 전체 100회는 서비스에 걸린 벽이라 여섯 번 돌리면
도구가 막힌다((옛 메모 saju-cost-and-cron — 저장소 문서로 흡수됨)). 벽은 그대로 두고 — 낮추면 그 벽이 실제로 서는지를
못 본다 — `gpt-ui-walk` 표식이 붙은 줄만 어제로 미룬다.
