# 밤 조율자 라운드 — 스킬 설치 점검 · 이름 맞추기 · `/retro` · 읽기량 · 느린 시험 — 2026-10-06

> **권한 봉투(운영자 2026-10-06 밤):** 「이상하다고 보는 점 1~5 를 모두 처리하고 나중에 보고해라 — 수정, 너의 결정 다 동의한다」.
> 뒤이어 「스쿼시 머지 허락한다」. 운영 배포 · 실호출 · 운영 DB 는 이 라운드에 없다(문서 · 시험 파일만 바뀜).
> 요구사항이 아니다 — 지금 규칙은 각 원본과 ADR 0146 · 0147 이 든다.

## 시작한 까닭

전날 세션에 mattpocock/skills(`~/.agents/skills`)를 깔았다. 운영자가 「스킬이 권하는 대로 선순환이 서 있나」를 물었고, 점검에서
빈 곳 셋(wayfinder 라벨 없음 · 스킬 `code-review` 미연결 · 스킬이 부르는 `CODING_STANDARDS.md` 와 저장소의 코드 규칙 색인이 이어지지
않음)과 이상한 점 다섯(읽기 예산의 천장이 지금 값과 같다 · 역할 필수 읽기량 · 로컬 5초 시간 초과가 소음이 됨 · 돌아보기 길이 둘 ·
사람에게 어려운 문체)이 나왔다. 머지는 #504~#509.

## 조율자가 내린 판단

- **다리 문장 대신 이름을 맞췄다(#504).** 운영자 지적: 「같은 개념이면 이름만 바꾸면 되지, 왜 적어서 토큰을 올리나」. 옛 기록(ADR
  본문 · 노트 · changelog 지난 줄 · 마이그레이션 주석)의 `CONTEXT.md` 는 그날의 기록이라 두었다.
- **`/code-review` 는 내장을 둔다.** 개인 스킬은 내장 스킬을 덮고 이름은 frontmatter `name` 이 정한다(공식 문서). Matt 의 두 축 검토는
  원본을 가리키는 한 줄짜리 `~/.claude/skills/spec-review` 로 두었다 — 내장은 버그를, 이것은 규칙 · 이슈 대조를 본다. 저장소 밖 설정이다.
- **선순환 셋째 걸음만 `/retro` 로(#505, ADR 0146).** 첫 · 둘 · 넷째(읽고 시작 · PR 마다 문서 · 노트)는 `/retro` 가 하지 않는다.
- **로컬 5초는 그대로, 느린 시험이 제 몫을 든다(#506 · #509).** `vitest.config.mts` 의 주석이 5초를 일부러 둔 까닭(달아나는 시험)을
  적고 있어 전역을 넓히지 않았다. #509 는 시험이 안 읽는 운 표를 짓지 않게 해 `needComplement` 를 혼자 18.9초 → 1.2초로 줄였다.
- **읽기 예산은 눈금 천장으로(#508, ADR 0147).** 파일 이름 한 글자로 붉어지던 잠금을 5,000 눈금 · 여유 2,500 이상 · 늘쩡한 천장 금지 ·
  올리면 ADR 줄로 바꿨다. 필수 읽기는 「닿을 때 여는 것」 칸으로 옮겨 feature 177,516 → 91,907.
- **사람용 안내는 에이전트 길 밖에(#507).** `docs/guide.md` 는 어느 역할 문서도 가리키지 않는다.

## 배운 것

- **auto 모드의 분류기가 무인 라운드를 막는다.** 운영자의 「진행」만으로는 `gh pr merge --auto` 가 「Merge Without Review」로 막혔고,
  그 뒤 에이전트 띄우기 · 읽기 전용 `gh pr view` 까지 막혔다. 권한 설정 파일을 고치는 것은 「Self-Modification」으로 막힌다. 머지는
  운영자가 대화에서 「스쿼시 머지 허락」을 말한 뒤에 섰다. 무인 라운드를 열 때 머지 허락을 봉투에 말로 받는다.
- **쌓은 PR 은 앞 PR 이 squash 되면 다시 합쳐야 한다.** #508 은 #505 의 squash 뒤 넷 파일이 글자 충돌했다 — `merge:sim` 이 먼저 잡았다.
  이 기계의 `gh` 에는 `pr update-branch` 가 없어 `gh api -X PUT repos/<o>/<r>/pulls/<n>/update-branch` 로 했다.

## 헤맨 것 — 다음 `/retro` 의 입력

- `docs/agents/delegation/local-env.md` · `working.md` 의 `node_modules` 복사가 `cp -Rc`(macOS) 뿐이다. 이 기계(Linux/WSL2)는
  `cp -a --reflink=auto` 또는 심볼릭 링크였다(세 에이전트).
- `reading` 역할 문서에 `scripts/` 잠금 시험과 시험 시간(`POPULATION_TIMEOUT_MS`), 시험 시간 재는 법(JSON 리포터 `duration`)이 없다.
- 워크트리 샌드박스는 변수를 든 복합 셸 명령을 거절한다 — 어디에도 안 적혀 있다.
- `docs` 역할: 옛 기록(ADR 본문 · 노트 · 마이그레이션)도 경로가 옮겨지면 고치는지가 역할 문서에 없어 ADR 0090 을 grep 했다.
- `README.md` 는 `reading` 이 읽는다 — 「에이전트 길 밖」 브리프가 틀렸다.
