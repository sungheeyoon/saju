## 헤맨 것 · 배운 것

- **smoke 시나리오를 새 계정 기준으로 쓰고 그렇다고 안 밝혔다** — 운영자 계정은 내 사주가 이미 있어 「이 사주가 내 사주 맞나요?」가 안 서고, 저장된 내 사주와
  같은 입력일 때만 이어진다(`app/save-for-reading.tsx` `useCarriedTasteResume`). 시나리오는 계정 상태(새 · 내 사주 있음 · 풀이 있음)를 먼저 가른다.
- 화면을 보고 있으면 완성 소식은 곧바로 읽음이 된다 — 「다른 화면에서 받는 소식」을 보려면 누른 뒤 홈으로 가야 한다고 시나리오에 적어야 했다.
- 확정 문구가 줄 이름 글자를 품으면 e2e `getByText` 가 두 요소에 걸린다(#612 → #616). 문구 PR 의 시험은 그 화면의 e2e 를 글자로 한 번 훑는다.
- 에이전트 보고의 함정 — `--auto` 뒤 main 이 붉으면 PR 이 그 실패를 안고 막힌다(#613, `update-branch` 로 풀었다) · 다른 PR 의 머지만으로 읽기량이 넘는다(#617) ·
  CLI 로 PR 본문에 그림을 못 붙여 원격에 그림 가지를 세웠다(머지 뒤 지웠다).
