# 세션 기록

에이전트 세션의 메모리에만 있던 판단 기록을 2026-09-22 에 저장소로 옮겼다(ADR 0090). **요구사항도
규칙도 아니다** — 무엇을 만드는가는 `docs/prd.md`, 결정은 `docs/adr/`, 낱말은 `GLOSSARY.md`, 일하는
법은 `docs/agents/delegation.md` 가 답한다. 노트는 **코드가 왜 이 모양인지** 되짚을 때 연다. 날짜가
붙은 문단은 그날의 사정이고, 코드와 어긋나면 코드가 맞다. 머리말의 「지금은」 줄이 그 글이 낡은 뒤의
자리를 가리킨다.

두 표에 모든 파일이 있는지는 `scripts/code-rules.test.ts` 가 잰다. **새 노트는 「최근」 맨 위에 한 줄을 더하고**, 그 표가
여덟 줄을 넘으면 가장 오래된 줄을 「차례」로 옮긴다 — 「최근」이 자라지 않아야 조율자가 먼저 읽는 양이 노트 수와 함께
늘지 않는다(시험이 여덟을 잰다).

**라운드 노트는 다른 문서에 없는 것만 든다** — 권한 봉투 · 조율자의 판단과 까닭 · 배운 것 · 헤맨 것. 머지 목록 · 배포 SHA ·
smoke 값은 PR · 배포 기록 · `docs/product/gaps.md` 가 원본이고 노트는 번호로 가리킨다. `shots/` 에는 화면마다 대표 몇 장만
두고 전후 전부는 PR 본문의 첨부다. 둘 다 `docs/agents/delegation.md` 「세션 기록」 · 「끝났다는 것」이 원본이다(2026-10-05).
