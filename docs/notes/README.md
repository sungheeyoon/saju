# 세션 기록

에이전트 세션의 메모리에만 있던 판단 기록을 2026-09-22 에 저장소로 옮겼다(ADR 0090). **요구사항도
규칙도 아니다** — 무엇을 만드는가는 `docs/prd.md`, 결정은 `docs/adr/`, 낱말은 `CONTEXT.md`, 일하는
법은 `docs/agents/delegation.md` 가 답한다. 노트는 **코드가 왜 이 모양인지** 되짚을 때 연다. 날짜가
붙은 문단은 그날의 사정이고, 코드와 어긋나면 코드가 맞다. 머리말의 「지금은」 줄이 그 글이 낡은 뒤의
자리를 가리킨다.

이 목록에 모든 파일이 있는지는 `scripts/code-rules.test.ts` 가 잰다. 새 노트는 날짜와 함께 여기
한 줄을 더한다.

## 옮기지 않은 것 — 저장소가 이미 든다

세션 메모 63벌 중 열여섯이 위 열셋이 됐다. 나머지는 옮기지 않았다 — 같은 것을 두 자리에 적으면
하나가 낡는다.

| 메모가 들던 것 | 지금 어디 |
| --- | --- |
| 일하는 법 · 권한 · 로컬 환경의 함정(존댓말, 한글 문구는 표로, 되돌리기를 선택지로 안 올림, worktree, `git diff` 먼저, 실호출, CSS 캐시, dev 서버 하나, `[SENSITIVE]`) | `docs/agents/delegation.md` |
| 배포 순서 · `db push` 는 따로 · 넓히고 나중에 좁힌다 · 운영 확인에 드는 열쇠 · 접속값 여섯 · 비용 한도 · 크론 실패 | `docs/ops/runbook.md` |
| 무엇을 고쳤으면 무엇을 돌리나 · 실호출 시험 셋 · CI 차선과 gate | `docs/agents/test-map.md` · ADR 0082 |
| 구조 후보 라운드 여덟(ADR 0073~0084)과 그 교훈 「후보 문장은 반쯤 틀린다」 | 이슈 #88 · 각 ADR · `docs/agents/delegation.md` |
| 출시 세 단계 · 버튼 용어 · 보류한 것 · 열린 결정 | `docs/prd.md` §7.0 · §3.2 · `docs/product/gaps.md` |
| 가입 코드 · 공유 링크 · 프로필과 얼굴 · 설문 둘 · 풀이권 예외 · 궁합은 저장 없이 · 자리가 붙은 사실 목록 · 관문은 `proxy.ts` | ADR 0040 · 0042 · 0043 · 0053·0054 · 0061·0062 · 0063·0064 · 0066~0070 · 0041 |
