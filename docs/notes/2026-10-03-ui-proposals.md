## 결정 · 판정

- 비로그인 홈의 입력폼 모양은 #470 이 확정이다. 로그인 뒤 폼(`/compat` · 온보딩 · 수정 · 사람 저장)은 옛 목록 줄 모양 그대로 — 맞출지는 아직 안 정했다.
- `/help` 의 「입력한 생년월일시는 저장되나요?」는 G-66 `[변호사 검토 필요]` 에 걸려 세우지 않았다.
- 버린 시안의 판단거리(성별 기본값 「여자」를 없앨지 — `src/lib/input` 이라 UI 밖, F 의 장식 한자, G 의 수(水) 파랑 강조)는 시안과 함께 닫혔다.

## 배운 것

- **「~가 별로」는 무엇이 별로인지 먼저 되묻거나 시안 하나로 확인한다.** 흐름 시안 넷을 통째로 버렸다.
- **병렬 아홉은 이 기계에 무겁다.** 로컬 Supabase 스택 8 + dev 서버 + Playwright 로 load 48/12코어. 에이전트마다 로그인 뒤 화면 · 곁 폼 · e2e 를
  다 하게 하지 말고, 시안 단계는 **로그인 전 첫 화면만 · DB 없이 · e2e 없이** 찍게 하면 충분했다. 끝난 워크트리는 바로 걷어야 스택 자리(1~9)가 빈다.
- 스크린샷 비교는 **같은 값 · 같은 상태 이름**(`<화면>-<상태>-<폭>-after.png`)을 브리프에 박아야 한 장에 나란히 놓인다.
- 공용 폼 부품을 고치면 그 부품을 쓰는 다른 화면이 같이 바뀐다 — 3010 다듬기 1차가 로그인 뒤 화면까지 번졌다가 되돌렸다.
- 운영이 「예전 화면」인 것은 대개 **머지 ≠ 배포**(ADR 0110) 때문이다. 로그인된 브라우저는 비회원 첫 화면 대신 회원 머리 문구를 보인다.
- 3010(DB 없는 dev)에서 `/privacy` 는 본문이 안 선다 — 보유기간 날짜 · 처리자를 DB 에서 읽고 못 읽으면 조항을 세우지 않는다(ADR 0078). 고장이 아니다.

## 역할 문서에 없어서 헤맨 것 (운영자가 말할 때까지 역할 문서는 고치지 않는다 — 목록만)

- 로컬 스택 자리 1~9 가 다 찼을 때 무엇을 하나(가짜 Supabase 주소로 로그인 전 화면만 · 수동 자리는 스크립트가 못 본다)
- 로그인 뒤 화면을 찍는 법(`scripts/ui-states.mjs` `build()` + 쿠키, `scripts/ui-shots.mjs`), seed 스크립트는 워크트리 폴더에서 돌아야 한다
- ego-browser 는 `localhost` 쿠키를 모든 세션 · 포트가 함께 쓴다 — `<이름>.localhost:<포트>` 로 비킨다. 오늘 여러 번 멈췄다
- 에이전트들이 같은 scratchpad 를 함께 쓴다 — 하위 폴더를 나눈다
- 한 워크트리에서 dev 서버와 Playwright 시험 서버를 같이 못 띄운다 — e2e 는 다른 워크트리에서, `.env.development.local` 도 복사
- 워크트리 격리가 `&&` 로 이은 git 명령 · 셸 `for` 를 거부한다
- 핫 리로드라 남의 dev 서버 위에서 고치면 「전」 그림이 사라진다 — 먼저 찍는다
- 「안 쓰는 코드 찾기」 도구(knip · `tsc --noUnusedLocals`)가 test-map 에 없다
- runbook 「묶음 배포」 5 는 「그 일의 이슈」, ops 역할 문서는 「그날 노트」에 적으라 한다 · 배포 워크트리 안에 둔 스크린샷은 걷을 때 같이 지워진다
