## 배운 것

- **운영자는 덱이 스와이프 앱처럼 계속 채워지는 줄 알았다.** 하루 열 명 목록이 줄다 비는 모양은 PRD 에 적혀 있었지만 운영자의 머릿속 모양과 달랐다 — 지도 상한을 묻는 질문에서 드러났다. 화면을 물을 때 그 화면이 기대는 데이터 모양(몇 명이 언제 오나)을 먼저 확인한다.
- **예시 셋으로는 붐비는 화면을 판단할 수 없다.** 시안을 비교할 때 인원 조절을 붙였다가 시안과 함께 지웠더니 운영자가 곧바로 「몰린 날을 어떻게 보라는 거냐」고 물었다. 미리보기 예시를 제품 쪽에 열여덟으로 남겼다. (정정 2026-09-28 — 같은 날 저녁 #288 이 미리보기와 예시를 걷었다, 아래 「저녁」.)
- 역할별 시안 에이전트는 main 트리에서 **파일을 하나씩만 쥐게** 하면 워크트리 없이도 부딪히지 않았다(시안 파일 · 전환 막대 · 문맥 하나를 조율자가 먼저 깔았다).
- main 폴더에 dev 서버가 떠 있으면 같은 폴더에서 e2e 가 두 번째 `next dev` 를 못 띄운다(「Another next dev server is already running」). 남아 있던 워크트리에서 돌렸다. 첫 컴파일은 웹서버 대기 120초를 넘길 수 있다 — 한 번 더 돌리면 캐시로 선다.
- 마이그레이션이 든 #281 을 `db push` 전에 머지했다(브리프가 그렇게 시켰다) — 규약은 push 뒤 머지다. 넓히기라 옛 앱은 안전했지만 다음부터 브리프에 「CI 초록에서 멈춤」을 적는다(#283 은 그렇게 했다).
