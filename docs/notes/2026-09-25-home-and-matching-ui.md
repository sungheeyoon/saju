## 고르는 법 — 시안을 3000 에서 넘겨 보게 했다

`/me/matching/preview?variant=` 에 시안 셋(틴더형 · 범블형 · 줄인 지금) → 기운 표시 셋 → 끌기 있음/없음 · 단추 모양 둘 →
사진 여러 장(막대 · 탭 · 편집 흉내)을 쿼리 단추로 넘겨 보게 했고, 운영자가 **A · 기운 1안 · 끌기 없음 · 글 고정**을 골랐다.
이긴 모양을 본체에 다시 쓰고 시안 파일은 지웠다(커밋에 안 들어감). 디자인 에이전트에게 맡길 때 「이 앱이 오행을 이미 어떻게
그리는가」(궤도 지도의 알 · 점선 · 차오름)를 먼저 읽게 한 것이 흰 알약 같은 낯선 모양을 걷는 데 들었다.

## 배운 것

- **화면을 통째로 숨기기 전에 그 화면이 드는 약속을 grep 한다.** 폰에서 저장된 출생 정보를 뺐더니 로그인 e2e 셋이 붉었다 —
  「이 사주가 무엇으로 계산됐나」(ADR 0002). 한 줄로 되살렸다.
- **로컬 e2e 초록 ≠ CI 초록.** 서버가 빠른 로컬에서는 0.46초 틈에 ↶ 를 눌렀고 CI 에서는 놓쳤다. 떠나는 카드를 재는 시험은
  같은 일을 하는 두 길을 `.or()` 로 받는다. 푸시 뒤 `gh run list --branch main` 을 배포 전에 본다.
- 3000(운영 DB)을 사용자가 보는 동안 검사는 로컬 스택 + `.next-check` 빌드 + `next start --port 3100`(`PLAYWRIGHT_PORT=3100`)
  으로 돌렸다. 스크린샷은 `scripts/ui-states.mjs` 의 `build('full'|'board')` 쿠키로 찍고 임시 스크립트는 지웠다.
- 흰 글 위 가독은 사진을 흰 PNG 로 바꿔치는(`page.route`) 최악 사례로 잰다.
