# 최적화 라운드 — 기다림과 겹친 왕복 걷기

요구사항이 아니다 — 왜 이 모양이 됐는지의 사정이다. 잰 값과 방법은 각 PR 본문(#537 · #538 · #539), 결정은 ADR 0016 · 0076 ·
0115 의 2026-10-08 덧이다. 운영에는 배포하지 않았다.

## 왜 · 무엇을 골랐나

운영자가 외부 리뷰(「서버가 끝날 때까지 화면이 기다리는 곳」 다섯)를 가져왔다. 조율자가 코드로 견준 판정:

- **고른 셋** — 액션 뒤 `router.refresh()` 중복(#538), 덱 지나치기의 기다림(#539), 풀이 조회 고리(#537).
- **미룬 둘** — 채팅 방마다의 색 RPC(`Promise.all` 이라 합이 아니라 최대값, 일괄로 바꾸면 마이그레이션), 홈의 참여 열기
  (이미 둘째 물결에서 나란히 돈다, `after()` 로 옮기면 쿠키를 미리 꺼내야 한다). 얻는 것에 비해 드는 것이 크다.
- 운영자 덧: 서른 곳을 일괄로 지우지 말고 대표 동작 2~3개로 먼저 재기, 동의 · 풀이권 · 수락은 서버 확정 그대로, 전후 값을 남기기.

## 배운 것 — Next 16.3 의 두 표지

- 액션 안의 `revalidatePath` 는 경로와 상관없이 「다시 그렸음(정적과 동적)」을 세운다(`revalidate.js` 의
  `TODO: only revalidate if the path matches`). 그래서 응답이 지금 화면을 싣고, 누른 쪽의 `router.refresh()` 는 같은 화면을 한 번 더
  그렸다 — 메모 저장 · 목록에서 빼기 · 풀이 완료 모두 `_rsc` 하나가 더 나갔다.
- `refresh()` 는 그 표지를 「동적만」으로 **덮는다.** 뒤에 부르면 브라우저가 미리 받은 화면(prefetch)을 안 버린다. C(#537)가
  `refreshPaths` 에서 먼저 찾았고, A(#538)는 표 끝에 `THIS_SCREEN` 을 붙여 같은 함정에 들었다가 조율자 검토에서 고쳤다 — 이제
  `refresh()` 는 표의 차례와 상관없이 지금 화면을 먼저 다시 그린다(시험이 잠근다).

## 조율자의 판단

- **#539 는 결정 점검표 「실패했을 때 열리는가 닫히는가」에 걸렸다.** 저장 전에 탭을 닫으면 지나치기가 서버에 안 남고 다음에 그
  카드가 다시 선다 — 운영자가 받아들이고 머지했다(2026-10-08). 요청 중 다음 누름은 순서 보장 대신 막기를 골랐다 — 실패가 되돌릴
  것이 늘 한 사람 몫이게.
- **C 가 브리프 밖 파일(`app/refresh.ts`)을 고쳤다** — `refreshPaths` 안만이라 받았다. 같은 파일 · 같은 e2e 파일을 A 와 함께 고쳐
  #538 → #537 → #539 차례로 머지했고, #537 의 글자 충돌(`e2e/signed-in.spec.ts`)과 경계 시험의 남은 줄은 조율자가 풀었다.

## 헤맨 것

- **WSL 6GB 상한** — 워크트리 셋이 e2e · 빌드를 나란히 돌리자 스왑까지 차서 에이전트가 10분씩 멈췄다. Docker Desktop 도 같은
  VM 이다. 이 기계(16GB)는 `%UserProfile%\.wslconfig` 를 `memory=10GB` · `swap=8GB` 로 올리고 `wsl --shutdown` 으로 재시작했다 —
  세션 · 에이전트 · Docker 가 다 끊긴다. 상한 안에서도 무거운 실행은 `flock /tmp/saju-heavy.lock <명령>` 으로 한 번에 하나만 돌렸다
  (워크트리 격리가 이 명령을 막아 스크립트 파일 안에 적었다).
- 메인 체크아웃의 `node_modules` 가 lock 보다 뒤처져 있었다(`web-push` 없음, Next 16.3.6 vs lock 16.3.8) — 복사한 워크트리의
  typecheck 가 붉었고 `npm ci` 로 맞췄다.
- WSL 에서 `lsof -ti tcp:<포트>` 가 듣고 있는 `next-server` 를 못 찾았다 — `ss -ltnp` · `pgrep -af "port <포트>"` 는 찾았다.
- WSL 재시작은 `/tmp` 를 비운다 — 그 아래 둔 측정용 워크트리가 사라지고 `git worktree list` 에만 남았다(`git worktree prune`).
- 이 넷은 `docs/agents/delegation/local-env.md` 「로컬 환경의 함정」에 둘 만한데, 그 표를 필수로 읽는 역할(coordinator · ops)이
  읽기량 천장에 닿아 있어 이번에는 노트에만 둔다.
- 측정 숫자는 로컬 스택 기준의 전후 차이다. 운영 값은 배포 뒤에 따로 잰다.
- 다음 후보: 풀이 완료를 라이브 채널로 알리면 조회 고리를 걷을 수 있다(`reading_run` 에 알림 트리거가 없어 마이그레이션이 든다).
