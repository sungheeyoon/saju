## 배운 것

- **시안 문구를 확정이라 브리프에 적어** 평서체 · 옛 이름이 제품에 들어갔다 — 규칙을 대장 먼저로 바꾼 까닭이다.
- **문구는 말투보다 사실 먼저** — 「답하면 궁합이 열린다」(거절도 답이다 → 「수락하면 인연 궁합이 열려요」), 「지금 보이는 궁합은 그대로」(처음 생성 실패엔 거짓)를 외부 리뷰가 잡았다. 문구가 말하는 상태 전이를 코드로 확인한다.
- **localhost 폴더에 머지된 코드를 계속 받아 넣으면** Turbopack 개발 캐시(`.next/dev`, 16.1 부터 기본 켜짐)가 불어나(3.4GB · 44분에 686MB) 탭 이동이 「Rendering…」에서 몇 분 멈췄다 — 운영과는 무관(배포는 완성본). 운영자가 보는 동안엔 받지 않고, 받을 땐 알리고 캐시를 비워 다시 켠다.
- 에이전트가 「앱이 Pretendard 를 싣지 않는다」고 잘못 보고한 것을 조율자가 확인 없이 옮겼다 — `globals.css:2` 가 이미 싣고 있었다.
- CI 에서만 붉던 폰 첫 화면 시험은 웹 글꼴이 오기 전 대체 글꼴로 잰 탓(#344 가 여백으로 여유를 만들었다). `undici` high 공지 여섯도 같은 날 붉혔다(#344, 7.30.0).
