# 매칭과 관계 지도의 읽는 흐름

2026-09-24 사용자 요청으로 매칭의 움직임과 지도, 풀이 헤더, 지나친 인연 카드를 점검했다.

- 넘김이 손을 놓은 자리에서 12px로 되감긴 뒤 700ms 멈췄다. 방향과 마지막 거리를 유지하고 100ms 확인 뒤 360ms로 퇴장한다. 서버 저장 실패는 제자리로 돌아온다. 오른쪽 스와이프는 기존 확인 창을 유지한다.
- 폰의 지도 부모가 후보 id로 다시 생성돼 다음 후보의 궤도 이동이 끊겼다. 지도는 유지하고 글과 사진만 교체한다. 후보가 바뀔 때 다른 후보의 각도를 다시 밀지 않는다.
- 지도는 첫 보완 기운만 선으로 그렸지만 설명은 보완 기운 전부를 말했다. 이제 설명과 같은 highlights를 선과 채움에 사용한다.
- 홈 관계 지도는 저장한 사람과 이미 본 풀이·궁합만 나타낸다. 안쪽/바깥은 친밀도나 적합성 순위가 아니다. 선택한 사람에 관련된 궁합 선과 점수를 강조하고, 선택 뒤에도 기존 범례를 유지한다.
- 지나친 인연은 사람의 일간 색 아바타와 보완 기운 배지만 색을 쓴다. 아래 본문은 앱의 종이색과 중립 단추다.
- 만든 풀이의 대상 화면에서 사주/사주풀이 토글을 제거했다. 저장한 사람 상세 화면의 기존 이동은 유지한다.
- 새 한국어 제품 문구와 동의/요청/복원 정책은 추가하거나 바꾸지 않았다.

## 검증 (2026-09-25)

- 분리 워크트리에서 typecheck · lint · 프로덕션 build · 브라우저 비밀 검사를 통과했다. 빌드는 CI의 공개 Supabase 자리표시자를 사용했다.
- 조율자 작업본에서 전체 단위 시험 2,335건과 typecheck를 통과했다. 첫 워크트리 전체 검사는 병렬 실행의 시간초과가 있어 worker를 둘로 제한했다. 이때 새 노트의 차례 등록 누락을 발견해 보완했다.
- 조율자가 localhost:3000 브라우저에서 왼쪽 드래그 · 되돌리기 · 오른쪽 드래그 확인 창 취소 · 지나친 인연 복원을 확인했다. 데스크톱과 모바일 폭 400px에서 시각 확인했다.
