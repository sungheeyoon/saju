## 배운 것

- 공용 부품에 표현 갈래(`presentation`)를 달아 한 화면만 바꾸면, 나머지를 맞출지는 반드시 간극 대장의 줄이 되어야 한다(#475 가 규칙으로).
- 한 주소의 한쪽 뜻을 바꾸면 반대쪽 상태까지 상태표로 걷는다 — #477 의 표가 「가입을 안 마친 사람」 · 「옛 복귀 주소의 탭」을 잡았다.
- 에이전트 셋이 모두 「하네스가 `&&` · 반복문 · 변수 든 명령을 거절한다」를 따로 밟았다. 스크립트를 파일로 쓰고 부르면 넘어간다.
- 「고친 뒤엔 전이 사라진다」 — 폼 에이전트는 WIP 커밋 뒤 `git checkout HEAD~1 -- app` 으로 옛 코드를 되살려 전을 다시 찍었다.
  전체 페이지 그림에서는 `nav.fixed` · `.sticky` · `nextjs-portal` 을 숨겨야 폼을 안 덮는다.
