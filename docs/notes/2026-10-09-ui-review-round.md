## 확인 못 한 것

- **로그인 smoke**(사람 목록 · 운영자 신고 화면)와 **G-82 실호출** — 운영 계정이 드는 운영 검증이라 남았다.
- **폰에서 신고할 메시지를 고르기가 충분히 쉬워졌는지** — 안내를 한 줄로 줄여 위 대화가 두 말풍선 보이는 것까지만 쟀다. 긴 방에서
  고르는 손놀림은 안 쟀다.
- **#564 의 `match:mobile` e2e 실패**(`[data-deck-fit]` 이 둘 — 로딩 뼈대와 실제 카드가 함께 선 것으로 보임)는 재실행에 통과했다.
  재실행 통과만으로 흔들리는 시험이라고 정하지 않는다. 그 실행의 trace 는 저장소 밖 로컬(`saju-evidence/2026-10-09-ui-round/`)에 남겼다.
- 운영에서 맛보기 글이 목차 첫 절에 서는 모습 — 실호출이라 로컬에서 심은 글로만 봤다.

## 남은 결함 · 열린 것

- **G-86** — 인연 요청 확인 창이 수락 뒤 대화방이 열린다는 것을 말하지 않는다. 운영자 답 전이라 문구를 안 넣었다.
- **G-85** — 「더보기」를 걷어 `more_clicked` 는 배포일부터 0 이다. **전환이 떨어진 것으로 읽지 않는다.**
- **찍는 도구** — `scripts/ui-dev.mjs` 가 맛보기 비밀값(`TASTE_BROWSER_SECRET` · `TASTE_IP_SECRET`)을 안 줘서 갤러리가 맛보기를 한 번도
  못 찍었다(이번엔 e2e 의 값으로 띄웠다). 로딩 뼈대는 이번에도 커밋 안 한 미리보기 페이지로 찍었다(G-84).
- **읽기량 천장** — 넷을 합치자 coordinator · reviewer 가 넘어 #566 에서 G-85 · G-86 줄과 화면 표 한 칸을 깎았다. 남은 여유는
  reviewer 22 · coordinator 42 · ui 67 · ops 86 바이트다. 다음 변경마다 깎기보다 필수 읽기의 상세를 필요할 때 여는 문서로 옮기는 정비가 맞다.

## 판단과 까닭

- **검토 셋은 화면 무리로 갈랐다**(첫 화면 · 관문 / 로그인 뒤 / 인연 · 운영자 · 로딩) — 같은 그림을 두 번 안 보게.
- **고침 넷은 파일로 갈랐다**(첫 화면 · 공유본+가입+타일 · 안내 화면 · 신고 차단) — 겹친 것은 문서(ADR 0109 · 문구 대장 · gaps)뿐이었고
  머지마다 main 을 합쳐 풀었다. 대장 절 번호는 머지 차례로 20~23.
- **전후는 네 PR 을 합친 로컬 가지와 main 을 같은 DB · 같은 스크립트로** 찍었다 — 그림마다 상태가 같아야 차이가 고친 것만 남는다.

## 배운 것

- **공유본 HTML 에서 글자를 세면 둘로 센다** — 서버가 그린 글자와 페이지 데이터(RSC 페이로드)에 같은 글자가 한 번 더 실린다.
  `check-share.mjs` 는 그린 링크(`>…</a>`)만 세게 고쳤다(#563).
- **효과가 입력 글자만 지켜보면 같은 입력 재제출에 안 돈다** — #565 의 A1 이 그것이었다. 전후 그림에서도 보였는데 조율자가
  「내려간다」고 보고했고, 바깥 리뷰가 잡았다(#568). 그림을 봤으면 그 그림이 말하는 것을 재어 적는다.
- **GitHub 러너가 브라우저 내려받기에서 403** 을 받으면 시험이 아니라 기반이다 — 실패한 작업만 다시 돌렸다.

- 촬영 스크립트의 무리 감싸기를 손으로 고치다 블록이 엇물려 한 무리가 안 돌았다 — 출력 「0 →」을 보고 알았다.
