# 2026-10-08 밤 — 스스로 갱신과 새 메시지 웹 푸시

요구사항도 규칙도 아니다 — 무엇이 섰는지는 ADR 0155 · 0156 과 PRD §7.1(`docs/product/prd/chat.md`), 남은 일은 간극 대장의
G-26 · G-71 ~ G-75 가 든다(G-76 — 라이브 갱신이 활동을 적던 것 — 은 같은 날 고쳐 닫았다). 여기는 그 문서들에 없는 사정만이다.

## 권한 봉투

- 운영자가 채팅 안전 베타의 「실시간이 아니다」를 바꾸는 것을 승인했다 — 앱 안 자동 갱신 · 탭과 기기 동기화 · 새 메시지의 외부 통보.
  접속 상태 · 타이핑 · 상대 읽음 표시는 범위 밖이다.
- 유료 서비스 · 플랜 업그레이드는 들일 뜻이 있다고 했지만 **구매 · 결제 · 계정 변경 · 운영 배포의 포괄 승인은 아니다.**
- 운영 `db push` 는 밤사이 하지 않는다(머지 · 배포와 함께). 제공자 선정은 조율자에게 맡겼다(「알아서」) — 표준 웹 푸시를 골랐다.

## 판단과 까닭

- ADR 번호는 0156 · 0157 로 쓰였다가 0155 · 0156 으로 옮겼다. 0155 를 든 초안 PR(#524)이 main 에 없어 번호 빈틈을 시험이 막았다.
- 읽기량 천장(ADR 0147)을 올리지 않으려고 PRD 의 §7.1–7.2 를 `docs/product/prd/chat.md` 로 떼었다 — 가장 큰 영역 파일(`roadmap.md`)이
  feature · reviewer 의 동적 라우트 값이었다. 간극 대장은 닫힌 줄의 회고 문장을 걷고 긴 메모 셋(G-20 · G-21 · G-23 · G-25)을 기록
  파일의 「표에서 옮김」으로 내렸다 — 조율자의 읽기량이 34바이트 남아 있었다.

## 헤맨 것

- **WSL 의 Docker** — Docker Desktop 이 꺼져 있으면 `db:start` 가 Docker 에 못 닿고, `npx supabase status` 는 샌드박스 안에서 같은
  증상을 낸다(밖에서만 됐다). `docs/agents/delegation/local-env.md` 에 줄로 옮겼다.
- **pgTAP 한 파일** — `supabase test db <파일>` 은 `00_helpers.sql` 을 함께 주어야 돈다(같은 표에 옮겼다).
- **워크트리 격리**가 막는 범위가 local-env.md 에 적힌 것보다 넓었다 — `xargs`, 셸 변수를 인자로 받는 `sed` · `node`, `git` 출력을 받는
  파이프. 스크래치패드의 `node` 스크립트에 절대 경로를 글자로 주는 길이 됐다(같은 표).
- **e2e 의 남은 서버** — 시간 초과로 끝난 e2e 가 dev 서버를 남기면 다음 실행의 `reuseExistingServer` 가 그것을 붙잡는다. `match.spec` 은
  `--workers=1` 이어야 하는데 그 사실이 `package.json` 스크립트와 `verify.yml` 주석에만 있었다(같은 표).
- **CSP** 는 `next.config.ts` 에 산다 — 소켓 주소(`wss:`)를 열 자리를 찾느라 돌았다.
- **GitHub** 가 한동안 새 가지 푸시를 500 으로 거절했다 — 저장소 쪽 문제가 아니었고 잠시 뒤 됐다.
