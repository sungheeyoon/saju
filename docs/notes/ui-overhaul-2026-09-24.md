# UI 전면 개편 — 부드러움 · 「점점」 (2026-09-24)

> **지금은:** 화면의 모양과 메뉴는 ADR 0109 와 PRD(§3.0 · §4.2 · §6.1.1 · §7.1 · §7.4.1)가 든다. 이 노트는 그 결정에 이른 **사정과
> 일하는 법에서 배운 것**이다.

## 무엇이 일어났나

한 세션에서 조율자 + 워크트리 에이전트로 여섯 라운드를 돌았다. main `57e0715` → `069bcc5`(Production `3d54d56`).

1. **1차 — 재배치 시안 아홉**(A1~F · R). 기존 부품을 다시 늘어놓았다. 운영자: 「카드를 대충 재조합해 구조만 다시 나열한 느낌 ·
   폰트에 위계가 없다 · 버튼이 버튼 같지 않다 · 창의성이 없다」.
2. **2차 — 디자이너 역할 아홉**(편집 · 핀테크 · 먹과 인장 · 정보 디자인 · 관계 지도 · 스위스 · 부드러움 · 시스템 다듬기 · 밤하늘).
   브리프에 **타입 스케일 · 버튼 체계를 수치로** 적게 하고 **스크린샷을 보고 두 번 고치게** 했더니 수준이 뛰었다.
   운영자가 **관계 지도(orbit)** 와 **부드러움(warm)** 을 골랐다.
3. **3 · 4차** — 두 스타일로 매칭 · 풀이 · 채팅을 그리고, 부드러움을 채택한 뒤 관계 지도를 부드러움으로 다시 그려 홈 · 매칭에 섞었다.
4. **5차 — 실제 화면으로 이관.** 기초(브랜드 상수 · 토큰 · `app/ui/` · 머리글)를 한 에이전트가 먼저 올리고, 화면 일곱(홈 · 매칭 ·
   풀이 · 채팅 · 사람·궁합 · 계정·소식 · 공개)을 나란히. 서비스 이름은 운영자가 **「점점」** 으로 정했다(점으로 만든 관계 지도 · 점술의 「점」).
5. **6차 — 되찾기.** 운영자: 「옮기면서 쇠퇴했다」. 지운 시안 자리를 `git archive fb3c3a1^ app/me/home-preview` 로 되살려 **원본과
   지금을 나란히 놓고 달라진 목록부터 쓰게** 했다 — 홈 지도(색 띠 → 중립 궤도) · 내 사주 카드 차례 · 매칭(사진 비율 · 점수 자리 ·
   지도의 「거리 = 관계, 각도 = 채우는 오행」) · 풀이 두 칸(레이아웃이 목록을 든다) · 채팅 두 일간 색(`my_match_scope`).
6. **기본 아바타 색** — 사진 없는 후보의 이니셜 바탕을 그 사람 **일간 오행**으로(글자로는 안 알림). 마이그레이션
   `20261021090000` 이 두 후보 문에 `avatar_element` 를 더했다(원격 `db push` 함). 카드 · 기운 칸 · 지도는 여전히 「채워 주는 기운」.

## 배운 것 — 다음 라운드가 같은 자리에서 잃지 않게

- **「재배치」로 시키면 재배치가 나온다.** 역할(누구처럼) + 수치 기준(타입 스케일 · 버튼 세 단 · 44px · AA) + **보고 고치기 두 번**을
  브리프에 넣어야 디자인이 나온다.
- **옮길 때는 원본을 곁에 둔다.** 시안을 제품으로 옮기는 에이전트는 차가운 시작이라 원본이 **왜** 좋았는지 모른다 — 색을 더하고
  장식을 붙이며 명료함을 잃었다. 옮기는 브리프에 원본 코드 · 스크린샷 경로와 「달라진 목록을 먼저 쓴다」를 넣는다. 시안 폴더는
  이관이 **확인된 뒤에** 지운다(지웠다가 git 에서 되살렸다).
- **사용자가 짚은 자리만 좁게 고친다.** 「매칭 색이 이상하다」에 카드 전체 색 정책을 물었다가 끊겼다 — 원한 것은 기본 아바타 색뿐이었다.
- **병합 검사에 `npm run build` 가 빠져 있었다.** `app/ui/icon.tsx` 는 Next 가 `icon` 메타데이터 라우트로 읽어 `next build` 가
  「Export default doesn't exist」로 섰고, **Production 배포가 두 시간 동안 전부 Error** 였다(typecheck · lint · 단위 · e2e 는 dev 서버라 통과).
  `icons.tsx` 로 옮겨 고쳤다. `delegation.md` 「로컬 환경의 함정」에 적었다.
- **`match.spec.ts` 는 `--workers=1` 로만.** 공유 후보 풀 때문에 워커 2 면 붉다(주장 5건이 전부 이것). 여러 워크트리가 같은 로컬 스택에서
  e2e 를 돌리면 「매칭 참여를 먼저 켜 주세요」가 드문드문 난다 — 다시 돌리면 선다.
- **3000 의 dev 서버가 떠 있으면** 같은 디렉터리에서 둘째 dev 서버를 못 띄운다 — 전체 e2e 는 별도 워크트리(`git worktree add --detach`,
  `node_modules` 는 `cp -Rc`, `.env.development.local` 복사)에서 `PLAYWRIGHT_PORT=3600` 으로 돌렸다.
- 토큰 이름에 `none` 을 쓰면 Tailwind 의 `fill-none` · `border-none` · `bg-none` 이 그 색이 된다 — `unknown` 으로 바꿨다.

## 남은 것 (다음 세션)

- **새 한글 문구는 운영자가 「프로덕션 적용 허용」으로 넘겼고 개별 확정 답은 아직이다.** 조율자가 표로 보고했다(홈 인사 · 관계 지도 범례 ·
  매칭 「이 사람이 채워 주는 기운」 · 풀이 「읽는 데 약 N분」 · 채팅 신고 판 제목 · 소식 제목 등). 바꾸라면 각 화면 상수를 고친다.
- **G-58** — 약관 · 처리방침 본문의 「만세력 서비스」(다음 판에서), 경고 이메일 `[서비스명]`, 공유 그림 로고.
- **G-59** — 풀이 책장 표지 색을 `my_readings` 가 주지 않아 명식을 한 번 더 읽는다.
- **사진 없는 후보의 일간 오행이 색으로 드러난다**(운영자 결정). 처리방침 · 참여 안내에 적을지 변호사 검토 목록에 올릴지 묻지 않았다.
- **약점(각 화면 담당이 스스로 적은 것):** 폰 홈의 지도가 한 화면쯤 차고 타일과 같은 사람을 두 번 보인다 · 넓은 화면 1280×800 에서
  매칭 점수가 첫 화면 끝에 걸린다 · 폰 매칭 반원 띠는 후보 다섯부터 붐빈다 · 풀이 글은 머리 · 공유 단추가 표지 위에 있고 본문이
  가운데 정렬이다(원본은 표지 먼저 · 왼쪽 정렬 — `panel.tsx` · `markdown.tsx` 는 궁합 결과도 써서 안 고쳤다) · 채팅 신고가 한 걸음 늘었다.
- pgTAP `46_operator_access_log` 3건이 공유 로컬 DB 에서 붉었다 — 이번 변경과 무관해 보이지만 깨끗한 DB(`npm run db:reset`)에서 확인 안 함.
