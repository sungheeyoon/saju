# 대화가 저장소 일로 번진 세션 — 이름 짓기에서 PG 까지, 그리고 `/retro` — 2026-10-07

> 요구사항이 아니다 — 지금 규칙은 각 원본이 든다. 이 라운드의 PR 은 #513 · #514 · #515 · #516 과 이 노트의 PR 이다.
> 남은 일은 `docs/product/gaps.md`(G-21 · G-25), 결정은 ADR 0148 · 0149 가 든다.

## 시작한 까닭

세션은 서비스 이름을 두고 운영자와 나눈 대화로 열렸다. 이름이 「만날지도」로 정해지자(#514, ADR 0149) 같은 대화가 환불 기준(#513, ADR 0148) ·
의존성 경보(#515) · PG 와 통신판매업 신고(#516)로 이어졌다. 끝에 운영자가 이 세션에 `/retro` 를 돌렸고, 그 권고를 이 노트의 PR 이 옮긴다.

## 조율자가 내린 판단과 헤맨 것

- **대화로 시작한 세션이 역할 없이 메인 체크아웃을 고쳤다.** 문서 · 머리글 부품 · 잠금 파일 · 노트를 직접 고쳤다 — 조율자는 직접 고치지
  않고 맡긴다(`docs/agents/delegation/coordinator.md` 「조율자 세션」). 입구의 「손대기 전에 역할을 고른다」(`docs/start.md`)가 걸리지
  않은 까닭은 「일을 연다」는 순간이 없었기 때문으로 본다 — 이름 이야기의 한 걸음씩 다음이 고칠 것이 되었고, 어느 걸음도 새 일의 시작으로
  보이지 않았다. 처음 권고는 「병렬이 아닌 대화 세션도 조율자이니 맡긴다」와 「첫 쓰기에서 도구가 묻는다」였다. 운영자는 두 번째 의견을 본 뒤
  고쳐 정했다 — 일이 하나면 역할을 바꿔 직접 하고, 훅은 묻지 않고 한 줄만 일러 준다(`docs/agents/delegation/coordinator.md`
  「조율자 세션」, `docs/agents/delegation/permissions.md` 「훅 — 메인 체크아웃에서 일러 준다」). 일 하나에 에이전트를 띄우는
  값과 매번 뜨는 창이 이 세션의 실수보다 비싸다고 본 것이다.
- **저장소 밖 사실을 단정했다가 거뒀다.** 「PG 계약에 통신판매업 번호가 필수」 · 「유효기간 1년이 흔하다」 · 「10% 공제가 표준」 ·
  「AWS 주소를 넣으면 된다」 · 「070/050 이면 된다」 — 출처 없이 말했고 하나씩 물렸다. 근거 조사는 따로 했다
  (`docs/notes/2026-10-07-reading-credit-refund-research.md`). 같은 칸에 법 · 가격 · 남의 업체 조건은 출처 링크나 「확인 전」으로 말한다는
  줄을 더했다(`docs/agents/delegation/coordinator.md` 「확인한 흔적을 붙여 전한다」).
- **force push 의 잠금이 비어 있었다.** 문서 에이전트가 PR 가지를 다시 써서 밀었고 밀렸다고 보고했다. 표는 「main 에 force push」라 적었고
  `deny` 는 깃발이 `git push` 바로 뒤일 때만 걸렸다. 어느 가지에도 안 한다로 고치고 꼴을 더했다 — 못 잡는 꼴은
  `docs/agents/delegation/permissions.md` 「잠그지 않은 것」 ③.
- **에이전트 PR 에 커밋을 더하다 원격에 빈 가지를 세웠다.** 워크트리의 로컬 가지 이름으로 밀었다 — 규약에 미는 꼴을 적었다.
- **`/retro` 는 운영자만 부른다.** 그 스킬은 모델이 스스로 부르지 못하게 되어 있다(`disable-model-invocation`). 조율자는 입력(보고의
  「헤맨 것 · 틀린 절」)을 모아 두고, 운영자가 부른다.

## 배운 것

- 대화형 세션은 「일의 시작」이 없이 일을 한다 — 시작에 거는 규칙만으로는 걸리지 않는다.
- 법 · 계약 · 요금의 「흔하다 · 표준이다」는 기억에서 나온 일반화다. 운영자가 그 말로 결정을 내리므로 출처가 먼저다.
- 잠금 목록은 쓰는 꼴을 따라가야 한다. 「main 에」라는 낱말이 표에 있으면 PR 가지는 괜찮다고 읽힌다.
