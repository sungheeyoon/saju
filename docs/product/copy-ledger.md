# 화면 문구 대장

**규칙의 원본은 `docs/context/copy.md` §8 이다. 이 대장은 운영자가 확정한 화면 문구와 예외만 든다.**
에이전트는 대장을 임의로 늘리지 않는다 — 새 후보는 PR · 보고에 표로만 낸다. 확정되면 그 PR 이
대장에 줄을 더하고 PR 번호 · 날짜를 적는다.

**UI 변경 요청이 오면 문구는 여기와 아래 「무리 색인」이 가리키는 고칠 화면의 무리 파일에서 먼저 찾는다** — 순서는
`docs/agents/code-rules/screen-copy.md` 「화면 문구」가 든다.
시안 · 외부 리뷰 · 에이전트가 쓴 문구는 이 대장에 들기 전까지 확정이 아니다.

서비스 이름은 **만날지도**(로마자 MannalMap)다(2026-10-07 확정, ADR 0149, `src/lib/brand`). 앞 이름 「점점」(2026-09-24)은 ADR 0109. 「만세력」은 서비스 이름이 아니라 「만세력 엔진」처럼
사주 계산 기능을 가리킬 때만 쓴다.

2026-09-29 에 claude.ai 아티팩트(<https://claude.ai/code/artifact/263b0f15-c2f5-48a1-a327-d747a58ed639>)에서
옮겼다. 그 아티팩트는 이제 보기용이고 원본은 이 파일이다. **옛 판(2026-09-03, 서비스 이름이 「만세력」이던 때)은
아티팩트의 「과거 기록」에 있다 — 기준이 아니다.**

## 01 규칙 — 버튼은 결과를 말하고, 닫는 것은 「취소」다

운영자 결정, 2026-09-28. 본문은 `docs/context/copy.md` §8 이고 아래는 그 요지다.

- 실행 버튼은 결과를 말하는 동작명 — 「확인」 같은 추상어 대신 「목록에서 빼기」 · 「요청 보내기」 · 「차단하기」 · 「신고하기」 · 「탈퇴 신청하기」.
- 목록 관계를 없앨 때는 「목록에서 빼기」. 파괴 여부가 불분명한 곳에 「삭제」를 쓰지 않는다.
- 확인창을 닫는 버튼은 「취소」.
- 「그만두기」는 입력 내용이 사라지는 작성 중단에만, 「작성 그만두기」처럼 구체적으로.
- 화면 이름은 「저장한 사람」. 「사람 탭」 · 「자리 비우기」를 쓰지 않는다.
- 말투 — (2026-09-28 판) 앱의 대부분은 합쇼체(「~습니다」)이고, 오류 화면 · 404 · 매칭 참여 오류는 해요체로 정했다. **2026-09-29 #338(ADR 0135)이 이겼다 — 해요체가 기본이고, 되돌리기 어려운 결과의 고지는 합니다체를 쓸 수 있다(`docs/context/copy.md` §8).** 이름 뒤 「님」은 띄어 쓴다(「{이름} 님」, 국립국어원 기준).
- 완료 안내는 해요체 · 능동형으로 쓴다 — 「저장되었습니다」가 아니라 「저장했어요」. 그 일이 **성공한 뒤에만** 서고, 저장 중 · 실패에는 서지 않는다(토스 UX 라이팅 원칙(해요체 · 능동형)을 따름 — 운영자 결정 2026-10-10).

## 12 확정 문구 — 서비스 이름 「만날지도」 · 바닥글의 사업자 정보 (운영자 결정 2026-10-07, ADR 0149)
