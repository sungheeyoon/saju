# 사주 서비스 PRD — 화면

색인은 `docs/prd.md` 다 — 표시(선다 · 없다 · 다르다)의 뜻과 절마다 사는 파일이 거기 있다.

## 3. 화면

**규칙: 한 사람의 만세력은 아무나 본다. 두 사람을 나란히 놓는 것과 저장·풀이는
로그인한 사람의 것이다.**

화면은 무리마다 한 파일에 산다(2026-10-10, ADR 0162) — 화면 표의 줄과 그 화면의 절(§3.0 · §3.1)이 함께 간다. 고칠 화면의 무리
파일을 연다. 화면 표의 칸은 무리 파일마다 같다(화면 · 주소 · 어디서 가나 · 역할). §3.1 은 사주 보기 쪽(첫 화면 · 사주 보기)과
궁합 보기 쪽(궁합) 둘로 갈렸다. 아래 §3.2 는 모든 화면에 걸린다. 같은 무리의 확정 문구는 `docs/product/copy-ledger/` 의 같은 이름 파일이다.

| 무리 | 화면 | 파일 |
| --- | --- | --- |
| 첫 화면 · 사주 보기 | 사주 보기 — §3.1 사주 보기 | `docs/product/prd/screens/first.md` |
| 로그인 · 가입 · 안내 화면 | 가입 · 처리방침 · 서비스 소개 · 자주 묻는 질문 · 공유 풀이 · 로그인 · 로그인 실패 · 테스트 종료 | `docs/product/prd/screens/public.md` |
| 홈 · 저장한 사람 · 풀이 | 홈 · 풀이 보관함 · 한 사람 풀이 · 사람 — §3.0 홈 | `docs/product/prd/screens/home.md` |

### 3.2 버튼은 동사로 갈린다 — **선다 · 2026-09-14**

**상품 이름은 넷뿐이다: 사주 · 궁합 · 사주풀이 · 궁합풀이.** 「한 사람 사주」·「두 사람
명식」 같은 분류명은 쓰지 않고, 사용자 화면에서 「명식」은 「사주」다(엔진과 사주 상세의
분석 설명은 그대로 「원국」을 쓴다 — 거기서는 그 낱말이 표의 뜻을 가리킨다).

버튼은 **이동인지 제출인지가 아니라 사용자가 기대하는 행동**으로 이름을 정한다.

| 행동 | 글자 | 어디 |
| --- | --- | --- |
| 입력을 제출하고 결과 확인 | 사주 보기 · 궁합 보기 | `/saju` 계산기 · `/compat` 고르는 칸 |
| 로그인 전 입력을 제출하고 로그인 전 결과 확인 | 무료로 내 사주 보기 · 무료로 두 사람 궁합 보기 | `/` 첫 화면의 두 입구 |
| 입력을 들고 로그인해 풀이로 | 로그인하고 전체 풀이 받기 · 로그인하고 궁합풀이 받기 | `/` 로그인 전 결과의 잠긴 목차 |
| 출생 정보 수정 후 재계산 | 수정하고 다시 보기 | `/` 첫 화면 · `/saju` 계산기 |
| 다른 기능으로 진입 | 사주 보러 가기 · 궁합 보러 가기 | `/me/compat` 머리 · 사람 상세 · 사람 목록 · 관계 지도의 사람 카드(안 본 궁합) |
| 새 풀이 생성 | 사주풀이 받기 · 궁합풀이 받기 | 풀이 화면 |
| 풀이 재생성 | 사주풀이 다시 받기 · 궁합풀이 다시 받기 | 풀이 화면 |
| 만들어 둔 풀이 열기 | 사주풀이 보기 · 궁합풀이 보기 | 사람 카드 · 관계 지도의 사람 카드(나와 본 궁합) |
| 상세로 들어가기 | 사주 자세히 보기 · {이름} 사주 보기 | 홈의 내 사주 카드(사주 자세히 보기) · 관계 지도의 사람 카드({이름} 사주 보기) |
| 되돌아가기 | 사주로 돌아가기 · 내 사주로 돌아가기 · 사람 목록으로 돌아가기 | 로그인 · 로그인 실패 · 사람 상세 |
| 상대에게 요청 보내기 | 궁합 요청 → 창에서 요청 보내기(닫기는 취소) | 인연 카드 |
| 저장한 사람을 목록에서 빼기 | 목록에서 빼기 → 창에서 목록에서 빼기(닫기는 취소) | 사람 카드의 관리 메뉴 |
| 저장한 사람 화면으로 가기 | 저장한 사람 관리 → | 저장 자리가 다 찬 저장 칸 |
| 화면을 못 열었을 때 | 다시 시도하기 · 홈으로 | 오류 화면(제목 「화면을 불러오지 못했어요」) |
| 없는 주소 | 홈으로 | 404 화면(제목 「페이지를 찾을 수 없어요」) |
| 없는 사람 · 인연 궁합 | 사람 목록으로 · 인연 탭으로 | 「찾을 수 없어요」(ADR 0007) |

- **저장은 저장하는 것만 말한다.** 저장이 곧 풀이가 아니라 풀이 화면으로 데려가는
  자리에서는 「저장하고 계속하기」이고, 이어지는 걸음은 버튼 아래 한 줄이 적는다
- **「보기」는 볼 것이 이미 있을 때만 쓴다.** 상대의 수락을 기다리는 것은 요청이고,
  아직 계정이 없는 사람에게 여는 것은 로그인이다(「로그인하고 시작하기」)
- **같은 화면에 같은 길을 두 번 세우지 않는다.** 고르는 칸이 이 화면에 있으면 머리에는
  버튼을 안 세운다(`/compat`) — 그 누름은 칸 안에 하나뿐이다
- 안내 문장이 버튼을 인용할 때는 **그 버튼의 글자 그대로** 적는다
- **닫기는 「취소」다.** 「그만두기」는 입력한 내용이 사라지는 작성 중단에만 「작성 그만두기」처럼
  구체적으로 적는다. 목록의 관계를 없애는 누름은 「목록에서 빼기」이고, 지워지는지 분명하지 않으면
  「삭제」라 적지 않는다(운영자 결정 2026-09-28). 되돌릴 수 없는 실행은 「차단하기」 · 「신고하기」 · 「탈퇴 신청하기」다
