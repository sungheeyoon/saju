# 사주 서비스 PRD — 화면: 운영 화면 · 작업대

색인은 `docs/prd.md` 다. 이 파일은 「3. 화면」(`docs/product/prd/screens.md`)의 한 무리다 — 모든 화면에 걸리는 규칙(§3 머리의 규칙 ·
§3.2 버튼은 동사로 갈린다)과 무리 색인은 그 파일에 있다(2026-10-10 에 화면 표와 §3.0 · §3.1 을 무리로 나눴다, ADR 0162). 이 화면들은 운영자 전용이다 — 확정 문구 파일 `docs/product/copy-ledger/ops.md`. 신고의 동작은 §6.5(`docs/product/prd/matching.md`), 운영 절차는 `docs/ops/runbook/moderation.md` 가 든다.

### 화면 표 — 운영 화면 · 작업대

| 화면 | 주소 | 어디서 가나 | 역할 |
| --- | --- | --- | --- |
| 검산 | `/me/reading/inspect` | 주소로만 | **우리 작업대다.** 사용자 동선에 없다. **로컬에서만 선다** — 운영 · Preview 에서는 없는 주소(404)다 (ADR 0122) |
| 설문 요약 | `/ops/survey` | 주소 · 운영 머리의 「설문」 | **운영자 화면.** 메뉴에 없고 `/me` 밖이다 (§4.6) |
| 주문 | `/ops/orders` | 주소 · 운영 머리의 「주문」 | **운영자 화면.** 주문 번호(`rdo_…`)로 주문을 찾아 결제 · 묶음 · 쓴 수 · 예약 중 수 · 안 쓴 수와 같은 계정의 다른 주문을 본다. 걷을 회차를 고르면 환불 금액(ADR 0148)이 셈해져 서고, PortOne 콘솔에서 취소한 뒤 취소 번호를 적어 장부에 적는다 — PG 취소는 부르지 않는다. 찾기 · 적기는 접속기록에 남는다 (G-110 ②, ADR 0184) |
| 신고 열람 | `/ops/reports` · `/ops/reports/[reportId]` | 주소 · 운영 머리의 「신고」 | **운영자 화면.** 신고 목록과 신고 당시의 불변 스냅샷 · 검토 기록을 읽는다. 읽기 전용 (§7.0, ADR 0103 · 0107). 목록 카드에 신고받은 계정이 앞에 서고, 고른 메시지 첫 줄(60자)을 발췌로 보이며, 목록을 열면 접속기록 한 줄에 그 쪽의 신고 id 들이 남는다(화면 점검 C17 · #588) |
