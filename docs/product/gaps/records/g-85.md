# G-85 기록

표의 줄: [간극 대장 「운영 베타에서 닫는다」의 G-85](../../gaps.md#운영-베타에서-닫는다)

인연 요청 확인 창(`app/me/matching/matching-experience.tsx`)은 풀이권 예약(`REQUEST_RESERVES_NOTE`)과 여덟 글자 공개
(`MATCH_PILLARS_DISCLOSURE`) 두 줄만 말한다. 「채팅은 아직 없다」 제한문은 채팅이 선 뒤(ADR 0091, #147) 걷혔고, 그 자리에
「수락되면 대화방이 열린다」는 말은 서지 않았다(2026-10-09 화면 감사 C3).

PRD §6.1 의 「아직 연락 기능이 없다는 것을 확인한 뒤 요청한다」는 ADR 0158 의 PR 이 지금 코드대로 고쳤다(문서 노후). 창 문구는
바꾸지 않았다 — 시안은 그 PR 보고의 문구 표에 있다. 시안: 「상대가 수락하면 두 분의 대화방이 열려요.」 — 정책 상수로 두면
`src/lib/consent` 의 공개 고지 곁이다.
