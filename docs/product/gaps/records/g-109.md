# G-109 기록

표의 줄: [간극 대장 「정비 — 위임 준비」의 G-109](../../gaps.md#정비--위임-준비)

2026-10-12 ~ 14 시스템 점검(`docs/notes/2026-10-14-system-audit-round.md`)에서 나왔지만 그 라운드에 고치지 않은 것이다.
어느 것도 동작 결함은 아니다. 하나를 고치면 이 목록에서 지우고, 다 지워지면 줄을 닫는다.

## 코드

- 결제 상태 값이 `string` 이다 — `app/me/credits/payment.ts` 의 `orderIsPaid` 와 `credits/history/orders.ts` 의 `STATUS`. 리터럴 유니온으로 바꾸면 새 상태를 컴파일러가 알린다.
- 풀이권 개념이 여러 자리에 있다 — 남은 수 읽기 · 잔액 신호(`app/me/reading/credits*.ts`), 넘기기만 하는 래퍼(`app/me/reading/current.ts` 의 풀이권 읽기), 0개 판정 · 거절 판정(`app/me/credits/`). 매칭 · 요청 화면이 `../reading/` 에서 신호를 가져온다. `app/me/credits/` 하나로 모으는 길.
- `app/me/reading/current.ts` 를 바깥 21곳이 들인다 — 대부분 `ReadingEntry` 타입만. 도메인 타입은 `src/lib/reading` 으로 내린다.
- 브라우저에서 저장 자리 수를 읽는 옛 자리 하나 — `app/save-for-reading.tsx`(`scripts/layers.test.ts` 의 옛 자리 목록).
- 소문자만 받는 UUID 정규식 사본 둘 — `SESSION_ID`(`app/taste/actions.ts` · `app/taste/taste-run.ts`). `app/uuid.ts` 를 쓴다.
- `seoulDay`(`audit-export/bundle.ts`, `YYYY/MM/DD`)가 `src/lib/reading/seoul-date.ts` 와 따로 있다.
- 날짜 · 운영자 결정 · 화면 점검 번호를 단 주석 435줄 — 손대는 자리에서만 걷는다는 규칙이라 한꺼번에 하지 않는다.

## 시험

- 문자열로 코드 모양을 잡는 시험 — `app/ui/fields.test.ts`(같은 파일의 `FIELD` · 같은 이름의 `.module.css` 만 찾는다 — `FIELD` 사본 넷을 `app/ui` 로 못 올리고 `birth-form.tsx` 가 519줄에서 멈춘 까닭), `app/api/portone/webhook/settle.test.ts` 의 마이그레이션 SQL 글자, `app/ui/buttons.test.ts` 의 정규식. AST 로 옮긴다.
- `scripts/code-rules.test.ts` 의 약 54개가 문서 모양 시험이다 — 「색인의 절 칸이 그 파일의 `##` 절을 전부 든다」가 다섯 벌. 문서 시험 파일로 떼거나 줄인다.
- 시험 파일마다 따로 둔 재귀 파일 탐색이 `scripts/*.test.ts` 에 남았다(앱 쪽은 `app/ui/source-files.ts` 로 모았다).

## UI

- 단추 상수 뒤에 클래스를 이어 붙인 자리 넷 — `checkout.tsx` 의 `${BUTTON_TERTIARY} text-fine …` 등. 같은 속성이 겹쳐 어느 쪽이 이기는지 빌드된 CSS 로 아직 안 봤다.
- 같은 문구 사본 열다섯쯤 — 「궁합 보러 가기」(4파일) · 「로그아웃하는 중…」(3) · 「만들어 둔 풀이를 이어서 읽어보세요」(3).
- 모양이 달라 묶지 않은 부품 둘 — `app/me/people/person-menu.tsx`(`border`, 나머지는 `ring`), `app/me/matching/card-photos.tsx` 의 사진 화살표(`bg-black/45`, 나머지는 `/50`).
