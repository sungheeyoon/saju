# G-109 기록

표의 줄: [간극 대장 「정비 — 위임 준비」의 G-109](../../gaps.md#정비--위임-준비)

2026-10-12 ~ 14 시스템 점검(`docs/notes/2026-10-14-system-audit-round.md`)에서 나왔지만 그 라운드에 고치지 않은 것이다.
어느 것도 동작 결함은 아니다. 하나를 고치면 이 목록에서 지우고, 다 지워지면 줄을 닫는다.

## 코드

- 결제 상태 값이 `string` 이다 — `app/me/credits/payment.ts` 의 `orderIsPaid` 와 `credits/history/orders.ts` 의 `STATUS`. 리터럴 유니온으로 바꾸면 새 상태를 컴파일러가 알린다.
- 풀이권 개념이 여러 자리에 있다 — 남은 수 읽기 · 잔액 신호(`app/me/reading/credits*.ts`), 넘기기만 하는 래퍼(`app/me/reading/current.ts` 의 풀이권 읽기), 0개 판정 · 거절 판정(`app/me/credits/`). 매칭 · 요청 화면이 `../reading/` 에서 신호를 가져온다. `app/me/credits/` 하나로 모으는 길.
- `app/me/reading/current.ts` 를 바깥 21곳이 들인다 — 대부분 `ReadingEntry` 타입만. 도메인 타입은 `src/lib/reading` 으로 내린다.
- 날짜 · 운영자 결정 · 화면 점검 번호를 단 주석 435줄 — 손대는 자리에서만 걷는다는 규칙이라 한꺼번에 하지 않는다.

## 시험
