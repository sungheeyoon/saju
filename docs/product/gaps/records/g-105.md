# G-105 기록

표의 줄: [간극 대장 「운영 베타에서 닫는다」의 G-105](../../gaps.md#운영-베타에서-닫는다)

성립 소식(`request_accepted`, 두 사람 다 받는다)이 가는 곳은 운영자가 그 Match 의 채팅방으로 정했다(2026-10-11 저녁, ADR 0130
「2026-10-11 저녁」). 글자는 그대로 「{닉네임} 님과 인연 궁합이 열렸어요」(닉네임이 없으면 「요청이 수락돼 인연 궁합이 열렸어요」,
`src/lib/consent/index.ts` 의 `notificationText`)라 글자는 궁합을, 가는 곳은 대화를 말한다.

- 시안 — 「{닉네임} 님과 대화가 열렸어요」 · 「{닉네임} 님이 요청을 수락했어요」(받은 쪽에게는 「{닉네임} 님과 연결됐어요」)
- 글자는 문구 결정이라(`docs/agents/delegation/decisions.md` 「결정 점검표」) 이 PR 에서 바꾸지 않았다. 「인연」을 바꾸면(G-104) 함께 정한다.
