# G-80 기록

표의 줄: [간극 대장 「정비 — 위임 준비」의 G-80](../../gaps.md#정비--위임-준비)

2026-10-08 `/tmp` 아래 워크트리마다 `node_modules`(약 760MB)를 복사하자 3.9GB tmpfs 가 차서 dev 서버가 OOM 으로 두 번 죽고 도구 출력이 `ENOSPC` 로 멈췄다. 하는 일 — 워크트리는 홈 디스크에 두고 끝나면 걷는다. 같은 날 Windows 쪽 `.wslconfig` 에 `memory=6GB` 를 세웠다(저장소 밖, WSL 기본 상한은 Windows RAM 의 50%).
