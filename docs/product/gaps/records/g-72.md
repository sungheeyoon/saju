## 설정 — 새 메시지 알림 (`app/me/settings/push-row.tsx` 의 `COPY`, ADR 0156)

| 자리 | 키 | 시안 |
| --- | --- | --- |
| 카드 제목 | (`SettingsCard title`) | 알림 |
| 줄 이름 | `label` | 새 메시지 알림 |
| 상태를 재는 동안 | `checking` | 알림 설정을 확인하는 중… |
| 꺼짐 설명 | `off` | 앱을 보고 있지 않을 때 새 메시지가 오면 이 기기로 알려 드려요. |
| 켜짐 설명 | `on` | 이 기기로 새 메시지 알림을 받고 있어요. |
| 무엇이 안 보이나 | `privacy` | 알림에는 메시지 내용과 보낸 사람이 보이지 않아요. |
| 브라우저가 막았다 | `denied` | 이 브라우저에서 알림이 차단되어 있어요. 브라우저 설정에서 이 사이트의 알림을 허용해 주세요. |
| 지원 안 함 | `unsupported` | 이 브라우저에서는 알림을 받을 수 없어요. |
| iPhone · iPad 의 브라우저 탭 | `iosNotInstalled` | iPhone · iPad 는 홈 화면에 추가한 앱에서만 알림을 받을 수 있어요. 공유 버튼에서 「홈 화면에 추가」를 누른 뒤 그 앱으로 열어 주세요. |
| 켜는 단추 · 누른 뒤 | `turnOn` · `turningOn` | 알림 켜기 · 켜는 중… |
| 끄는 단추 · 누른 뒤 | `turnOff` · `turningOff` | 알림 끄기 · 끄는 중… |
| 권한 창에서 허용하지 않았다 | `notAllowed` | 알림을 허용하지 않아 켜지 못했어요. |
| 켜기 실패 | `failedOn` | 알림을 켜지 못했어요. 다시 시도해 주세요. |
| 끄기 실패 | `failedOff` | 알림을 끄지 못했어요. 다시 시도해 주세요. |
