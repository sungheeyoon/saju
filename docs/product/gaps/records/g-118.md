# G-118 기록

표의 줄: [간극 대장 「공개 출시」의 G-118](../../gaps.md#공개-출시)

## 2026-10-22 — 대장에 올림 (읽기 감사)

`docs/ops/runbook/jobs.md` 「도는 잡이 정말 도나」의 「감시기가 못 보는 것 셋」이 든 대로, 알림은 DB 안의 `notify_ops` 가 `ops_alert` 에
적고 Vault 의 `ops_alert_url` 로 보내는 길 하나다. 감시기 자신이 계속 실패하거나 `pg_cron` 이 통째로 멈추면 그 길이 함께 선다. 앱이 통째로 응답하지 않는 것(배포 실패 · 플랜 한도 ·
도메인)도 이 길은 모른다 — 지금은 운영자가 쓰다가 보거나 이용자 제보로 안다.

바깥에서 보는 꼴은 둘이다 — 주소를 주기적으로 두드리는 uptime 감시, 그리고 잡이 주기적으로 신호를 보내고 그 신호가 끊기면 알리는
dead-man heartbeat. 어느 서비스를 쓸지 · 알림을 어디로 받을지 · 비용은 운영자가 정한다(`docs/agents/delegation/decisions.md` 「결정 점검표」의
비용 · 외부 서비스). 정해지면 무엇을 두드리고 어떤 잡이 신호를 보내는지를 `docs/ops/runbook/jobs.md` 에 적는다.

## 2026-10-23 — 후보와 추천, 서비스와 상관없는 몫은 준비됨 (밤 라운드 E1)

**결정할 것은 서비스 선택 · 비용 둘뿐이다.** 무엇을 두드리고 · 어떻게 판정하고 · 어디로 알리고 · 붙이는 차례는
`docs/ops/runbook/jobs.md` 「바깥 감시」가 든다. 서비스와 상관없는 코드 둘 — 상태 문 `/api/health`(앱이 DB 에 닿나)와
DB heartbeat 잡 `ops-heartbeat`(Vault `ops_heartbeat_url` 이 비어 있으면 아무것도 안 한다) — 은 PR 로 올렸다: 상태 문 #804(자격을 묻지 않는 문이라 결정 대기 — 그 PR 의 ADR) · heartbeat draft #805(오늘 밤 마이그레이션 자리를 쥔 일이 머지된 뒤 번호를 맞춘다).

**필요한 것** — uptime(HTTP) 감시 둘(5분) · heartbeat 하나(기간 10분 · 유예 10분) · 이메일 알림(+ Slack 이나 Discord) · 상업 이용 가능.

한국 서비스는 이번에 찾지 않았다 — 감시는 사용자가 보는 모양이 아니라 운영 도구라 「한국 사용자에게 익숙한 모양」이 걸리지 않는다.

**추천 — UptimeRobot Free(uptime 둘) + Healthchecks.io Hobbyist(heartbeat 하나), 월 $0.** 두 꼴을 무료로 다 덮고, 둘 다 공식
약관이 상업 이용을 막지 않는다. 대가는 계정 둘(MFA 둘)이다. 하나로 줄이고 싶으면 **UptimeRobot Solo $9/월**(heartbeat 가 유료 판에
든다고 회사가 적는다 — 붙이는 날 그 판의 heartbeat 를 화면에서 확인한다). Better Stack 은 무료 판이 개인 프로젝트용이라 뺐다.
공개 자료가 밝히지 않은 것(무료 판의 알림 지연 · 연동 종류별 한도)은 붙이는 날 화면에서 본다.
