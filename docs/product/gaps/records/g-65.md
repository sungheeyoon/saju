# G-65 기록

표의 줄: [간극 대장 「공개 출시」의 G-65](../../gaps.md#공개-출시)

표의 「G-65」 줄 메모 칸에 있던 글이다 — 문장은 그대로 옮겼다(2026-10-08, 칸에 세 줄을 더할 읽기 예산을 내려고).

**운영자 결정(2026-09-28): MFA 적용 여부는 아직 정하지 않고, 인증 앱도 등록하지 않는다. 배포된 화면 막음은 그대로 두어 `/ops/reports` · `/ops/survey` 가 열리지 않는 채로 둔다. DB 후속 PR 은 시작하지 않는다.** 화면 막음은 `a45e34e` 로 Production 에 섰다(2026-09-28 18:30 서울) — 등록한 요소가 없는 운영자는 운영자가 아닌 사람과 같은 404 를 받는다. DB 층은 아직 aal 을 안 묻으므로 세션 토큰으로 PostgREST 를 직접 부르면 운영자 문은 그대로 열린다(ADR 0123 「DB 층」). **이것에 묶이는 것:** 신고 열람대 운영 확인 14단계(G-24 · #304 의 6)는 `/ops/reports` 를 여는 걸음이 있어 이 줄이 풀릴 때까지 밟을 수 없다

**메모(2026-10-10, 권하지 않음).** 화면 점검 C18 — 설정 키 띄우기 · 복사 단추 — 는 이 줄에 걸려 손대지 않았다(2차 노트). 이 줄이 풀리는 날 함께 본다. G-24 의 #576 · #588 화면 확인과 G-82 의 신고 화면 smoke 도 이 줄을 기다린다.

**운영자 결정(2026-10-15): 구글 간편로그인만 사용하기로 결정.** 운영자 로그인은 당분간 구글 간편로그인(OAuth)만 쓰고, 운영 화면의
2단계(aal2) 제한과 `/ops/mfa` 를 걷는다(ADR 0182). 운영자 판정(`is_operator()`)과 접속기록 · 거절 기록은 그대로다. 위 2026-09-28 결정과
2026-10-10 메모(C18)는 이것으로 끝났다 — 신고 열람대 운영 확인 14단계(G-24 · #304 의 6)는 이 변경이 Production 에 오른 뒤 2단계 없이 밟는다.

**법적 충족 여부 — 판정 전, 근거는 읽었다(2026-10-18).** 위는 기능 결정이다. 고시 현행판(제2026-9호) 제6조 ② 원문 · 시행일, 개인정보위
안내서(2025.11)의 「안전한 인증수단」 예시, 블랙야크 처분 보도자료를 [처리방침의 근거 「운영자 로그인 — 안전성 확보조치 기준 제6조 제2항」](../../../legal/privacy-grounds.md#운영자-로그인--안전성-확보조치-기준-제6조-제2항-g-65)에
적었다 — 요건 · 우리 사실 · 남는 물음만이고 판정하지 않았다. 안내서는 제6조 ② 의 예로 「비밀번호 인증 외에 일회용 비밀번호(OTP) 등
추가적인 인증 수단」과 인증서 · 보안토큰 · OTP 를 들고, 소셜 로그인은 제5조 ⑤ 의 인증수단 예시에만 둔다. 운영자 구글 계정의 2단계 인증
여부는 계정 설정이라 저장소에 사실이 없다. 이 줄은 운영자(필요하면 변호사)가 답할 때까지 닫지 않는다. 앞서 적은 고시 링크
(`flSeq=133609911`)는 옛 판(제2023-6호)이었다.

**접속기록과의 경계(2026-10-23)** — 이 줄은 인증수단(제6조 ②)이다. 접속기록에 접속지 정보 칸이 없다는 것과 그 대조는 [G-23 기록](g-23.md) 「⑩ 덧」 · [처리방침의 근거 「운영자 접속기록」](../../../legal/privacy-grounds.md#운영자-접속기록--안전성-확보조치-기준-제2조-제3호--제8조-g-23--g-25)에 있다.
