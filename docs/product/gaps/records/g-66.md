# G-66 기록

표의 줄: [간극 대장 「공개 출시」의 G-66](../../gaps.md#공개-출시)

표의 「G-66」 줄 메모 칸에 쌓였던 실행 기록이다 — 문장은 그대로 옮겼다(2026-10-05). 줄을 닫으면 이 절도 함께 걷는다.

**근거를 고쳐 썼다(2026-10-03, ADR 0143 이 0131 을 대체).** 0131 의 「입력은 브라우저 밖으로 안 나가고 표를 열쇠로 읽는다」는 더는 참이 아니게 된다(앱이 붙으면, G-68). **보내는
것** — 로그인 전 생년월일시가 **우리 서버**로 와서 계산에만 쓰이고 저장되지 않는다(DB 에 원문 칸이 없다). 모델 제공자(OpenAI, 국외)에는 여덟 글자 · 성별 · 시간 앎과 허용된 분석값이 간다. **안
보내는 것** — 생년월일시 원문 · 출생지 · 이름 · 연락처 · IP · 해 숫자 · 나이 · 절기 날짜. IP 는 날짜별 키의 HMAC 만 24시간, 쿠키는 안정 비밀의 HMAC, 미가입 기록은 24시간 연장
없음. **숨기지 않을 사실** — 여덟 글자는 60년 주기 안에서 날짜와 2시간 범위로 역산된다(원문은 안 나가지만 출생 날짜 · 시간대에 준하는 값이 식별자 없이 나간다). 근거 지문은 비밀이 아니다 — 경우의
수가 적어 대입으로 풀린다. **변호사 질문 셋** — ① 식별자 없는 여덟 글자 · 성별 · 분석값을 로그인 전에 국외 모델 제공자에게 보내는 것이 개인정보 처리 · 국외 이전 고지 대상인가 ② 화면 고지 한
줄(운영자가 정한 문구, ADR 0143 의 6)로 충분한가, 처리방침 개정이 필요한가 ③ 미가입 기록의 24시간 보관을 고지해야 하는가. 변호사는 아직 답하지 않았다 — 이 줄의 어느 문장도 답이 아니다.
`docs/legal/privacy-v8-draft.md` 의 해당 줄(10절 표의 로그인 없이 계산할 때의 출생 정보)에 사실을 옮긴 초안과 `[변호사 검토 필요: G-66 …]` 표지를 달았다(#443) —
그것도 답이 아니다

## 2026-10-08 — 첫 화면의 고지 한 줄을 걷었다

운영자가 로그인 전 첫 화면을 고치며 주 단추 아래의 고지 한 줄(ADR 0143 의 6 「화면 고지 문구」)을 걷었다(ADR 0143 「2026-10-08 덧」).
**이것은 변호사의 답이 아니고 이 줄을 닫지 않는다.** 바뀐 것과 남은 것:

- **처리는 그대로다** — 위 「보내는 것 · 안 보내는 것 · 숨기지 않을 사실」은 한 글자도 바뀌지 않았다. 로그인 전 입력은 서버에서
  계산에만 쓰이고, 여덟 글자 · 성별 · 시간 앎 · 허용된 분석값이 국외 모델 제공자로 간다.
- **화면에서 무엇이 어디로 가는지 말하는 자리가 이제 없다.** 처리방침(`/privacy`)의 지금 판은 로그인 전 계산을 적지 않는다 —
  초안(`docs/legal/privacy-v8-draft.md`)에 표지만 있다.
- **변호사 질문이 바뀐다.** ① · ③ 은 그대로다. ② 는 「화면 고지 한 줄로 충분한가」에서 **「화면 고지 없이 처리방침(개정)만으로
  되는가, 입력 전에 화면에서 알려야 하는가」** 로 읽는다. 답이 「화면에 알려야 한다」면 고지를 다시 세운다 — 그 답이 운영자의
  2026-10-08 결정을 뒤집는다.

## 2026-10-10 — 다음 개정에 푸시 줄과 국외 이전 물음이 함께 든다

이 줄의 답으로 생길 처리방침 개정에 새 메시지 알림의 한 줄(구독 주소 · 암호화 열쇠, 문구 확정)과 「브라우저 회사의 푸시 서비스를 국외
이전 표에 드는가」 물음이 함께 든다 — 운영자가 판 올림을 한 판으로 묶었다(2026-10-10). 문구와 물음은 [G-71 기록](g-71.md).

## 2026-10-15 — 변호사 답을 조건에서 뺐다 (ADR 0180)

운영자 결정(원문 「변호사 답 조건 빼고 진행해」). 위 2026-10-03 · 2026-10-08 의 「변호사 질문 셋」은 선택 검토로 옮겼다(`docs/legal/counsel-request.md` B-9).

- 처리방침 `notice-v8`(내용 개정 — 확인한 사람 전원이 다시 읽는다)이 첫 화면 입력의 수신 · OpenAI 로 가는 때와 항목 · 임시 기록 24시간 ·
  쿠키 7일 · 계정에 이어진 기록의 예외 · 거부 방법과 효과를 적는다. 문장은 PR 에서 전/후 표로 운영자에게 묻는다 — 승인 전에는 머지하지 않는다.
  새 메시지 알림(G-71)은 같은 날 이 판에서 뗐다.
- 첫 화면 문단의 요청은 이름 칸을 빼고 보낸다(`app/taste/taste-draft.ts`) — 서버가 쓰지 않는다.
- OpenAI 로 가는 값이 법상 개인정보인지는 판정하지 않는다. 적는 까닭은 지금 문장이 사실과 어긋나서와, 우리 쪽 처리가 처리방침의 설명
  대상이어서다 — 근거는 `docs/legal/privacy-grounds.md` 「판단 셋」.
- **위 「숨기지 않을 사실」의 「60년 주기 안에서」는 첫 화면 문단(과 인연 궁합)에만 참이다.** 사주풀이 · 직접 고른 궁합은 해 · 나이를 함께
  보낸다(`src/lib/saju/evidence/redacted.ts` 가 자르지 않는다) — 그 갈래의 역산은 근거 문서 「판단 셋」의 3(검증 전). 역산 문장은 처리방침에
  넣지 않는다.
- 첫 화면의 고지 한 줄은 다시 세우지 않는다(2026-10-08 결정 그대로). 다시 세울지는 따로 묻는다.
- **법 항목 대조(운영자 「법적 근거를 바탕으로 해라」, 2026-10-15)** — `docs/legal/privacy-grounds.md` 맨 앞의 대조표. 빠졌던 셋(받는 자의
  연락처 · 거부의 방법 · 첫 화면 문단의 위탁)을 고쳤다. 확인 전: OpenAI 의 연락처(공식 처리방침 403), **Supabase 의 명칭과 국가**(공식 문서는
  Supabase Pte. Ltd. · 싱가포르를 든다 — 우리 계정의 계약 법인을 운영자가 확인), 쿠키를 막았을 때의 효과, 첫 화면 처리의 근거 경로(B-9).
- **서울 리전 반영(운영자 2026-10-15)** — 구성요소마다 처리 위치와 계약 법인을 쟀다(근거 문서 「구성요소마다」). DB · 로그인 · 서버 처리는 위탁 절에
  「서울 리전」으로, 국외 절에는 실시간 갱신 · 로그 · 지원 접근 · 모델 호출만. 법인명을 Supabase Pte. Ltd. · OpenAI OpCo, LLC 로 고쳤다 — 우리
  구매 경로 · API 약관 판을 운영자가 확인한다.
- **확인된 것만 싣는다(운영자 2026-10-15)** — 처리마다 사실 · 추정 · 미확인을 갈랐다(근거 문서). 국외 절에는 Supabase 로그(EU) · 지원 접근(미국) ·
  Vercel 지원 접근 · OpenAI 만. Realtime 은 국외 노드 경유가 미확인이라 싣지 않고 서울 DB 의 3일 보관만 적었다. 국외 이전의 근거는 회원의 풀이
  생성에만 제28조의8 ① 3 으로 적었다 — 첫 화면 · 로그 · 지원 접근은 단정 못 함. 안전성 확보 조치 절(시행령 제31조 ① 3)은 v7 부터 빠져 있다.
  계정 값: Supabase 무료 · 직접 조직, Vercel Hobby, AWS 반출 꺼짐.
- **다음 걸음(운영자 2026-10-15)** — 안전성 확보 조치 절을 더했다(확인되는 조치만 — 2단계 인증 · 저장 암호화는 적지 않음). 첫 화면에 동의창을 더하지
  않는다 — ①3 의 적용 가능성과 조건을 근거 문서에서 따졌다(남이 보낸 생년월일시 주소를 열어도 문단이 만들어진다 — 거부 줄에 더함). OpenAI 의 처리
  국가는 「확인 중」으로 칸을 비웠다 — **게시 전에 채운다.** 회사에 물을 문안은 근거 문서 끝.
- **범위를 좁혔다(운영자 2026-10-15)** — 우리 개인정보가 실제로 이전되는 처리의 필수 항목만 채운다(근거 문서 「남은 항목 — 네 칸」). 지원 접근의
  보유기간은 DPA(계약 기간, 끝나면 삭제)로 채웠고, 저장 암호화는 Supabase 보안 페이지로 안전 조치에 실었다. **게시를 막는 값은 OpenAI 의 처리 국가와
  개인정보 연락처 둘뿐이다** — 운영자가 브라우저로 DPA · 처리방침을 열어 보고, 없으면 좁힌 문의 하나. 주소를 열기만 해도 문단 요청이 나가는 것은 코드 경로로
  확인했다(로컬 재현은 안 함).
