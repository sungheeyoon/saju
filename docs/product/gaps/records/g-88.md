# G-88 기록

표의 줄: [간극 대장 「공개 출시」의 G-88](../../gaps.md#공개-출시)

G-83(화면의 폭과 제목 자리, 2026-10-10 ADR 0161 로 닫음)의 기록에서 옮겼다.

홈 뼈대(`app/me/(home)/loading.tsx`)는 등록 뒤 홈의 전폭 모양이라, 등록 전에 열면 다 불러온 순간 인사가 옆으로 옮긴다(1280 에서
x=64 → 272, 2026-10-10 재어). 뼈대 전체(내 사주 카드 · 풀이 격자)도 등록 폼과 다르다. 뼈대는 등록 여부를 읽기 전에 서므로 상태별로
맞추려면 로딩 구성을 바꾸거나 공용 뼈대를 단순하게 하는 추가 변경이 든다. 사용을 막지 않아 후순위로 둔다.
