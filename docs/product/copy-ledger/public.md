# 화면 문구 대장 — 로그인 · 가입 · 안내 화면

화면: `/auth` · `/auth/denied` · `/signup` · `/closed` · `/privacy` · `/about` · `/help` · `/share/**` · 바닥글 · 오류 · 404.

규칙 · 여러 화면에 걸친 줄 · 무리 색인은 대장의 머리 `docs/product/copy-ledger.md` 가 든다 — 여기는 이 무리 화면의 확정 문구만이다.
절 번호는 대장 전체에서 하나다(2026-10-10 에 한 장을 화면 무리로 나눴다, ADR 0162). 한 절의 줄이 여러 무리에 걸치면 머리말은 한
곳에 두고 다른 무리에는 그 무리의 줄만 둔다.

## 02 확정 문구 — PR #298 (2026-09-28)

저장 중에 실패했는지 모르므로 「저장된 값은 그대로」를 보장할 수 없다.

## 07 확정 문구 — 가입 거절 · 채팅 한도 · 첫 화면 (운영자 확정 2026-09-30)

원칙은 **오류는 상황 + 다음 행동**이다. 운영자가 표를 확정했다. 「검토 대기」에 있던 가입 코드 DB 오류와 `RATE_LIMITED_TEXT`
