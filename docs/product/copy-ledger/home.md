# 화면 문구 대장 — 홈 · 저장한 사람 · 풀이

화면: `/me` · `/me/people` · `/me/readings` · `/me/readings/[subject]` — 풀이 판 · 풀이 의견.

규칙 · 여러 화면에 걸친 줄 · 무리 색인은 대장의 머리 `docs/product/copy-ledger.md` 가 든다 — 여기는 이 무리 화면의 확정 문구만이다.
새 절의 번호는 `home-01` 부터다. 한 절의 줄이 여러 무리에 걸치면 머리말은 한
곳에 두고 다른 무리에는 그 무리의 줄만 둔다.
