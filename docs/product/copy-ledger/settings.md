# 화면 문구 대장 — 설정 · 프로필 · 설문

화면: `/me/profile` · `/me/settings` · `/me/survey`.

규칙 · 여러 화면에 걸친 줄 · 무리 색인은 대장의 머리 `docs/product/copy-ledger.md` 가 든다 — 여기는 이 무리 화면의 확정 문구만이다.
절 번호는 대장 전체에서 하나다(2026-10-10 에 한 장을 화면 무리로 나눴다, ADR 0162). 한 절의 줄이 여러 무리에 걸치면 머리말은 한
곳에 두고 다른 무리에는 그 무리의 줄만 둔다.
