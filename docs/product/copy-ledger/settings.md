# 화면 문구 대장 — 설정 · 프로필 · 설문

화면: `/me/profile` · `/me/settings` · `/me/survey`.

규칙 · 여러 화면에 걸친 줄 · 무리 색인은 대장의 머리 `docs/product/copy-ledger.md` 가 든다 — 여기는 이 무리 화면의 확정 문구만이다.
절 번호는 대장 전체에서 하나다(2026-10-10 에 한 장을 화면 무리로 나눴다, ADR 0162). 한 절의 줄이 여러 무리에 걸치면 머리말은 한
곳에 두고 다른 무리에는 그 무리의 줄만 둔다.

## 33 확정 문구 — 새 메시지 알림 카드 · 잠금 화면 · 채팅의 스스로 갱신 (운영자 확정 2026-10-10, G-72)

운영자가 G-72 의 시안 표(채팅 셋 · 설정 카드 · 알림 본문)에 답했다 — 원문 「이대로 확정」. 카드 자리는 지금 그대로(인연 찾기와
선택 동의 사이, G-73). 채팅 셋은 `docs/product/copy-ledger/matching.md` 의 같은 번호다. 표시 조건의 판정은 `src/lib/push`
(`pushPrivacyNoteShown` · `pushToggleFailure`)다.

| 자리 | 이전(시안) | 확정 |
| --- | --- | --- |
| 카드 제목 · 줄 이름 `app/me/settings/push-row.tsx` | 알림 · 새 메시지 알림 | 그대로 |
| 상태를 재는 동안 | 알림 설정을 확인하는 중… | (문구 없음) — 설명 줄을 비우되 꺼짐의 두 줄 높이를 보이지 않게 지켜 다 잰 뒤 줄이 밀리지 않는다. 누름은 세우지 않는다 |
| 꺼짐 설명 | 앱을 보고 있지 않을 때 새 메시지가 오면 이 기기로 알려 드려요. | 켜면 이 기기로 새 메시지 알림을 받아요. |
| 켜짐 설명 | 이 기기로 새 메시지 알림을 받고 있어요. | 이 기기의 알림이 켜져 있어요. |

| 브라우저가 막았다 · 지원 안 함 | 이 브라우저에서 알림이 차단되어 있어요. 브라우저 설정에서 이 사이트의 알림을 허용해 주세요. · 이 브라우저에서는 알림을 받을 수 없어요. | 그대로 |
