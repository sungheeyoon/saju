# 글꼴 사용 조건 — 근거

앱 글씨(부산단디명조, ADR 0109 추기 2026-10-28)의 사용 조건을 원문과 함께 둔다. 판정(써도 되는가)은 적지 않는다 — 조건과 이 앱이
쓰는 방식만 두고, 판정은 운영자 몫이다(이 폴더 README 「법률 근거의 자리」).

## 부산단디명조 (부산광역시 전용서체 「부산단디체」)

확인 2026-10-28. 부산시 서체 페이지(<https://www.busan.go.kr/bhbusan/font>)는 이 작업 환경에서 접속이 막혀(보안 정책 차단 화면)
원문을 직접 열지 못했다 — 아래 원문 문장은 그 페이지를 옮긴 무료 글꼴 안내(<https://www.wmupdate.com/2026/10/BusanDandiMyeongjo.html>)와
보도에서 가져왔다. 운영자가 받은 배포 압축(`부산단디명조.zip`, L · M · B 의 OTF · TTF)에는 약관 문서가 없었다.

- **사용 범위(원문 인용)** — 개인, 단체 등이 특별한 허가 절차 없이 무료로 영상, 인쇄, 출판, 웹, 모바일 등 여러 매체에 사용할 수 있다.
- **금지(원문)** — 「부산시 전용서체를 유료로 판매하거나 어떤 이유로든 수정, 편집, 복사, 배포 등의 대가로 비용을 청구 및 수령할 수
  없습니다.」
- **항목별 표(wmupdate 정리)** — 인쇄 · 웹사이트(웹서버용 폰트 포함) · 영상 · 임베딩(웹사이트 · 서버 탑재, 기기 내 탑재, **앱 GUI**) ·
  BI/CI(회사명 · 브랜드명 · 상품명 · 로고) 허용. 유료 판매 금지.
- **배포 · 출처** — 부산시가 2026-10-11 부터 시민 · 기업 · 단체에 무료 배포, 고딕 3 · 명조 3 · 손글씨 1 의 7종
  (<https://www.metroseoul.co.kr/article/20261011500248>). 보도는 「지자체 서체는 시민과 기업이 자유롭게 사용할 수 있다」고 전한다.
- **공공누리** — 부산시 보도자료 자체에는 공공누리 제4유형(출처표시 · 상업적 이용금지 · 변경금지)이 붙어 있다 — 보도자료 글의 조건이고
  서체의 조건으로 적힌 곳은 찾지 못했다. 부산시는 서체를 공공누리 「안심글꼴」로 등록하는 일을 추진한다고 했다(등록 여부는 확인 전).

### 이 앱이 쓰는 방식

- 웹 글꼴로 앱 화면에 쓴다 — 웹서버 탑재 · 앱 화면(GUI)이다.
- M · B 를 글자 조각 92개씩으로 잘라 `public/fonts/busan-dandi/` 에 두고 화면에 쓰인 조각만 받는다 — 글꼴 파일의 모양(글자)은 고치지
  않았고, 담는 그릇(woff2 조각)만 바꿨다. 글꼴을 따로 팔거나 내려받게 하지 않는다.
- Expo 앱(`mobile/assets/fonts/`)에는 배포 압축의 M · B OTF 를 고치지 않고 그대로 넣어 기기 안에 싣는다(앱 GUI) — 공개 저장소에 원본 파일이 함께 올라간다. 대가를 받지 않는다.
- 유료 판매(풀이권)는 앱이 파는 서비스이고 글꼴을 파는 것이 아니다.
