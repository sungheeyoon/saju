# 3차 · warm · 매칭 — 「오늘의 인연」 한 사람을 한 장의 편지로

## 콘셉트

홈이 아침 인사로 여는 앱이었다면, 매칭은 **오늘 도착한 편지 한 통**이다. 한 번에 한 사람만 선다: 큰 사진
한 장, 고운돋움으로 크게 쓴 이름, 과감한 숫자 점수(64px), 그 옆에 판정 한 줄. 그 아래 **「이 사람이 채워
주는 기운」**은 홈의 다섯 상징과 파스텔로, 소개는 크림색 편지지 위에 인용처럼 놓고 끝에 「— 서연」으로 서명한다.
카드는 **그 사람이 채워 주는 오행의 색**을 입는다(서연 = 나무의 초록, 지우 = 불의 분홍, 하린 = 물의 하늘) —
홈의 타일이 일간의 색을 입던 규칙을 매칭으로 옮긴 것이다. 사진 뒤에는 다음 사람들의 색이 한 장씩 기울어 비쳐
「아직 더 있다」를 말하고, 제목 옆의 진행 표시도 얼굴 대신 **그 사람의 상징**으로 선다(누가 올지 미리 들키지 않는다).

데이팅 앱(힌지 · 범블)의 손짓은 사진 위에서 흉내만 낸다 — 왼쪽으로 끌면 「다음 인연」, 오른쪽으로 끌면
「궁합이 궁금해요」 도장이 뜨고 요청 확인 창이 선다. 요청은 나가지 않는다.

## 홈 시안에서 이어받은 것

- 팔레트 한 벌(`warm.module.css`) · 다섯 상징(`symbols.tsx`) · 단추 세 층(`buttons.ts`) · 고운돋움(`fonts.ts`) — 전부 import, 안 고쳤다.
- 타입 단: 날짜 13px → 「오늘의 인연」 표시 단(28 → 36px) → 이름(폰 36 · 넓은 화면 48px) · 판정(22px) → 본문 15px → 보조 12~13px.
- 제안 메뉴(맨 위 알약 탭 + 종 · 톱니, 폰은 하단 독) — 홈 것이 켜진 탭을 `/me` 로 박아 두고 내보내지 않아서
  `menu.tsx` 에 **모양 그대로** 옮기고 `active` 만 받게 했다. 매칭 탭이 켜진다.
- 빈 상태와 참여 안내는 홈의 「내 사주 등록」 카드(크림 면 + 다섯 상징 + 먹색 주 단추) 모양을 그대로 쓴다.
- 「더 해 보기」 줄 카드(아이콘 동그라미 + 화살표)를 빈 날의 「그동안 할 수 있는 것」으로.

## 스스로 본 약점

1. **폰에서 참고 점수 고지가 길게 선다.** PRD §6.1.1 은 좁은 화면에서 이 줄을 접으라 하는데, 이 시안은 상세 창을
   없앴기 때문에 접을 자리가 없어 12px 두 줄로 남겼다. 점수 바로 아래라 숫자의 힘을 조금 깎는다 — `<details>` 로
   「참고 점수예요」 한 마디만 남기는 안이 있지만 새 문구가 든다.
2. **넓은 화면에서 사진(약 480×600)과 오른쪽 칸의 높이가 어긋난다.** 편지가 짧으면(하린, 소개 없음) 오른쪽이
   먼저 끝나 사진 아래가 비고, 길면 편지가 사진보다 아래로 내려간다. 사진 칸을 `sticky` 로 세우거나 사진 높이를
   화면 높이에 묶는 쪽이 낫다. 또 채움 색이 「채워 주는 오행」 첫 하나라서, 보완 오행이 없는 사람은 회색(`none`)
   카드가 된다 — 점수가 낮은 사람만 무채색이 되는 셈이라 의도와 달리 차별처럼 읽힐 수 있다.

## 4차: 지도를 섞다

사용자 결정(2026-09-24): 부드러움이 기본이고 느낌은 합격, 다만 관계 지도의 「내 궤도로 다가오는 인연」이 인상 깊었다 —
그 지도를 부드러움으로 다시 그려 섞는다. 편지 같은 한 사람 카드 · 큰 점수 · 채워 주는 기운 · 먹색 「궁합 요청」은 그대로다.
지도는 `orbit-map.tsx` 하나에 새로 그렸다(orbit 파일은 import 하지 않았다 — 생각만 가져왔다).

### orbit 에서 가져온 것

- 나는 가운데, **안쪽 궤도 = 내 오행 다섯**(상생 차례, 정수리부터 72°), 여덟 글자의 20% 에 못 미치는 기운은 빈 자리.
- **바깥 궤도 = 오늘의 후보**, 자기가 채워 주는 오행의 각도에 선다. 후보 점은 사진(명식은 공개되지 않는다).
- 선은 자료에 있는 관계(「이 기운을 채워 준다」) 하나뿐. 판정을 지어내지 않는다.
- 덱과 지도가 한 상태를 읽는다: 넘기면 궤도 밖으로 날아가고, 요청하면 가운데(나)로 빨려 든다. 넓은 화면은 카드 옆에 지도.
- 같은 오행을 채우는 후보끼리 각도를 벌리는 셈(`anglesOf`), 위쪽 반의 이름표는 위에 다는 규칙.

### 부드러움으로 바꾼 것

| orbit | warm 4차 |
| --- | --- |
| 한자 딱지(木 · 火 …) + 차가운 회색 궤도 | **파스텔 원 + 다섯 상징**(새싹 · 불꽃 · 산 · 보석 · 물방울), 크림 종이 위 옅은 먹 선, 바깥은 진주알 같은 둥근 점 궤도 |
| 적은 기운 = 점선 원 | 같음 — 점선의 **빈 원**. 후보가 닿으면 아래에서부터 그 오행의 파스텔로 **차오르고**(clip-path) 테두리가 먹 실선이 되며 천천히 숨을 쉰다 |
| 직선 점선 | **휘어진 빛 한 줄** — 번진 굵은 선(`--mid`) 위에 가는 먹 선, 후보에게서 오행 자리로 그어진다 |
| 지금 후보는 제 오행 바로 바깥 → 선이 사진과 알 사이에 묻혀 안 보였다(orbit 약점 1) | 지금 후보는 **한 걸음 옆**으로 비켜 선다(`stepAside`) — 선이 휘어 들어갈 길이가 생긴다 |
| 가운데 = 일간 글자 + 오행 테두리 | 가운데 = 내 일간의 파스텔 원 + 글자 + 「나」 알약 |
| 폰은 지도를 접고 카드 속 112px 도식 | 폰은 **해돋이 띠** — 궤도의 위쪽 반을 사진 바로 위에 가로로 펴고, 나는 띠 아래 끝에 반쯤 떠오른 해처럼 선다. 넘김 · 요청 · 되돌리기의 움직임이 폰에서도 보인다 |
| — | 사진을 끄는 만큼 지도 속 후보가 따라 움직인다(왼쪽 = 궤도 밖으로, 오른쪽 = 나에게로) |
| — | 움직임은 전부 `motion-reduce` 에서 멈추고 끝 모습만 선다(`orbit.module.css` 의 `draw` · `breathe` 포함) |

예시 명식(서하, 戊 일간, 목 0 · 화 1 · 토 2 · 금 4 · 수 1)에서 木 · 火 · 水 가 문턱 아래라 빈 원이고, 서연(木) · 지우(火) · 하린(水)이
**모두 실제로 빈 원을 채운다** — 그림이 참이다. 土 · 金 은 찬 원으로 선다.

### 자리

- **넓은 화면**: 왼쪽 = 그 사람(사진 → 편지), 오른쪽 = 나와 그 사람(이름 · 점수 한 줄 → 판정 → 단추 줄 → **지도 카드**). 지도 카드 아래 띠가 「이 사람이 채워 주는 기운」을
  글로 말한다(따로 서던 기운 칸을 지도에 붙였다). 이름과 점수를 한 줄로 모아 지도를 위로 끌어올렸다. 3차 약점 2(사진과 오른쪽 칸의 높이 어긋남)도
  왼쪽에 편지를 내려 얼추 맞췄다.
- **폰**: 해돋이 띠(오른쪽 위에 `01 / 03`) → 사진(6:5, **이름과 점수 숫자를 사진 아래 끝에**) → 단추 줄 → 판정 → 채워 주는 기운 → 편지.
  사진 · 점수 · 궁합 요청이 띠 바로 아래 한 덩어리로 선다. 폰의 진행 표시(상징 셋)는 띠가 대신해서 숨겼다.
- **지나친 인연**: 넘긴 사람들이 바깥 궤도에 남은 띠가 목록 위에 선다 — 「다시 만나보기」가 안으로 불러들이는 그림.
- **탐색 후보**: 지도의 사진 원에 반짝 딱지(+ 사진 위 「색다른 인연」, 기운 칸의 탐색 안내는 그대로).
- **빈 날 · 다 만난 날**: 나와 내 오행 다섯만 선 **아무도 다가오지 않는 작은 궤도**(`QuietOrbit`) + 기존 문장.
- **내 사주 없음**: 같은 작은 궤도인데 가운데가 점선으로 비고 다섯 자리도 모두 빈 원 + 「내 사주로 가기」.

### 클릭 수 변화

없다. 궁합 요청 2 · 넘기기 1 · 되돌리기 1 · 지나친 인연 보기 1 · 다시 만나보기 2 · 왜 맞는지 읽기 0 — 지도는 누를 자리가 없다(보조기기에는 숨기고, 같은 뜻을 카드의 글이 말한다).

### 스스로 본 약점

1. **폰 띠가 첫 화면을 조금 먹는다.** 띠(약 150px) 때문에 사진을 4:5 에서 6:5 로 눕혔고 점수 숫자를 사진 위로 올렸다. 그래도 Pixel 5(727px)에서는
   「궁합 요청」 줄이 화면 끝에 걸린다(시안 비교 머리를 빼고 셈). 띠를 사진 위에 겹치는 안은 얼굴을 가려 버렸다. 또 띠 가장자리의 알 이름표(10px)는
   작아서 읽기보다 그림으로 읽힌다.
2. **지도가 넓은 화면 첫 화면 아래에서 시작한다(1280×720).** 이름 · 점수를 한 줄로 모아 올렸지만 지도의 위 절반만 걸린다 — 그래서 선이 그어지는
   움직임을 스크롤한 뒤에 본다(Chrome 은 화면 밖 애니메이션을 미루므로 그어지는 순간은 보인다). 사진 칸을 줄이고 지도를 사진 옆 맨 위로 올리는 안은
   「편지」 느낌을 깎는다. 또 후보가 10명쯤이면 바깥 궤도의 같은 오행 자리에 ±24° 씩 겹쳐 쌓여 붐빈다(예시 덱은 3명이라 안 보인다).
